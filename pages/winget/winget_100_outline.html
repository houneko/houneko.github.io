wingetって何

wingetは Windows Package Managerのこと

wingetは、ソフトウェアの検索やインストール、アンインストール、アップデートをCLIで行うためのソフトウェア。だけと単独のソフトウェアとして存在しているのではなく、App Installerというアプリの一部として存在する

Linuxの世界でいうと、Debian/Ubuntu系の「apt」やRedHat/CentOS系の「yum」や「dnf」みたいなもので、CLIのパッケージマネージャ

wingetのインストール

wingetは、Windows10のバージョン21H1以降からはプリインストールされているので、自分でインストールしなくてもいい

手動でインストールする場合は、Microsoft Storeからインストールする方法と、GitHubからインストールする方法がある

Microsoft Storeからインストール

  1. Microsoft Storeで「アプリインストーラ」を検索
  2. Searchの検索で Winget-CLIを検索
  3. 見つかったリンクをクリック
  4. 右ペインのReleaseの下にある Windwos Package Manager バージョン番号 をクリック
  5. 一番下のAssetsまでスクロール「Microsoft.DesktopAppInstaller_xxx.msibandle」をクリック

GitHubからインストール

  1. GitHubのWebページに行く
  2. Searchの検索で Winget-CLIを検索
  3. 見つかったリンクをクリック
  4. 右ペインのReleaseの下にある Windwos Package Manager バージョン番号 をクリック
  5. 一番下のAssetsまでスクロール「Microsoft.DesktopAppInstaller_xxx.msibandle」をクリック

自分がはまったわな

まぁ、罠というほどではないのですが、Windows11環境でコマンドラインから「winget」とタイプしてもそんなコマンドは知らんと怒られて、動かなかったことがあります。Windows11ではプリインストールされているはずなのに何で？？と悩んでいました。仕方が無いので上記のインストールを試してみてもインストーラから「もうインストールされてますわ」と言われる始末。インストールされているけど使えない状態になっていました。 


        > winget
        winget: The term 'winget' is not recognized as a name of a cmdlet, function, script file, or executable program.
        Check the spelling of the name, or if a path was included, verify that the path is correct and try again.

どうやって解決したか？

wingetは、単独のソフトウェアとして存在しているのではなく、App Installerというアプリの一部として存在しています。
このため、「C:\Users\自分\AppData\Local\Microsoft\WindowsApps」 にパスが通っていることが必要です。これに気づかなかったらインストールはされているけど、実行してもそんなコマンドは知らんと言われ続けてしまいます

パスを確認してみる


        > $env:path -split ';' | where {$_ -like "*win*"}
        C:\WINDOWS\system32
        C:\WINDOWS
        ...
        ...
        C:\Users\xxx\AppData\Local\Microsoft\WindowsApps  #← このパスが設定されていないとだめ
        ...

wingetの書式

wingetの書式は以下のようにサブコマンドとそのオプションを指定する形式となっている

サブコマンドは「-」ハイフンなし、サブコマンドオプションは「-」ありとなっている


        #wingetの書式は以下のようにサブコマンドとそのオプションを指定する形式となっている
        winget [サブコマンド][サブコマンドオプション]

        #バージョンを確認する場合は「-v」や「--version」
        > winget -v  #「-v」でバージョンを表示させる
        v1.xx.xxx       #バージョンが返ってきている
