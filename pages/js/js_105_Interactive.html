JavaScriptによるインタラクティブな動作

インタラクティブな動作とは

インタラクティブ（Interactive）とは、ユーザの操作に応じて動的な応答を行う機能のことで、JavaScriptを使えばこの機能を実現できます（CSSでもインタラクティブな動作を表現できると思いますが、Webページに動きを付けるということではJavaScriptです）

以下のサンプルコードは、Webページに「クリックしたらalert表示します」というボタンを表示し、それをクリックしたらメッセージボックスで「ボタンを押したらにゃー」と表示されるというものです

buttonタグのonclick属性に「関数名」を指定し、ボタンがクリックされるとその関数がコールされてメッセージが表示されるというものです（注："showMessage()" のように「()」まで書かないといけない）


            <body>
              <!-- ボタンをクリックしてjs関数をコールする -->
              <button onclick="showMessage()">クリックしたらalert表示します</button>
              <script>
                function showMessage() {
                  alert("ボタンを押したらにゃー");
                }
              </script>
            </body>

参考：よりJavaScriptらしい書き方だと以下になります


            <body>
              <!-- ボタンをクリックしてjs関数をコールする -->
              <button id="myButton">クリックしたらalert表示します</button>
              <script>
                function showMessage() {
                  alert("ボタンを押したらにゃー");
                }
                document.getElementById("myButton").addEventListener("click", showMessage);
              </script>
            </body>

以下は、インタラクティブな動作を体験するボタンです。クリックするとalertでメッセージが表示されます
