forループで表を作る

Webページで表を作る場合は、tableタグ内にtrやtdで行やセルデータをマークアップして作りますが、大きな表をたくさん作る場合、いちいちtr、tdを書くのは面倒です。そう言う場合はこの方法が便利です


          <!-- htmlで普通に表を書く場合 -->
          <table>
            <tr>
              <th>No</th>
              <th>名前</th>
              <th>意味</th>
            </tr>
            <tr>
              <td>01</td>
              <td>Neko</td>
              <td>猫である</td>
            </tr>
            <tr>
              <td>02</td>
              <td>Inu</td>
              <td>犬である</td>
            </tr>
            <tr>
              <td>03</td>
              <td>Usagi</td>
              <td>うさぎである</td>
            </tr>
          </table>

これをJavaScriptのforループで書くと以下のようになります。表のデータを配列で持ち、forループで配列要素を表のデータとして書くようになっています


          <table>
            <thead>
              <tr>
                <th>No</th>
                <th>名前</th>
                <th>意味</th>
              </tr>
            </thead>

            <script>
              let nums = ['01', '02', '03'];                              //Noの配列データ
              let names = ['Neko2', 'Inu2', 'Usagi2'];                    //名前の配列データ
              let means = ['猫である２', '犬である２', 'うさぎである２']; //意味の配列データ
              for (let lp = 0; lp < 3; lp++) {
                document.write('<tr>');
                document.write('<td>' + nums[lp] + '</td>');  //tdタグのコンテンツとして配列要素を書く
                document.write('<td>' + names[lp] + '</td>');
                document.write('<td>' + means[lp] + '</td >');
                document.write('</tr>');
              }
            </script>
          </table>
No 名前 意味

配列要素をオブジェクトにする

上の例では、配列を別々に定義していたけど、これらは関連するデータなので、オブジェクトにしてそれを配列要素として扱った方が後々便利になります（りんごは8000 というデータとセットで一緒に扱う）

なので、同じように配列をforループで表にする場合は、こちらの方がいいです


          <script>
            let myDatas = [
              // 配列要素は、{name:値, mean:値} のオブジェクト
              { name: "Neko3", mean: "猫である" },
              { name: "Inu3", mean: "犬である" },
              { name: "Usagi3", mean: "うさぎである" },
            ];
            for (let lp = 0; lp < 3; lp++) {
              document.write('<tr>');
              document.write('<td>' + myDatas[lp].name + '</td>');
              document.write('<td>' + myDatas[lp].mean + '</td >');
              document.write('</tr>');
            }
          </script>
