JavaScriptの変数

JavaScriptの変数は代入する値により型類推されるので型を指定する必要はない（動的型付け言語）。また、宣言時は文字列を代入していたけど、その後の処理で数値を代入することも可能

  • 型指定は不要（動的型付け言語）
  • 違う型のデータの再代入が可能
  • 変数名命名は「キャメルケース」

再代入時のメモリイメージ

左図のように変数a に「10」を代入し、その後「Neko」を再代入した場合、変数aはもう一度メモリ上で確保しなおされてアドレスが変わる

最初、変数aに数値10が代入される。この時、メモリ上に（例えば1000番地）変数aの領域が確保され、そこに10が格納される。次にこの変数aに文字列Nekoを再代入する時に別のアドレス（例えば1500番地）が確報され、そこに文字列Nekoが格納される。ある変数に別の型の値が再代入できるのは、このようにアドレスが変わるからやろうな。（C言語のような静的型付け言語の場合は、int a = 10で宣言した後に、a = 20; と再代入しても変数aのアドレスは変わらない）


        let myVar = "Neko";   //文字列を代入。変数myVarはキャメルケースで命名
        ...
        myVar = 1200;         //数値型データを再代入

動的型付け言語の注意点：JavaScriptに限らず動的型付け言語は、型指定しないので使いやすいけど意図しないバグを発生させてしまう可能性があるので注意が必要


        let myVar = "40";     //文字列で40を代入
        ...
        myVar += 5;           //数値の5をプラスしようとしているけど、文字列が連結されて "405" となる

JavaScriptの変数の宣言方法

変数の宣言は以下の３つの方法があります。こちらで再整理しました

  • var ：これは古い書き方で、今はあまり使われない（なのでとりあえず無視）
  • let ：現在の宣言方法。再代入可能
  • const：再代入不可の変数宣言（なので実質、定数の宣言）

変数の型

JavaScriptは、動的型付け言語なので、プログラマは変数宣言時に型を指定する必要はありませんが、この変数には内部的に型が存在しています。つまりJavaScriptは内部で変数の型を認識しています

変数の型
名前 意味
number 数値
string テキスト
boolean 真偽値（true、false）
undefined 未定義
null 存在しない事を示す値

数値はnumber型ですが、これは他の言語のようにint型やlong形、float型のように分かれていません。つまり、整数や小数を１つで扱えるようになっています

JavaScriptの定数

定数は、constで宣言する。constは再代入不可の宣言で実質、定数の宣言になる。


          const myVar = 10;
          ...
          myVar = 20;   // ← この処理は「エラー」になる。∵constは再代入不可のため

const宣言した定数は変更できる？

最初にJavaScriptを見てた時に驚いたのがこれ。JavaScriptのconstは、再代入はできないが値を変更することは可能

どういうことかというと、constは他の言語と同様に再代入はできないが、const宣言する定数が参照型の場合、そのアドレス内のデータは変更できるってこと


          const myVar = ["Neko", "Inu", "Usagi"];   //constで宣言している配列。constなので再代入はできない
          console.log('myVar[1] = ' + myVar[1]);
          myVar[1] = "Komainu";                     //再代入はできないが、このアドレス内の要素は変更できる
          console.log('myVar[1] = ' + myVar[1]);

const宣言した定数であるmyVar配列。この配列のインデックス[1]の値が変更できていることが分かる
