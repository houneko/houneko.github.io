JavaScriptのオブジェクト

JavaScriptはオブジェクト指向なので、多数のものがオブジェクト（参照型）として扱われています。オブジェクトをうまく使うには、そのオブジェクトがどういうものかを知る必要があります。つまり、どんなプロパティやメソッドを持っているかを知ることは、オブジェクトを上手に使えることだと思います

MDNドキュメントで調べる方法

JavaScriptのドキュメントは、MDN（Mozilla Developer Network） です

例えば、getElementByIdメソッドが返すオブジェクトが持つプロパティやメソッドは何かを調べたい場合、MDNのページからこのメソッドを検索して、何オブジェクトが返ってくるかなどを調べます。マニュアル内には「Element」オブジェクトが返ってくると説明されているので、次に「Element」オブジェクトを検索してこのオブジェクトが持つプロパティやメソッドを調べたらいいと思います

console.dirで調べる方法

console.dirは、引数で指定したオブジェクトが持つプロパティやメソッドを表示するメソッドです。この結果をブラウザの開発者ツール（F12）で確認するということです


            <body>
              <p id="myTest">HouNeko!</p>
              <script>
                // getElementById()の取得結果オブジェクトをmyObjに代入
                const myObj = document.getElementById("myTest");
                // console.dirでそのオブジェクトの持つプロパティやメソッドをコンソールに表示
                console.dir(myObj);
              <script>
            </body>

F12で開発者ツールを開いて、コンソールタブの内容を確認すると、このオブジェクトが持つプロパティやメソッドが確認できます

この例では、コンソールタブを開くと以下のように「p#myTest」があり、それを展開するとこのオブジェクトが持つプロパティやメソッドが表示されます（いっぱいある）

Object.getOwnPropertyNamesで調べる方法

Object.getOwnPropertyNamesは、MDNを見ると引数で指定されたオブジェクトが持つプロパティやメソッドを配列で返すスタティックメソッドであることがわかります


            <body>
              <p id="myTest">HouNeko!</p>
              <script>
                // getElementById()の取得結果オブジェクトをmyObjに代入
                const myObj = document.getElementById("myTest");
                // Object.getOwnPropertyNamesでそのオブジェクトの持つプロパティやメソッドをコンソールに表示
                console.log(Object.getOwnPropertyNames(myObj));
              <script>
            </body>

F12で開発者ツールを開いて、コンソールタブの内容を確認すると、このオブジェクトが持つプロパティやメソッドが確認できます

この例では、コンソールタブを開くと以下のように「Array」があり、配列要素を見るとこのオブジェクトが持つプロパティやメソッドが表示されます（いっぱいある）
