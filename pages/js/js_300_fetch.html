fetch関数って何

fetchはブラウザに実装されている非同期処理を行う関数です。これはFetch APIという仕様（ネットワーク通信に関するAPI仕様）に従ってブラウザ内に実装されています。これだけだと何が言いたいねんとなりますが、平たく言うと指定された物を取ってきてと依頼する関数です。この時、物が取れるまで同期で処理するのではなく、取ってきてと言った後は他の処理を進めて、物が取れたよというのが返ってきたらそこで取れた後の処理を行うという感じです

通常ブラウザとサーバの間ではリクエストとそれに対するレスポンスのやり取りを行っており、これは同期処理となっています。しかし、非同期の場合は完了のレスポンスを待たずに次の処理を行い完了時にコールバック関数が実行されるようになっています。fetchだけ覚えておけばいいと思いますが、fetch以前は「XMLHttpRequest()」というメソッドが使われていたそうです（自分は知らん）


ちなみに自分はアセンブラがルーツなのですが、アセンブラの世界ではフェッチという言葉を良く使っていてなじみ深い言葉です。また、その後にやったCではコールバックも良く使っていました

fetchの動作

fetch()を実行するとすぐにPromise が返ってきます。これは処理の完了ではなく、fetchを受け付けましたよって感じのものです。その後次のコードを実行します（つまり非同期）

fetchの動作は以下のようなフローになります

  1. ① fetch()で、引数指定したものを取ってきてという依頼をする
  2. ② すぐにPromiseが返ってくる（これは関数を受け付けた程度の意味）
  3. ③ 非同期なので、次の「.thenメソッド１」を実行。thenの引数はアロー関数となっているが、これはこのアロー関数を実行するという意味ではなく、コールバック関数として登録するという意味。 なのでここではコールバックを登録するだけとなっている
  4. ④ 非同期なので、次の「.thenメソッド２」を実行。このthenも同じで引数のアロー関数をコールバックとして登録するだけ
  5. ⑤ 非同期なので、次の「.catchメソッド」を実行。これもコールバック関数を登録するだけ

  //fetchの書式（.then、.catchはメソッドチェーンになっている）
  fetch(...)            //① 引数で指定したものをフェッチしてという依頼
    .then(() => {    //③ Promise の thenメソッド。引数はコールバック関数
      処理…
    })
    .then(() => {    //④ Promise の thenメソッド。引数はコールバック関数
      処理…
    })
    .catch(() => {   //⑤ Promise の catchメソッド。引数はコールバック関数
      エラー処理…
    });

以下のシーケンス図は、自分の理解の元で作ったものです。細かくは違うかも知れないので参考としてください（とりあえずこの理解で困ったことは無いので大体あっていると思いますが）

Promiseって何

Promiseの詳細はMDNを確認していただきたいですが、ざっくり言うと非同期処理の状態を持っているオブジェクトです（と自分は理解しています）。

Promiseの「.then()」と「.catch()」

Promiseの書式は、.thenメソッド、.catchメソッドでコールバック関数を登録していますが、.thenメソッドは成功系のコールバック関数を登録し、.catchメソッドはエラー系のコールバック関数を登録します

Promiseの状態遷移

Promiseは、以下のステータスがあり、この状態遷移によりコールバック関数が実行されます

  • pending（処理中）
  • fulfilled（成功）
  • rejected（失敗）
