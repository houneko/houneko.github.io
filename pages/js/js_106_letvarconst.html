varとlet、constについて

JavaScriptは動的型付け言語なので、型の指定は不要ですが変数の宣言自体は必要です（他の動的型付け言語も同様と思います）。つまり、型の指定と変数の宣言は別という事です

varとletは変数を宣言する時のキーワード。昔はvarだったけど今はletだけ使えばいいと思います

constは、定数を宣言するキーワード。JavaScriptでは他の言語よりもconstをよく使うと思います

変数宣言のvarとlet、定数宣言のconst
名称 再代入 再宣言 スコープ
var 〇 〇 関数
let 〇 × ブロック（{}内がスコープ）
const × × ブロック（{}内がスコープ）

再代入と再宣言

上記の表を見ると、varとletで再宣言の所が違うのが分かると思います。では再宣言や再代入は何でしょうか？

なお、定数は当然再代入も再宣言も不可です

  • 再代入

    これは変数の値を代入しなおすことで、普通のプログラムでは日常的にあるものです。varもletも変数に対する宣言なので、当然宣言されたものは変数ですから、再代入は可能です（だから両方とも〇）

    
              //varによる変数宣言と再代入
              var varValue = 100;
              varValue = "varNeko";     //最初100を代入したvar変数に文字列を再代入している
              console.log('varValue = ' + varValue);

              //letによる変数宣言と再代入
              let letValue = 100;
              letValue = "letNeko";     //let変数でも再代入は可能
              console.log('letValue = ' + letValue);

              //実行結果
              varValue = varNeko
              letValue = letNeko

  • 再宣言

    再宣言はvarに特有な仕様です。言葉通り宣言しなおす事が可能ということです（再宣言ってメリットあるん？）。昔のJavaScriptでは、letが無くvarでの宣言しかなかったのでvarを使っていましたが、varは再宣言ができるので逆にわかりにくかったかもしれません（なので、letだけ使えばいい）

    以下のコードはvarはエラーにならないですが、letは再宣言不可なのでエラーになります

    
              //varによる再宣言
              var varValue = 100;
              var varValue = "varNeko";   //varで宣言した後、またvarで宣言しているがエラーにならない

              //letによる再宣言
              let letValue = 100;
              let letValue = "letNeko";   //letで再宣言するとエラーになる
              // letは再宣言でエラーになる（既に宣言済やというエラーになってる）
              SyntaxError: Identifier 'letValue' has already been declared

varとletのスコープによる差分

varとletでは再宣言の違いがありましたが、スコープも違います。どちらかというこのスコープの違いがvarを使わない方がいい理由のようです

どういう事かと言うと、varは関数スコープなので意図しない動作になる可能性があるということです。以下のサンプルは、関数内のif文のtrueケースブロック内でvar宣言していますが、false側になった場合、宣言が無いのでundefinedになります。しかし、これはエラーではないので処理は続き意図しない動作を誘発するおそれがあります 


          function hoge(condition) {
            if(condition) {
              var result = "trueです";    //if文のtrueのケース内でvar宣言
            }
            //false側に来た場合、result変数は宣言されていないためundefinedになる
            //しかしスコープは関数なので、関数内からは見えるのでエラーではない
            //という挙動になります
            console.log(result);          
          }

          hoge(true);   //trueでhoge()をコール
          hoge(false);  //falseでhoge()をコール

          //実行結果
          > node .\test.js
          trueです      //trueでコールした結果
          undefined     //falseでコールした結果

これをlet宣言にした場合はどうなるかというと、false側ではresult変数が見えないのでエラーになります

エラーになったらあかんじゃんと思うかもしれませんが、明示的にエラーで止まってくれるので、予期せぬ状態で処理が進むよりも何倍もいいということです


          function hoge(condition) {
            if(condition) {
              let result = "trueです";    //if文のtrueのケース内でlet宣言
            }                             //let宣言の変数はブロックスコープなのでresult変数が見えるのはこの中だけ

            //false側に来た場合、result変数は見えないので未定義のエラーとなる
            console.log(result);          
          }

          hoge(true);   //trueでhoge()をコール
          hoge(false);  //falseでhoge()をコール

          //実行結果
          > node .\test.js
          ReferenceError: result is not defined   // resultが未定義というエラーで止まっている

varとletのスコープによる差分２

var宣言の変数の場合、スコープ内で名前がぶつかる可能性があるという問題もあります。var宣言の変数は再宣言も可能なのでこのような問題が起き得るということです


          function hoge() {
            var myValue = "外側で設定した値";   // myValueに「外側で設定した値」を代入
            if(...) {
              var myValue = "内側で設定";       // myValueに「内側で設定」を再宣言
              ... 
            }
            console.log(myValue);
          }

          //実行結果
          > node .\test.js
          内側で設定  // myValueは関数スコープで、var宣言の変数なので再宣言も可能なため上書きされている

これがlet宣言の場合はスコープが違うので名前がぶつかることはありません


          function hoge() {
            let myValue = "外側で設定した値";   // let myValueに「外側で設定した値」を代入
                                                // このmyValue変数のスコープは関数の{}ブロック内
            if(...) {
              let myValue = "内側で設定";       // ifブロック内で let myValueに「内側で設定」を宣言
              ...                               // このmyValueはスコープが違うので再宣言ではなく名前も
            }                                   // ぶつからない
            console.log(myValue);               // if文の外からはif文内の変数は見えない
          }

          //実行結果
          > node .\test.js
          外側で設定した値  // if文の外から見えるmyValue変数は、if文の外で宣言したmyValue変数
