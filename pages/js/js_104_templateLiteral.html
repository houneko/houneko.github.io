テンプレートリテラル

テンプレートリテラルとは

文字列の中に変数や定数を埋め込むことができるしくみ。${変数名} を文字列に埋め込んでおけば、その部分はその変数の値に展開される。ただし、テンプレートリテラルは文字列全体をバッククオートで囲まないといけない

  • 文字列全体をバッククオートで囲む（`文字列`）
  • 変数名や定数名は「${}」で文字列内に指定する

          const name = "Neko";
          const age = 18;
          //templateLiteralを使った場合
          console.log (`名前は ${name} です。年齢は ${age} です`);
          
          //templateLiteralを使わない場合
          console.log("名前は " + name + " です。年齢は " + age + " です");

おまけ）リテラルとは

リテラル（Literal）は、プログラム上に埋め込まれた直値のこと。文字リテラルや数値リテラルがある。基本的に何度も出てくるような値は変数や定数で定義した方がいいと思っている（∵あちこちに同じ意味の値があると修正する時に修正箇所が多くなってしまう）。
じゃ、リテラルを使うメリットって何か？これは一度しか使わないような値はリテラルの方がいい。変数に入れると変数宣言や定義がありその値を参照するコードとなるが1回しか使わないのであれば、これは冗長。また変数などに入れると変数名から何かを類推しないといけないがぱっと分からないこともある。でも直値であればそのものなのでわかりやすい
