JavaScriptの関数：アロー関数

アロー関数とは

アロー関数は、ES6で追加された関数の書き方、表現方法です。アロー関数を使えばJavaScriptらしい書き方ができます

()で引数を示し、=> でアロー関数を示し、その右側に返す値を書くという書式です（=>の右側は関数ブロックも可）。これは、functionで書いていたものを「() => {...}」と短く書いたものと言えるので、呼び出し方などは何も変わりません

また、アロー関数は、構文上関数名を定義できないので他の言語で言う「無名関数」や「ラムダ式」と同じです。つまり、アロー関数≒無名関数とイメージしたらいいと思います


          // funnctionキーワードで定義した関数
          function myAdd(a, b) {
            return a + b;
          }

          // これをアロー関数で書くと
          const myAdd = (a, b) => a + b;
          // この意味は、
          // a, b を引数で受け取り、a + b を返すと読むことができ直観的な表現となっている
          // このアロー関数をコールする
          console.log(myAdd(10, 20));

          // 引数が無い場合のアロー関数
          const hoge = () => console.log("Hello");
          // コール
          hoge();

アロー関数で関数ブロックを定義

先ほどの例では、=>の右側には関数がリターンする値を書いていましたが、ここに関数ブロックを定義することもできます


          // アロー関数で関数ブロックを定義
          const myFunc = (a, b) => {   //関数ブロックを定義している
            const result = a + b;
            return result;                //関数ブロックの場合、自分でreturnを書く
          };
