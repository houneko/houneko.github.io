console.logの注意点

JavaScriptの開発では、console.logで「変数名＝値」を表示させたりしますが、この時の注意点です（というほどのものではない？）


          const myName ="Nkko";
          console.log('myName = ' + myName);

          //表示結果、見かけ上意図した表示になっている
          myName = Nkko

この例は、変数名＝その変数の値 という形で表示され、見かけ上は意図した表示ができています

意図した結果は表示されますが、これは「'myName='」という文字列と「myNameの値（つまり文字列）」が連結されて１つの文字列となり、それをconsole.logで表示していることになります

次にオブジェクトの場合はどうなるかを見てみます


          // myInfoはオブジェクト
          const myInfo = { name: "Neko", age: 1000, city: "KOBE" };
          // 'myInfo = ' + myInfo は意図した表示にならない
          console.log('myInfo = ' + myInfo);          

          > node .\hoge.js の結果
          myInfo = [object Object]

この結果は、myInfo = オブジェクト内容 が表示されることを期待していますが、実際は上記の通り、myInfo = [object Object] と表示されます

これは何故かというと、JavaScriptは、文字列と何かを「＋」で連結すると文字列に置換してから連結するという動作をするからです。少しもやもや感が残りますが、これがJavaScriptの性質です。文字列と＋で何かを連結すると、その何かは文字列にしてから「文字連結」します

じゃ、どうするか「＋」演算子だと文字連結になるので、「,カンマ」で別の引数としてconsole.logに渡せばいいです


          // myInfoはオブジェクト
          const myInfo = { name: "Neko", age: 1000, city: "KOBE" };
          // +演算子は使わず、「,カンマ」で次の引数を指定する
          console.log('myInfo = ', myInfo);          

          > node .\hoge.js の結果
          // myInfoに代入されたオブジェクトがそのまま表示されている
          myInfo = { name: "Neko", age: 1000, city: "KOBE" }
