JavaScriptの基本

JavaScriptの基本型と参照型

基本型（プリミティブ型）

JavaScriptは動的型付け言語なので、型指定を気にせず使えるが、データ型として「基本型（プリミティブ型）」と「参照型」という２つの型があるので、この違いを認識しておかないといけない

基本型（プリミティブ型）

タイプ 概要 その他
number（数値） 数値全体。整数、小数等の区別なし
string（文字列） 文字列。シングルかダブルクォーテーションで囲む
boolean（真偽値） trueが真、falseが偽
symbol（シンボル） シンボル
null（ヌル値） 値が空
underlined（未定義） 値が未定義

基本型（プリミティブ型）の変数には、値そのものが変数に代入される。なので基本型（プリミティブ型）は変数定義した時に変数a用にメモリアドレスが確保されてそこに値が代入される


          <script>
            //変数aに10を代入する時にメモリ上に変数aのアドレスが確保されてそこに10が格納される
            let a = 10;
            ...
            //変数aに文字列型の値を再代入。この時、再度メモリ上に変数aのアドレスが格納されてそこに文字列Nekoが格納される
            a = "Neko";
          </script>

参照型（オブジェクト）

参照型は、その実際の値が格納されるメモリアドレスが代入される。これが基本型（プリミティブ型）と参照型の違い

参照型はオブジェクトでもあります

参照型の変数aに別の参照型変数bを代入すると、変数aには変数bのオブジェクトが格納されているアドレスが代入される。なので、変数aも変数bも同じアドレスを参照することになる。また、変数aに基本型のデータ（例えば、数値10）を代入すると値そのものが格納される

※C言語のポインタ変数に似ているけど、アドレス操作はできない（実際にはアドレスは見えない）。こういう操作はある意味危険なので、JavaScriptではできないようになっている（つまりポインタ変数と同じようなものだけど安全になるようにラップされている）

タイプ 概要 その他
配列(array) 配列への参照
オブジェクト(object) オブジェクトへの参照
関数(function) 巻数への参照 

        const myArray = [10, 20, 30];
        console.log("myArray type = " + typeof(myArray));   // 型はobject。         結果： myArray type = object
        console.log("myArray value= " + myArray);           // 値はアドレスではない 結果： myArray value= 10,20,30
