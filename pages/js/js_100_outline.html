JavaScriptの基本

JavaScriptの基本概念

JavaScriptとは

ブラウザに実装されているスクリプト言語。Javaとは違う。ブラウザに実装されている言語なので、基本的にはブラウザ上で実行する。このため、HTMLやCSSなどの知識もある程度必要となる

  • JavaScriptの歴史

    JavaScriptはネットスケープ社が開発したもので、JavaScriptが生まれたころはJavaが非常に注目されていた。その頃ネットスケープ社はオラクルと提携しており、Javaをリスペクトしていたので、オラクルさんの作ったJavaという言葉を取り入れてJavaScriptと名付けられた。 （なので、JavaとJavaScriptは全然別物）
    ※スクリプトとは、ソースコードを記述したそのまま動くような言語の総称

    JavaScriptはもともとNetsacple用に作られたが当時のIEも対抗として同じようなプログラミング言語を作って対抗していた。その結果、NSでは動くがIEでは動かないなどの違いができて、国際的な団体のEcma International（欧州電子計算機工業会、ECMA: European Computer Manufacturers Association) が仲立ちし規格を制定した。これで、ECMAScript (ECMA-262)とも呼ばれるようになった。
    現在、ECMA は Ecma International に名称が変更されている。

JavaScriptの有効化

ブラウザでJavaScriptが有効になっているかどうかの確認方法（というか有効にしない使い方はあるのかな）

  • Chromeの場合

    右上の三点リーダ → 設定 → プライバシーとセキュリティ → サイトの設定 → JavaScript

  • Edgeの場合

    三点リーダ → 設定 → プライバシー → サイトのアクセス許可 → すべてのアクセス許可 → JavaScript

  • Firefoxの場合

    Firefoxは少し違っていて、アドレスバーに「about:config」と入力して「JavaScript.enabled」の値を確認する

JavaScriptを書く場所

JavaScriptはどこに書くのか

JavaScriptは基本的にブラウザ上で動く言語（として始まったけどブラウザ上以外でも動く）。なので最初やる時はどこに書くのかなという壁があります。

  • インラインスクリプト

    インラインスクリプトは、HTMLコードの中に直接JavaScriptのコードを埋め込む方法。<body>要素に<script>～</script>タグでscript要素として直接JavaScriptを書く 

    
            <body>
              <script>
                document.write('Hello World!');
              </script> 
            </body>
  • 外部スクリプト

    外部スクリプトは、JavaScriptを別ファイルで作成しHtmlコード内に取り込む方法。<head>タグ内に<script>タグを書いて取り込むファイル名を指定する

    
            <head>
              <meta charset="UTF-8" />
              <meta name="viewport" content="width=device-width, initial-scale=1.0" />
              <title>Document</title>
              <script src="../neko-script.js"></script>			<!-- jsファイル -->
              <script src="../inu-script.js"></script>			<!-- jsファイル -->
            </head>

Hello, World

とりあえず Hello, World をやってみる

プログラミング言語を始める時は、最初にHelloWorldを表示させるってのをよくやる。なので、最初の一歩はJavaScriptでHelloWorldを表示させる
JavaScriptのHello, Worldは、表示させる場所によりいろいろな方法がある

  1. コンソールにHelloWorld表示する）

    この例は、コンソールにHello, Worldを表示するもの。コンソールはブラウザ画面とは違うので一見何も表示されていないけど、コンソールを見ると、Hello, Worldが出力されている

    
              <script>
                console.log("HelloWorld");
              </script>

    この結果を見るには、F12キーでブラウザの開発者ツールを起動して、コンソールタブを開いて表示されている内容を確認する

  2. alertでHelloWorld表示する）

    
              <script>
                alert("HelloWorld");
              </script>

    alertは、MsgBoxみたいなものなので、実行するとブラウザ上にポップアップが表示される。この内容にHelloWorldを表示させている

  3. ブラウザ画面にHelloWorld表示する

    ブラウザ上に書くにはいくつかの方法がある

    • writeメソッド（今は推奨されない） 
      
                  <script>
                  document.write("HelloWorld");
                  </script>

      document.writeメソッドでブラウザ上にHelloWorldを表示させている

    • JavaScriptでWebページに書き込む 
      
                <!-- divはid属性を指定しているだけで中身は空 -->
                <div> id="output"</div>

                <!-- 
                  JavaScriptで
                  ・表示する定数messageを定義（これがHelloWorld）
                  ・getElementById(it名)で、id名がつけられている要素を取得
                  ・取得したオブジェクトの.textContentプロパティにmessageを代入して表示
                  -->
                <script>
                  const message = "HelloWorld";
                  document.getElementById("output").textContent = message;
                </script>

      document.getElementById("output")メソッドで、idが「output」と付けらている要素を取得し、そのtextContentプロパティに表示した文字を代入して、ブラウザ上にHelloWorldを表示させている
