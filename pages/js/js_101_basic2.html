JavaScriptの基本的な特徴

JavaScriptで動的なページが可能となる

JavaScriptは、それ以前にあったような静的なWebページを動的、インタラクティブなものにするために作られた。このためJavaScriptから見たらWebページもオブジェクトであり、全てオブジェクトとして扱う事ができる。

  • Webブラウザのウィンドは、windowオブジェクト
  • HTMLドキュメントは、documentオブジェクト
  • 画像は、Imageオブジェクト

          <script>
            //documentオブジェクトは、windowオブジェクトのメンバ。以下の2つは同じ内容である
            //documentオブジェクは、windowオブジェクトの子供なので正確に書くと以下のようになるが、
            //自分のウィンドウの要素の場合は、windowオブジェクトは省略できるので、通常はdocumentから書く
            document.write("Hogeです");
            window.document.write("Hogeです");
            
            //alert()メソッドもwindowオブジェクトのメソッドなので、正確に書くとwindow.alert()になる
            //同様にwindowは省略して、alert()から書く方が多い
            window.alert("Nekoです");
          </script>

JavaScriptは動的型付け言語

JavaScriptは動的型付け言語なので、変数の型指定をしなくてもいい。また数値型として作成した変数に途中で文字列型のデータを代入しなおすこともできる


          let x = 10;       // x は今は数値(Number)
          x = "hello";      // x は今度は文字列(String)
          x = true;         // x は今度は真偽値(Boolean)

JavaScriptは大文字小文字を区別する

JavaScriptは、HTML内にscriptタグを使って記述することができるが、HTMLは大文字小文字を区別しないので間違って大文字小文字を意識せずに書いてしまう可能性がある（VSCodeを使っていたらインテリセンスが効くので、インテリセンスで補完すれば間違いにくいが）。 


          <body>
            <script>
              Alert("Hogeです");    //このJSコードはエラー。JSは大文字小文字区別ありのため、メソッド名は「alert」で記述しないといけない
            </script>
          </body>

JavaScriptはインタプリタ

JavaScriptは、スクリプトなのでインタプリタ型の言語である。そうするとインタプリタはどこにあるの？という疑問が出るかと思うが、インタプリタはWebブラウザ内にある。という事は、WindowsでもMacでもOS毎にインタプリタをインストールするなどは不要で、ブラウザがあればいい。つまり、ユーザは意識せずにJavaScriptを使う事ができる。

JavaScriptの文の終わりは「;」セミコロン

JavaScriptの文の終わりは「；」セミコロンをつける。これはC言語と同じだけど、JavaScriptはこのセミコロンを省略することができる。Webの記事とかを見るとつける派とつけない派みたいなのがあるようだけど、自分は「つける」に統一している。というか言語でつけるに統一した方がわかりやすいのでは？

DOMのおかげ

初期のJavaScriptは扱えるHTML要素は多くなかったが、DOM（Document Object Model）により、HTMLドキュメントの全てのタグや属性、CSSのプロパティを動的に変更することができるようになっている。
