if文で分岐

if文は、条件分岐を表現する構文ですが、これはWeb上でも使えます（当たり前）

以下のサンプルは、if文で表の要素の値を判定して0だったら在庫なしと表示するものです


          <head>
            ...
            <style>
              table { border: solid 1px red; }
              th, td { border: solid 1px red; }
              /* ストック表をデザインするCSS設定 */
              .nostock { color: red; font-weight: bold; }
            </style>
          </head>

          <body>
            <table>
              <thead>
                <tr>
                  <th>名前</th>
                  <th>バリュー</th>
                  <th>在庫</th>
                </tr>
              </thead>
              <tbody>
                <script>
                  let myDatas = [
                    { name: "りんご3", val: 8000, stock: 10 },
                    { name: "ばなな3", val: 4000, stock: 20 },
                    { name: "みかん3", val: 2000, stock: 0 },
                  ]
                  for (let lp = 0; lp < 3; lp++) {
                    document.write('<tr>');
                    document.write('<td>' + myDatas[lp].name + '</td>');
                    document.write('<td>' + myDatas[lp].val + '</td >');
                    //if文で在庫による表示を変更する
                    if (myDatas[lp].stock > 0) {
                      document.write('<td>' + myDatas[lp].stock + '</td >');
                    } else {
                //else側に来るのは在庫が0の場合。なので表をnostockクラスにして、
                //tdに在庫なしをマークアップすれば、在庫なしが表示された表になる
                      document.write('<td class="nostock">在庫なし</td >');
                    }
                    document.write('</tr>');
                  }
                </script>
              </tbody>
            </table>
          </body>
