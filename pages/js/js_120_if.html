if文

JavaScriptのifの構造は、他の言語のif文と同様で特別変わっている点は無いです（比較演算子が一部特殊）


          //if文の構造
          if (条件式1) {
            条件式1がtrueの場合の処理;
            …;
          } else if (条件式2) {
            条件式2がtrueの場合の処理;
            …;
          } else {
            条件式1 も 条件式2 も falseの場合の処理;
          }

if文の条件式

  • 比較演算子

    a < b a が b より小さい場合は、true

    a <= b a が b 以下の場合は、true

    a > b a が b より大きい場合は、true

    a >= b a が b 以上の場合は、true

  • 等価演算子

    JavaScriptの等価の比較は「等価演算子==」 と「厳密等価演算子===」 の2つがあります。この違いは型を意識する比較かどうかです。
    「等価演算子==」は、型を見ずに比較を行うので、例えば「数値の12」と「文字の12」を比較すると、trueになります。一方「厳密等価演算子===」は型も含めての比較なので、「数値の12」と「文字の12」の比較は falseです

    a == b a が b と等しい場合は、true

    a != b a が b と等しくない場合は、true

    
            let intNumber = 12;
            let strNumber = "12";
            console.log( intNumber == strNumber );    //この結果は「true」となる
  • 厳密等価演算子

    JavaScriptで普通の比較（他の言語で言う比較）は、「厳密等価演算子===」 を使うようにする

    a === b a が b と等しい場合は、true

    a !== b a が b と等しくない場合は、true

if文の複数の条件式（かつ、または）

条件式「()」の中に、&&かつ、||または で複数の条件をANDやORで指定することができる


        if (age >=10 && age <= 100) {
          console.log ("範囲内です");
        }
