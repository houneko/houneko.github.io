JavaScriptの関数：関数式（関数リテラル）

関数リテラル（関数式）とは

関数リテラル（または関数式）は、関数を変数や定数に代入して使うものです。JavaScriptは、関数もデータ型の1つなので、関数を変数や定数に代入することができます


          //関数リテラルの宣言
          //代入する関数名は不要（function Hoge(a,b) {...} と書かなくていい。Hogeを書いてもいい）
          const myAddFunction = function (a,b) {
            let c = a + b;
            console.log('結果 = ' + c);
            return c;
          };                  //関数を式として代入しているので、最後にセミコロンが必要

          //関数リテラルを実行（関数コール）
          console.log(myAddFunction(10,20));
          
          //実行結果
          > node .\test.js
          結果 = 30
          30

関数式（関数リテラル）の注意事項

  • constで関数式に関数を代入する場合、定数名はキャメルケースにする

    定数はスネークケースが一般的だけど、関数式の定数名は、アッパースネークではなくキャメルケースを使う

    JavaScriptでは、変数はキャメルケースで定数は、アッパースネークケースで書くのが一般的ですが、関数式（定数に関数を定義する）では、キャメルケースの定数名にします

  • 引数が無い場合もコールには「()」が必要

    関数式をコールする場合の注意点ですが、定数に関数を代入していてもコール時は「()」を付けて指定する。

    
              const hoge = function () {
                console.log("Hello");
              };
    
              hoge;     // この呼び出しは「間違い」
              hoge();   // これは正しい。引数が無くても「()」をつけて呼び出す
  • 関数式は、ホイスティングされない

    関数式は、ホイスティングされないので、関数式をコールするよりも前に関数定義（constに代入）しておかないといけないです
