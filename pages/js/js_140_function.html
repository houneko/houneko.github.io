JavaScriptの関数：functionキーワード

functionキーワードで関数宣言

JavaScriptの関数はいくつかの書き方があります。まずはfunctionキーワードで関数を定義する方法です


          // functionキーワードを使って関数を宣言する
          funnction 関数名 (引数1, 引数2,…) {
            関数の処理内容;
            ・・・
          }

          // 関数のコール
          console.log(関数名(arg1, arg2));

以下のtest.jsサンプルは、functionで myAdd関数を 定義している例です


          // 関数定義
          function myAdd(a, b) {
            return(a+b);
          }
          // 関数コール
          console.log(myAdd(10, 200));

          //node.jsで実行してみる
          > node .\test.js               // WindoesTerminalでnode.jsを使って、test.jsを実行
          210                               // 10, 200を渡した結果が表示されている

おまけ：ホイスティング（Hoisting）

JavaScriptの関数は、関数コールが関数宣言部より前にあっても問題ないです（例だと、console.log(myAdd(10,200));が先にあり、その後に、function 関数名(){...} があってもいいという事です）

この順番は、なんでかというとホイスティング（巻上げ）により、宣言部が前に巻上げされるからです。つまり「コール」「宣言」が、「宣言」「コール」になり、関数コール時に関数は認識済になるからです
