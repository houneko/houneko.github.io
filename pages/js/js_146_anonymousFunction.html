無名関数

無名関数とは

無名関数はその名の通り「関数名の無い関数」です。普通の関数はfunctionキーワードの後に関数名を設定しますが、無名関数の場合、functionキーワードの後に関数名がありません

無名関数のメリットは、関数名を考える必要が無いという事です。これは以外とメリットがあるようです（自分はそこまで、JSを使いこなしていないのであんまり実感が無いですが）。また、他の関数と名前が衝突することも気にしなくていいです

無名関数の誕生

JavaScriptは、変数に関数を代入することができます（関数リテラル）、そうすると以下のように関数名が必要になくなるケースが出てきます


  //関数定義
  function hoge(x, y) {
    return x + y;
  }
  //関数リテラル
  let myFunc = function hoge(x, y) {
    return x + y;
  }

この関数リテラルをコールする場合、もはや関数名は不要であることが分かります


  //関数リテラルをコール
  let result = myFunc(10, 20);  //関数名hogeはどこにも出てこない！じゃ、無名でいいやん
