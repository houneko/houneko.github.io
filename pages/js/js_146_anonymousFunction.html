メソッド

メソッドとは

メソッドの実体は関数ですが、オブジェクトの中で定義されている点が関数と違います


  let obj = {
    プロパティA: 値,
    プロパティB: 値,
    ・・・
    プロパティX: 関数     ← メソッド：キーに対して値が関数となっているもの
  }

メソッドの定義と呼び出し方法

メソッドの定義は、上述した通りキーに対する値として関数を定義します。メソッドはオブジェクトのメンバでもあるので、プロパティの参照と同様に「.（ドット）」でメソッド名を指定します

注意点として、メソッドは引数が無くても()が必要です


  //myobjオブジェクト内にshowHelloというメソッドを定義
  //以下の例は、メソッドをfunction()でし定義ています
  const myobj = {
    showHello: function() {
      console.log('Hello, World!');
    }
  };
  //メソッド呼び出し
  myobj.showHello();    //←メソッドmyobj.showHello()呼び出し。引数が無い場合も()が必要

  //実行結果
  //Hello, World!

メソッドは、function()以外にアロー関数 で定義することもできます


  //myobjオブジェクト内にshowHelloというメソッドを定義
  //以下の例は、アロー関数で定義しています
  const myObj = {
    showHello2: (myName) => {          //←アロー関数で定義
      console.log('Hello, ' + myName);
    }
  };

  //const my = new myobj;
  myObj.showHello2('Neko');   //←メソッドmyObj.showHello2()呼び出し。引数がある例

  //実行結果
  //Hello, Neko   //←引数が表示に使われている

値を返すメソッド

メソッドの実体は関数なので値を返すこともできます。つまり、値を返すメソッドを定義することも可能です（当たり前やろ。。）


  //myObj内にメソッドを定義
  const myObj = {
    calcPow: (value) => {
      return value * value;     // ←引数でもらったvalueを二乗して返している
    }
  };
  //メソッド呼び出し
  console.log(myObj.calcPow(20));
  //実行結果
  //400   //20*20

メソッドの退縮記法

上の方では、メソッドの定義は「プロパティ：funciton() {...｝」と書いていましたが、プロパティを作らず書くこともできます。この書き方の方が簡潔かと思います


  //プロパティを使ったメソッドの書き方
  const myobj = {
    showHello: function() {           //showHelloというプロパティに値としてfunction(){}を定義している
      console.log('Hello, World!');
    }
  };

  //短縮記法
  const myobj = {
    showHello() {                     //プロパティはなく、showHello()を定義している
      console.log('Hello, World!');
    }
  };

メソッドチェーン

メソッドチェーンは、メソッドを繋げて書くことで、次々とメソッドを実行する方法です。PowerShellのパイプのようなイメージで、メソッド1を実行した結果を次のメソッド2で実行します。

メソッドチェーンは、メソッドを続けて実行する時のための書き方という事だと思います（メソッドチェーンで書けば各メソッドをバラバラで呼び出す書き方よりも簡潔に書けるってこと）

注意点としては、各メソッドは「this」を返す必要があります。もしくは次のメソッドが実行できるオブジェクトが返されていないといけないです。つまりmethodAの戻り値のオブジェクトhogeが、methodBメソッドを持っていないといけないです（hoge.methodBが実行できる） 


  //メソッドチェーンの書き方
  obj.methodA().methodB().methodC();

メソッドチェーンを使わずにmethodA～methodCを実行する場合


  const resultA = obj.methodA();
  const resultB = resultA.methodB();    //methodBは、Aの結果オブジェクトで実行
  const resultC = resultB.methodC();    //methodCは、Bの結果オブジェクトで実行
