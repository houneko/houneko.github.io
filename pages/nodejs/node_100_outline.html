node.jsって何

node.jsは何か？という問いに対して、node.jsはJavaScriptを実行するためのランタイム環境と言えると思います

もともとJavaScriptは、ブラウザ上で動く言語でしたがnode.jsにより独立したプログラムとして実行できるようになりました。なので、JavaScriptの勉強もコマンドラインからnodeで実行すると便利です（Web上の操作をするJavaScriptはブラウザで実行しますが、JavaScriptの単体でのスタディはnodeでやった方が便利。例えば、console.logで何かの実行結果を表示する場合でも、nodeならコマンドラインに結果が表示されるけど、ブラウザでは開発者ツールを起動してみないといけないなどです）

インストール

インストールは、nodejs.orgから、自分のPC(OS)にあったものをDLしてインスールすればいいです（インストール手順は割愛します）。インストール後は、-vでバージョンが表示されれば成功です 


          > node -v
          v14.2.0

偶数バージョンと奇数バージョン

node.jsでは、偶数バージョンと奇数バージョンに意味を持たせており、偶数バージョンが安定版、奇数バージョンが新機能を取り込んだものとなっています。通常使う場合は、偶数バージョンを使えばいいと思います

node.jsの実行と終了

node.jsはコマンドラインから実行するプログラムです。Windowsの場合は、WindowsTerminal（またはCmdやPowershell）を起動して、nodeとタイプしてリターンキー。これでnode.jsが起動します

これで、node.jsのプロンプトが表示され、JavaScriptの文を入力できるようになります。終了は「.exit」でコマンドラインに戻ります


          > node
          Welcome to Node.js vxx.xx.x.
          Type ".help" for more information.
          >             # これがnode.jsのプロンプト

          #// JavaScriptを実行
          > console.log("Neko");
          Neko
          undefined

          #// node.jsの終了
          > .exit

OneDrive上のコードとnode.jsの注意点

自分の環境は、ソースコードはOneDrive上に置いておりそこで編集しています。そうした場合、node.jsがうまく実行してくれない時があります。これはOneDrive上でのコードがnode.js実行時に同期ができてないなどがあるからだと思います

なので、node.jsが動かない時は、コードがOneDriveなどのクラウドに置いて無いかを確認するのが１つのポイントです

以下のサンプルコードは、変数の型を表示するだけのものですが、最初OneDrive上にhoge.jsとして格納しておきnode.jsで実行しても何も表示されませんでした。何が間違いかなかなか分からず悩んだ事があります。このコード自体は問題がなく、node.jsも対話モードで実行するとちゃんと動くので問題はOneDrive上に置いていたからでした。ローカルドライブに移すとちゃんと動作しました 


          let myVal = 'Neko';
          console.log('typeof = ' + typeof(myVal));
