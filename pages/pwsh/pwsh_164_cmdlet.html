Cmdlet（コマンドレット）

Cmdlet（コマンドレット）とは

PowerShellはCUIなので、コマンド（PowerShellではコマンドレットという）で操作することになります。じゃ、コマンドレットって何なん？ということになりますが、これはPowerShellに何かをさせるためのキーワードです。例えば「Get-ChildItem」というコマンドレットを入力するとそのディレクトリ一覧が表示されるということです。 


        > Get-ChildItem

        Mode          LastWriteTime         Length Name
        ----          -------------         ------ ----
        d----         yyyy/mm/dd    hh:mm          work        ← ディレクト（workディレクト）が1つと
        -a---         yyyy/mm/dd    hh:mm     1230 hoge.txt    ← hoge.txtが1つあることがわかる

コマンドレットが返すものはオブジェクト

PowerShellがいいのはオブジェクト指向になっていること。このため、コマンドレットが返すものは.NETのオブジェクトになっています

例：Get-Dateコマンドレット

Get-Dateの結果がどういう型であるかは「.GetType()」メソッドで調べる事ができる。というかメソッドがある時点でオブジェクトが返って来ていることが明白。(Get-Date).GetType()で確認する 


        #// 日付時刻データが返ってくるが、これはテキストではなくオブジェクトが返って来ている
        > Get-Date
        YYYY年MM月DD日 hh:mm:ss 
        
        #// Get-Dateが返してくるオブジェクト型を調べてみる
        #// DateTime型（System.DateTime）であることが分かる
        > (Get-Date).GetType()
        IsPublic IsSerial Name        BaseType
        -------- -------- ----        --------
        True     True     DateTime    System.ValueType

Get-Dateの結果は「System.DateTime」型のオブジェクトが返って来ている事がわかったので、次にこの型が持っているメソッドやプロパティはどんなものがあるか調べてみる。PowerShellには、どんなメンバがあるかを調べるためのコマンドレットがあり「Get-Member」で調べることができる。

以下の例のように多数のメソッドやプロパティがあることが分かる。例えば、Monthプロパティというのがあり、int Monthが返ってきそうなプロパティであることが想定できる。


        > Get-Date | Get-Member

          TypeName: System.DateTime     ← System.DateTime型であることがわかる

        # メソッドやプロパティが多数あることが分かる
        Name                 MemberType     Definition
        ----                 ----------     ----------
        Add                  Method         datetime Add(timespan value)
        AddDays              Method         datetime AddDays(double value)
        ...
        GetType              Method         type GetType()
        ...
        ToString             Method         string ToString(), string ToString(string format), ...
        ...
        Month                Property       int Month {get;}
        Second               Property       int Second {get;}
        ...

例えば、上記でMonthプロパティというのがあるのが分かったので、試してみる


        > (Get-Date).Month
        # 今1月として、Monthプロパテの値である1が返ってきている
        1

        # スタティックメソッド InvariantCulture()で、1月を英語表示に変えて表示する
        > (Get-Date).ToString("MMMM", [System.Globalization.CultureInfo]::InvariantCulture)
        January

オブジェクトが返って来ているので、このように必要なプロパティを取得したり、メソッドを使って加工したり、いろいろ自由度の高い処理ができる
