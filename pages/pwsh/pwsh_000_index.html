  2. PowerShellの変数

    PowerShellの変数は3つのタイプがある（自動変数、環境設定変数、ユーザ変数）

    1. 自動変数

      自動変数は、PowerShellが自分で作り各情報を設定している変数。自動変数はユーザが変更したりすることをはできない （書き換えた場合動作は保証されない）

    2. 環境変数

      PowerShellの環境変数は、自動変数の一種ですがプログラマが値を設定することができます

    3. ユーザ変数

      ユーザが自由に作成、設定できる変数です（以上）

    PowerShellの演算子（算術演算子、論理演算子、比較演算子、範囲演算子、置換演算子、型演算子、包含演算子）について書いています。書式演算子を追加しました。書式演算子「-f」を使えば桁数調整や基数変換して表示などが簡単にできます

  5. パイプ（パイプライン）

    PowerShellでは、1つのコマンドレット結果をパイプで次のコマンドレットに渡すことができます。パイプ機能により複雑な処理ができます

  3. PowerShellでやりたい事を実現させるには★大事

    Powershellで何かを行う場合、Cmdlet（コマンドレット）で操作をすることになりますが、じゃ今自分がしたい事を実現するCmdlet（コマンドレット）は何なのか？どうやって見つけるのか？といった最初の壁を乗り越えないと、一気にやる気がなくなると思います。
    各自で自分のやり方を確立していけばいいと思うけど、自分はこんな感じで習得していったという話です

  4. Get-Helpコマンドレット

    Get-Helpは、コマンドレットを調べるためのコマンドレット

  5. Get-Commandコマンドレット

    Get-Commandは、コマンドレットを表示するコマンドレット。だけど、対象はPowerShell内のコマンドレットだけではなく、自作の関数・スクリプト、外部アプリケーションも対象となっており実はいろいろ使えるコマンドレット

  6. Get-Memberコマンドレット

    Get-Memberは、他のコマンドレットが返すオブジェクトがどのようなプロパティやメソッドを持つかを調べるためのコマンドレット

  7. Get-Alias

    コマンドレットは動詞-名詞の形に統一されているから分かりやすいが、過去のコマンド名で使いたい場合などへの対応としてAlias名があります

  8. Out-Hostコマンドレット

    Out-Hostは、画面表示量をコントロールする時に使うコマンドレット（他の使い方もあるかもしれないけど自分はほぼこの使い方だけ）。Cmd.exeの「-More」と同じような使い方

  9. Out-Null

    Out-Nullは通常前段のコマンドレット結果（Obj）をパイプで受け取りそれを捨てる動作を行う。何でこれが必要かをまとめています

  10. Write-Host

    Write-Hostは画面表示するコマンドレット。実行中の状況を表示したりする使い方をした時のメモ

  11. Get-Verb

    Get-Verbは、Microsoft承認済みの動詞の一覧を表示する。PowerShellでは承認されている動詞があるので自作スクリプトを作る場合のスクリプト名はこの承認されている動詞から選ぶようにするのがいい（それがPowerShellの文化に則った運用やろ）

  12. Measure-Command

    Measure-Commandは、処理時間を測定するコマンドレットです。コマンドやスクリプトファイル、外部コマンドなどいろいろな処理の時間を計れます
    また、自分が自作スクリプトでよく書く方法ですが、Get-Dateを使う方法も書いています

  13. Get-CimInstance

    Get-CimInstanceは、Get-WmiObjectの後継コマンドレットです。指定したクラスのCIMインスタンスを取得します
    このコマンドレットは単独で使うのでは無く引数にクラスを指定して使います
    Get-WmiObjectは、Windows専用なので、pwshではサポートしていない

  14. ForEach-Object

    間違いやすいかもしれませんが ForEach-Objectは、パイプライン用のコマンドレットです。ForEachループ的な動作はしません

  1. コマンドレットオプションの色に関する問題

    コマンドラインで、コマンドレットのオプションをつけて指定する時、デフォルトだとオプションの色が背景色に近いため見にくいです

  2. Get-ChildItemの「-Exclude」オプション

    Get-ChildItem の「-Exclude」オプションは意図した動作にならないことがあります

  3. Windows PowerShellにおける$DebugPreferenceとWrite-Debug問題

    [CmdletBinding()]で高度化した時のWindows Powershell とPowerShell Coreでは、$DebugPreferenceの値が異なる。このため、Windows Powershell環境では、Write-Debugの度に「この操作を実行しますか？」という確認メッセージが出たという問題。PowerShell Coreではこの問題は起きないけど、社内の環境はWindows Powershellなので問題が顕在化

  4. ZoneID問題

    ZoneIDは、WindowsXp SP2以降に導入された概念で、ファイルにZoneIDというセキュリティ情報をもたせて、インターネットから入手したファイルかどうかを判断できるようにしている仕組みです

  5. Get-Content結果をWrite-Hostで表示すると意図しない結果になる

    Get-Contentでファイルをリードして、その結果をWrite-Hostで表示すると1行になって表示されてしまう。この原因と回避方法を説明しています
