Get-Command

Get-Gommandとは

Get-Commandは実は便利なコマンドレット。Get-CommandはPowerShellが提供しているコマンドレットだけではなく、自作関数・スクリプト、外部アプリケーションも対象としています。このため、コマンドレットや関数・スクリプト、外部アプリケーションを探すという使い方もできます

引数無しで、Get-Commandを実行するとPowerShellが持っているコマンドレットや関数、Aliasなどが一覧表示される。大量に表示されるので、一画面ずつ見たいは場合は「Out-Host -Paging」 で見ることができる


        > Get-Command
        #出力結果（大量に表示され画面がスクロールする）
        CommandType     Name                            Version    Source
        -----------     ----                            -------    ------
        Alias           Add-AdlAnalyticsDataSource      1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlAnalyticsFirewallRule    1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlStoreFirewallRule        1.3.1      Az.DataLakeStore        
        ...
        ...

「CommandType」について

Get-Commandを実行すると表示される項目に「CommandType」というのがありますが、CommandTypeでは以下の情報を表示しています

  • CommandTypeの意味

    Get-Commandを実行すると表示項目に「CommandType」が表示されるます。この意味は以下の通りです。

    値 意味 備考
    Alias エイリアス
    Function 関数
    Cmdlet コマンドレット
    Filter フィルタ
    Script PowerShellスクリプト
    Application アプリケーション
    Workflow ワークフロー
    ExternalScript Pathにある外部スクリプト
  • CommandTypeで種類を指定してGet-Commandを実行する パート1

    Get-Commandのオプションで「-CommandType」を指定し、値を「ExternalScript」にすると外部スクリプトだけを表示することができます。

    以下は実行結果サンプル。これを見ると自分が作った自作スクリプトも、外部からインストールしたスクリプトも外部スクリプトとして見えていることが分かる

    
            > Get-Command -CommandType ExternalScript    # ExternalScriptだけを表示するようにする

            CommandType     Name                  Version    Source
            -----------     ----                  -------    ------
            ExternalScript  Check-HtmlFiles.ps1               C:\..\Check-HtmlFiles.ps1                     # ←自作スクリプト
            ExternalScript  Check-ShowSnippetsPS1.ps1         C:\..\Check-ShowSnippetsPS1.ps1               # ←自作スクリプト
            ExternalScript  gemini.ps1                        C:\Users\xxx\AppData\Roaming\npm\gemini.ps1   # ←外部から来たスクリプト
            ...
            ...
  • CommandTypeで種類を指定してGet-Commandを実行する パート2

    「-CommandType」オプションは外部スクリプトは指定値「ExternalScript」があるけど、関数は「Function」しかない。このため自作関数を調べようとしても「Function」には内部Functionも多数あるからこのままだと見にくい

    PowerShellはパイプで次のコマンドにオブジェクトを渡せるので、Where-Objectでフィルタする

    
            > Get-Command -CommandType Function | Where-Object {$_.Name -like "*isad*"}

            CommandType     Name                  Version    Source
            -----------     ----                  -------    ------
            Function        isAdmi                                              # ←自作関数の「isAdmi」が表示された
            ...
            ...
  • CommandTypeでApplicationを指定すると外部アプリも表示できる

    Get-Commandは、PowerShell内のコマンドレットだけを対象としていないので（ナイスな設計）、カレントPCにインストールされているアプリケーション（実行ファイル）も表示させることができる。

    このアプリケーションはパスが通った所にあるExeやCom、bat（com）などが対象となる（なのでExcelとかは表示されない）

    以下の例は自作のcalen.exeを表示させたところ

    
            > Get-Command -CommandType Application | Where-Object {$_.Name -like "cal*"}
            CommandType     Name                                               Version    Source
            -----------     ----                                               -------    ------
            Application     calc.exe                                           10.0.2610… C:\WINDOWS\system32\calc.exe
            Application     calen.exe                                          0.0.0.0    C:\WINDOWS\system32\calen.exe

Get-Commandで表示する項目を変更する方法

Get-Commandを実行するとデフォルトでは、CommandType、Name、Version、Sourceが表示されていますが、これを変更することができます

変更方法

  1. まずは、パイプでGet-Memberに渡して表示できる項目を調べる

    Get-Help Get-Commandで調べる方法もあるけど、Get-Memberでプロパティを表示させる方法もある。

    
            > Get-Command | Get-Member -MemberType Proper*
            Name                MemberType     Definition
            ----                ----------     ----------
            CommandType         Property       System.Management.Automation.CommandTypes CommandType {get;}
            Definition          Property       string Definition {get;}
            Description         Property       string Description {get;set;}
            Module              Property       psmoduleinfo Module {get;}
            ModuleName          Property       string ModuleName {get;}
            Name                Property       string Name {get;}
            ...
            ...
  2. Select-Object で項目を指定する（パイプでSelect-Objectに渡して指定する）方法

    Select-Object 項目1, 項目2, … のように表示したい項目をカンマで区切って指定する

    以下は、NameとVersionだけ表示させるようにした例。表示順はVersion, Nameで表示させる

    
            > Get-Command | Select-Object Version, Name | Out-Host -Paging
            Version Name
            ------- ----
            1.0.3   Add-AdlAnalyticsDataSource
            1.0.3   Add-AdlAnalyticsFirewallRule
            1.3.1   Add-AdlStoreFirewallRule
            1.3.1   Add-AdlStoreItemContent
            ...
            ...
  3. Select-Object 以外の方法もある

    Format-Table で項目をカンマで区切って指定する方法

    以下は、NameとVersionだけ表示させるようにした例。表示順はVersion, Nameで表示させる

    
            > Get-Command | Format-Table Version, Name -Autosize | Out-Host -Paging
            Version Name
            ------- ----
            1.0.3   Add-AdlAnalyticsDataSource
            1.0.3   Add-AdlAnalyticsFirewallRule
            1.3.1   Add-AdlStoreFirewallRule
            1.3.1   Add-AdlStoreItemContent
            ...
            ...

Get-Commandで特定のコマンドを表示する

Get-Commandだけを実行すると全部のコマンドレットや関数などが表示されるが、特定のコマンドレットだけを表示させることもできる

  • 指定したコマンドレットだけを表示する方法 
    
            #Get-Commandの後にスペースでコマンドレット名Hogeを指定。
            #このコマンドレット名Hogeは、Get-Commandの引数に相当するのでパイプで指定しない
            > Get-Command Get-Process

            #指定したコマンドレットだけ表示された
            CommandType     Name            Version    Source
            -----------     ----            -------    ------
            Cmdlet          Get-Process     7.0.0.0    Microsoft.PowerShell.Management
  • ワイルドカードで指定することも可能 
    
            > Get-Command Get-Pro*

            #Get-Proで始まるコマンドレットだけ表示された
            CommandType     Name                                               Version    Source
            -----------     ----                                               -------    ------
            Alias           Get-ProvisionedAppPackage                          3.0        Dism
            Alias           Get-ProvisionedAppSharedPackageContainer           3.0        Dism
            Alias           Get-ProvisionedAppxPackage                         3.0        Dism
            Cmdlet          Get-Process                                        7.0.0.0    Microsoft.PowerShell.Management
            Cmdlet          Get-ProcessMitigation                              1.0.12     ProcessMitigations
            Cmdlet          Get-ProvisioningPackage                            3.0        Provisioning
  • ワイルドカードではなくPowerShellっぽい指定も可能 
    
            > Get-Command -Verb Get | Out-Host -Paging
            #動詞部が「Get」のものが表示されている
            CommandType     Name                                               Version    Source
            -----------     ----                                               -------    ------
            Alias           Get-AdlAnalyticsAccount                            1.0.3      Az.DataLakeAnalytics
            Alias           Get-AdlAnalyticsComputePolicy                      1.0.3      Az.DataLakeAnalytics
            Alias           Get-AdlAnalyticsDataSource                         1.0.3      Az.DataLakeAnalytics          
            ...
            ...

            #同時に名詞部も指定してみる。名詞部は「Pro*」で指定した例
            > Get-Command -Verb Get -Noun Pro* | Out-Host -Paging
            CommandType     Name                                               Version    Source
            -----------     ----                                               -------    ------
            Alias           Get-ProvisionedAppPackage                          3.0        Dism
            Alias           Get-ProvisionedAppSharedPackageContainer           3.0        Dism
            Alias           Get-ProvisionedAppxPackage                         3.0        Dism
            Cmdlet          Get-Process                                        7.0.0.0    Microsoft.PowerShell.Management
            Cmdlet          Get-ProcessMitigation                              1.0.12     ProcessMitigations
            Cmdlet          Get-ProvisioningPackage                            3.0        Provisioning
