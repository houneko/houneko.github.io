PowerShellのSwitch文

PowerShellにもSwitch文がある。Switch文は、他の言語と同様にif文の分岐が多数になる場合などで使うと可読性や保守性の高いコードを書くことができる。また、PowerShellのSwitch文は、例えばC言語のswitch～case文よりも高機能となっている

switch文の基本的な書式は、他の言語だいたい同じだけど、Case文は不要（存在しない）。また、breakは必要となっている


          # Switch文の基本形
          switch (評価式) {
            値1 { 処理1; break }  # PowerShellのswitch文は、Caseは無い。breakは必要
            値2 { 処理2; break }
            値3 { 処理3; break }
            ...
            Default {処理}
          }

サンプルコード
このサンプルコードは、評価式の$seasonの値が2で、分岐する値は2が2つ定義されている。この場合、最初のケースがヒットして評価される。breakが無ければ次の「2」にもヒットする 


        $season = 2
        switch ($season) {
          0 { Write-Host "春です" ; break }
          1 { Write-Host "夏です" ; break }
          2 { Write-Host "秋です" ; break }
          2 { Write-Host "It's autumn." ; break }
          3 { Write-Host "冬です" ; break }
          Default { Write-Host "四季ちゃうやん" ; break }
        }	
        #実行結果
        秋です

Switch文のいろいろなオプション

switch文には、いろいろなオプションがありswitchの挙動を変えることができる。こういうのはC言語にはない（と思う）

  • -CaseSensitiveオプションによる大文字小文字区別での分岐判定

    switch文に -CaseSensitiveオプションをつけると、大文字小文字を区別した分岐判定になる

    
            $lang = "PowerShell"	
            switch -CaseSensitive ($lang) {	                  # -CaseSensitiveオプションにより大文字小文字が区別される
              "powershell" { Write-Host "small case" ; break }    # 小文字なのでヒットしない
              "POWERSHELL" { Write-Host "large case" ; break }    # 大文字なのでヒットしない
              "PowerShell" { Write-Host "mix case" ; break }      # このケースにヒットする
              Default { Write-Host "no-hit" ; break }	
            }	
            #実行結果
            mix case
  • -Wildcardオプションによるワイルドカードでの分岐判定

    switch文に -Wildcardオプションをつけるとワイルドカードでの分岐判定になる。以下のサンプルは「-CaseSensitive」と「-Wildcard」オプションの両方をつけている。オプションは複数つけることができる

    
            $lang = "PowerShell"
            switch -CaseSensitive -Wildcard ($lang) {   # -CaseSensitive と -Wildcardオプションがついている
              "p*" { Write-Host "p で始まる" ; break }  # p* だけど大文字小文字の区別をするのでヒットしない
              "*L" { Write-Host "L で終わる" ; break } 
              "P*" { Write-Host "P で始まる" ; break }  # P*なのでヒットする
              Default { Write-Host "no-hit" ; break }
            }
            #実行結果
            P で始まる
  • -FIleオプションをつけると評価式にファイルを指定できるようになる

    ※ファイルの1行ずつが$_に読み込まれるそれを評価式として値とswitch比較する

    
            $mycmd = @()
            Get-Command | Select-Object Name > hoge_switch.txt   # Get-Command | Select Nameでコマンド名だけを hoge_switch.txtに書き出す
            switch -Wildcard -File ".\hoge_switch.txt" {
              "Get-A*" { $mycmd += ($_ + "`n")}     # Get-A*というコマンド名のものを mycmdバッファに追記する
            }
            Write-Host "Get-A* Cmdlet = ", $mycmd.Count   # Get-A* のコマンド名のものの数
            Write-Host "Get-A* Cmdlet are ", `n , $mycmd  # Get-A* のコマンド名を表示
            
            #実行結果
            Get-A* Cmdlet = 23	
            Get-A* Cmdlet are 	
            Get-AppPackage
            Get-AppPackageDefaultVolume
            Get-AppPackageLastError
            Get-AppPackageLog
            Get-AppPackageManifest
            Get-AppPackageVolume
            ・・・
