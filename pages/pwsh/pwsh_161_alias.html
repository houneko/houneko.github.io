Alias（エイリアス）

Get-Alias

Aliasとは

PowerShellのコマンドレットは、動詞-名詞の書式となってわかりやすいですが従来のコマンドに比べて長くなります。また、従来のコマンドに慣れている人にも使いやすいようにエイリアスが用意されています

例）Get-ChildItemは、Dirやlsでも同じ動作になる。このDirやlsがAlias名。Dos環境の人にはDir、Unix環境の人にはlsが馴染みやすい と思います

Alias名の順引きと逆引き

Alias名の調べ方は、コマンドレットのAlias名を調べる方法と、Alias名から対応するコマンドレット名を調べるので異なる（同じやり方にして欲しかった。。）

どちらもGet-Aliasの結果をWhere-Objectでフィルタする方法で覚えた方が統一感があっていいかも

  • コマンドレットのAlias名を調べる

    Get-Alias の結果をパイプで、Where-Objectに渡して、キーワードでフィルタする

    Get-Alias | Where-Object {$_.Definition -like "キーワード"}

    
            PS > Get-Alias | Where-Object {$_.Definition -like "Get-Child*"}
            結果）
            #// 以下のようにGet-ChildItemのAliasは、dir、gci、lsの3つあることがわかる
            CommandType     Name                        Version    Source
            -----------     ----                        -------    ------
            Alias           dir -> Get-ChildItem
            Alias           gci -> Get-ChildItem
            Alias           ls -> Get-ChildItem
  • Alias名からコマンドレット名を逆引きする

    こっちは単純に、Get-Alias エイリアス名 でいい

    Where-Objectを使ってフィルタして調べる方法も可能。「Get-Alias | Where-Object {$_.Name -like "ls"}」

    
            PS > Get-Alias ls
            結果）
            #// Alias名の「ls」は、Get-ChildItemのことだとわかる
            CommandType     Name                        Version    Source
            -----------     ----                        -------    ------
            Alias           ls -> Get-ChildItem

            PS > Get-Alias | Where-Object {$_.Name -like "ls"} でも同じ結果を得ることができる

Alias名の調べ方

$_.Definition は、パイプで渡された$_の「Definition」プロパティを見ているということ。どうやってこの考えになったかの流れ

  1. Get-Aliasが持っているメンバを調べ、使えそうなプロパティを試してみる

    この結果は以下のようになっている。ここで各プロパティの説明を見て「Definition」プロパティが使えそうとわかる

    
            PS > Get-Alias | Get-Member -MemberType Property
            結果）
            Name               MemberType Definition
            ----               ---------- ----------
            CommandType        Property   System.Management.Automation.CommandTypes CommandType {get;}
            Definition         Property   string Definition {get;}        #// get; したStringってことかな。何か使えそう
            Description        Property   string Description {get;set;}
            Module             Property   psmoduleinfo Module {get;}            
            ...                ...
  2. $_.Definitionを表示させてみる 
    
            PS > Get-Alias | Where-Object {$_.Definition -like "Get-Child*"}
            CommandType     Name                        Version    Source
            -----------     ----                        -------    ------
            Alias           dir -> Get-ChildItem
            ...             ...

しかし、全く見当がつかない場合もあると思う。その場合は気になるプロパティをSelect-Objectで選んで表示させてみる

以下の例は、NameプロパティとDefinitionプロパティを選んで表示させてみた結果


        PS > Get-Alias | Get-Member -MemberType Property
        結果）
        #// これを見ると、NameプロパティはAlias名、Definitionプロパティはコマンドレット本名を表していることがわかる
        Name    Definition
        ----    ----------
        ?       Where-Object
        %       ForEach-Object
        ac      Add-Content
        cat     Get-Content
        cd      Set-Location
        ...
