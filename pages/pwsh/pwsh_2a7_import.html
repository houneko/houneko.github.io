公開した関数を使う方法

公開した関数を使う方法

公開した関数は、コマンドラインからあたかも新しいコマンドのように使ったり、別のスクリプト内にImport-Moduleして取り込んで使うことができます（だからモジュール化すると便利）

とりあえず、自分の環境にMy.Hardware.Memoryというモジュールを作り「Get-MyMemoryInfo」という関数を公開設定したとします。「Get-MyMemoryInfo」関数は、今のシステムのメモリ情報を取得して表示する関数です

  1. My.Hardware.Memory.psd1マニフェストファイルで公開する 
    
              @{
                .....
                RootModule        = 'My.Hardware.Memory.psm1'       #// RootModuleでモジュールファイルを示す  
                FunctionsToExport = @(                              #// 公開する関数はfunctionsToExportキー（配列）で
                  'Get-MyMemoryInfo',                               #// 指定する
                  'Get-MyMemoryUsage'
                )
              }
  2. Import-MyModules.ps1ファイルを作成（これは自分の環境の場合）

    自分のモジュールファイルを格納しているフォルダパスを「$moduleRoot」変数に設定して、そのフォルダ配下のディレクトリ一覧をGet-ChildItemで取得する。このディレクト内にある「psd1」ファイルをImport-Moduleする 

    
              #// 自分の環境のモジュールフォルダを変数に代入しておく
              $moduleRoot = 'C:\My\MyCmd\myModules'
              #// そのフォルダ配下の「psd1」ファイルを全部1つずつ「Import-Module」でインポートする
              Get-ChildItem $moduleRoot -Directory | ForEach-Object {
                $psd1 = Join-Path $_.FullName "$($_.Name).psd1"
                Write-Debug ("import file = $psd1")
                if (Test-Path $psd1) {
                  Import-Module $psd1 -Force      #// 各psd1ファイルをインポートする
                }
              }
  3. $Profileを実行する

    「Import-MyModules.ps1」ファイルを実行すれば、このスクリプト内で全部のpsd1ファイルをImport-Moduleするので各モジュールの公開関数がインポートされる

    だけど、もっと汎用的な仕組みをプロファイル に作っているので、コマンドラインから「.$Profile」を実行すればいい

    
              #$Profile
              #// プロファイル内で Import-MyModules.ps1 を実行しているので各公開関数がインポートされる
              $loadMyModules = Join-Path $developScriptsFolder "Import-MyModules.ps1"
              . $loadMyModules

コマンドラインから使う方法

上記のような仕組みができているので、新しく公開関数を作成したら「psd1ファイルで公開設定し、$Profileを実行する」だけでいいです


          > .$Profile            #// プロファイルの実行
          $gt; Get-MyMemoryInfo     #// コマンドのように呼び出せるようになっている！

別のスクリプトに取り込んで使う方法

hoge.ps1というスクリプトからGet-MyMemoryInfo関数を使いたい場合、Import-Moduleでこのスクリプトに公開関数のモジュールをインポートします（これでそのモジュールが公開している関数がコールできるようになる）

参考情報

インポートのパスは、「配布」を考えてPSModulePathを使わないようにする

モジュールのデバッグ


          #// hoge.ps1
          [CmdletBinding()]
          Param()

          #// [CmdletBinding()]、Param()の後にImport-Moduleで取り込む
          $thisModuleRoot = Join-Path (Split-Path $PSScriptRoot -Parent) "myModules"
          Import-Module (Join-Path $thisModuleRoot "MY.Hardware.Memory\My.Hardware.Memory.psd1")

          #// call Get-MyMemoryInfo
          #// 関数コールの引数に「-Debug」を付けているとコマンドラインからデバッグできるので付けておく
          Get-MyMemoryInfo -Debug:$PSBoundParameters.ContainsKey('Debug')

Import-Module時の注意事項

  • モジュール内容が変更されてもリロードされない

    インポートするモジュール（関数）を修正しても使う側は自動でリロードされないので、もう一度インポートする必要があります。この時、一度インポートしていた場合、Import-Moduleしても取り込まれない場合があるので「-Force」オプションで強制的にインポートしなおすようにします

  • インポートするのは直下のパスだけ

    モジュールパス直下にフォルダが無く、さらに深いフォルダにモジュールがある場合、見つけられずエラーになる。つまりモジュールパスは再帰的に検索しないという事です

    
              # 以下のフォルダ構成は[OK]          # 以下のフォルダ構成はだめ
              モジュールパス                      モジュールパス
                ├ モジュールA                       ├ Utilty
                │   ├ psm1ファイル                 │   ├ モジュールA
                │   └ psd1ファイル                 │        ├ psm1ファイル
                ├ モジュールB                       │        └ psd1ファイル
                │   ├ psm1ファイル
                │   └ psd1ファイル
