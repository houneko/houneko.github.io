Get-CimInstance

Get-CimInstanceとは

Get-CimInstanceは、CIM（Common Information Model）を通してWindowsの内部情報を取得することができます。かなりいろいろなクラスがあり様々な情報が取得できます。詳細はGet-Helpで見てみてください

CIMとWMI

CIM（Common Information Model）とは、WMI（Windows Management Instrumentation：これもCIMベースで作られたWindows仕様モデル）の後継の概念モデルで、PCやハードウェアの個別な情報を共通の形で表現した仕様・仕組みです

CIMは、DMTFという団体が策定した標準仕様であり、Windowsだけのための仕様ではないです。Windows PowerShellでは、WMIを使うケースがありましたが、現在はCIMが推奨されています

Get-CimInstanceと同じようなコマンドレットで、Get-WmiObjectがありますがPowerShell Coreではサポートされていないです。Get-CimInstanceは、Windows PowerShellでもサポートされています

つまり、Windows PowerShellでも、PowerShell Coreでも「WMI系」のコマンドレットではなく「CIM系」のコマンドレットを使う方がいいです

Get-CimInstanceの使い方

Get-CIMInstanceは、かなりオプションがあります。また各オプションで指定する値も多数あり全部を覚えることはしなくてもいいです（極めたらすごい）。取得したい情報が新たに出てきた時にその部分だけ追加で覚えていけばいいかなと思います 


        > Get-CimInstance -ClassName ここでCtrl+Space
        1204 個の候補をすべて表示しますか? (y または n) _     ← -ClassNameで指定できる値が1000以上あり確認メッセージが出ている
        ...
        Win32_OnBoardDevice                   ← いろいろなおもしろそうな情報が取れるっぽい
        Win32_OperatingSystem
        Win32_OperatingSystemAutochkSetting
        ...

        # Win32_OperatingSystem クラスを指定してこのCIM情報を取得してみる
        > Get-CIMInstance -ClassName Win32_OperatingSystem
        # デフォルトで取れるのは以下の項目
        SystemDirectory     Organization BuildNumber RegisteredUser   SerialNumber    Version
        ---------------     ------------ ----------- --------------   ------------    -------
        C:\WINDOWS\system32              xxxx        houneko.xx       xxx-xxx-        10.0.26200
        # Get-Memberで他にどんなものがあるか調べてみる
        > Get-CIMInstance -ClassName Win32_OperatingSystem | Get-Member
        # Win32_OperatingSystemクラスの情報は以下のようなものがあることが分かる
        Name                                      MemberType  Definition
        ----                                      ----------  ----------
        ...
        InstallDate                               Property    CimInstance#DateTime InstallDate {get;}
        ...
        > Get-CIMInstance -ClassName Win32_OperatingSystem | Select-Object InstallDate
        InstallDate
        -----------
        2015/01/04 8:56:24    ← OSがインストールされた日がわかった

クラス情報を調べる方法

例えば「Win32_PhysicalMemory」。これは名前の通り、MSがWindows用に実装したCimベースのクラス

これらのクラスはGet-Helpでは取得できない（コマンドレットではないから）

まずは、APIブラウザ で探してみるが、見つからない。そういう時は、このAPIブラウザ画面のパンくずリストの「Learn」をクリックして全体で探すと見つかったりします

Get-CimClassというコマンドレットで、クラス一覧を表示させることもできます。大量にありますが、パイプを使って絞り込んで探すことができると思います


          > Get-CimClass
          CimClassName                        CimClassMethods      CimClassProperties
          ------------                        ---------------      ------------------
          __SystemClass                       {}                   {}
          __thisNAMESPACE                     {}                   {SECURITY_DESCRIPTOR}
          __Provider                          {}                   {Name}
          ...

メモリに関する情報が取得できるクラス

他にもあると思いますが、とりあえず覚えたのは以下の２つ

  • Win32_PhysicalMemoryArray

    このクラスを使って自分のPCのメモリスロット数を調べることができます

    
              > Get-CimInstance Win32_PhysicalMemoryArray | Select-Object MemoryDevices
              MemoryDevices   
              -------------
                          2    # このPCにはメモリスロットが2つあることがわかる
  • Win32_PhysicalMemory

    このクラスを使ってメモリの情報を取得できます

    
              > Get-CimInstance Win32_PhysicalMemory | 
                    Select-Object Banklabel, Capacity, Speed, Manufacture, PartNumber, SMBiosMemoryType
                    Banklabel        : P0 CHANNEL A       #スロットA
                    Capacity         : 17179869184        #容量16GB
                    Speed            : 3200               #速さ 3200MT/s（32M転送/s）
                    Manufacture      :                    #メーカ
                    PartNumber       : M471A2G43CB2-CWE   #型番
                    SMBiosMemoryType : 26                 #26は、DDR4 SDRAM

                    Banklabel        : P0 CHANNEL B
                    Capacity         : 17179869184
                    Speed            : 3200
                    Manufacture      : 
                    PartNumber       : D4N3200CS-16G       
                    SMBiosMemoryType : 26
  • おまけ

    T/sという単位は何なん。昔はB/sでバイト/secで表していることが多かったと思いますが、今はT/s。これは転送回数/secということらしいです。
    例えばこの値が「5600」だった場合、5600メガ回転送/sということ。DDRメモリは64bit幅なので、5600 x 10^6 x 64bit = 44.8GB/s という高速なメモリってことです。
