モジュールのデバッグ方法

PowerShellのモジュールファイルpsm1は、関数を列挙したファイルです。モジュールは何かのスクリプトにインポートして実行するので、モジュールのデバッグもこの中で行います

具体的には、myTest.ps1ファイルにモジュールファイル「My.System.Memory.psd1」をインポートして、公開している関数「Get-MyMemoryInfo関数」を使うケースを例に説明します

モジュールのデバッグ手順

  1. 親スクリプト「myTest.ps1」をデバッグオプションをつけて実行する 
    
              #myTest.ps1はcmdletbindingを行っているのでDebugが使える
              myTest.ps1 -Debug
  2. 「F11」でモジュール関数「Get-MyMemoryInfo」にステップイン 
    
              #myTest.ps1 テストプログラム
              [CmdletBinding()]
              param()
              Import-Module .\My.System.Memory.psd1
              Write-Debug ("Start Test")              #myTest.ps1側のデバッグメッセージが表示される
              ・・・
              #// call Get-MyMemoryInfo               ← モジュール関数がコールされる。F11でステップイン
              Get-MyMemoryInfo -Debug:$PSBoundParameters.ContainsKey('Debug')
              ・・・
              #// End
  3. モジュール関数「Get-MyMemoryInfo」でステップ実行

    モジュール関数「Get-MyMemoryInfo」に入るので通常のデバッグと同じようにステップ実行すればいい

    
              function Get-MyMemoryInfo {
                [CmdletBinding()]
                param()
                
                $MYNAME = "Get-MyMemoryInfo"
                $MYVERSION = "v1.00.00"  
                Write-Debug ('myname = ' + $MYNAME)         #//Get-MyMemoryInfo関数側のDebugメッセージが表示される
                Write-Debug ('myversion = ' + $MYVERSION)   #// 〃
                ・・・
                ・・・
              }

モジュールのデバッグ「ちょっとだけ注意」

モジュールのデバッグは上述の通りです。一見普通のスクリプトのデバッグと一緒でわざわざ1つの章にする必要ないんじゃね？と思う人もいたかもしれません。

確かに、デバッグオプションを使わない場合は、特に注意は要らないのですがデバッグオプションを使う場合はちょっとした注意が必要です。どういう事かというと「myTest.ps1 -Debug」の「-Debug」はそのままだとモジュール関数には伝わらないです。
このためモジュール関数コール時に「-Debug」引数をどうやって伝えるかという話です

答えは 「$PSBoundParameters」変数の引数情報を使って渡すです


          #myTest.ps1 テストプログラム
          ・・・
          #// call Get-MyMemoryInfo               ← モジュール関数がコールされる。F11でステップイン
          #// $PSBoundParameters変数でオプション引数を受け取っており、この引数リスト内に「Debug」があれば
          #// ContainsKeyメソッドがTrueになり、-Debug がTrueとなる
          Get-MyMemoryInfo -Debug:$PSBoundParameters.ContainsKey('Debug')
          ・・・
          #// End
