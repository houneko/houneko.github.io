Get-ChildItemの「-Exclude」オプション

Get-ChildItemの「-Exclude」の問題

発生した課題・問題とは

文章が長くなったので先に問題は何かを書いておきます。問題は「-Exclude と -Filter を一緒に使ったらGet-ChildItemが何も取得しなくなった」というものです。詳しくは以下をみてみてください。

まず、当初したかった事とは、フォルダAからフォルダBへファイルをコピーするということです。そうすると、Get-ChildItemでフォルダAのファイルObjを取得して、それをパイプでForEach-Objectに渡して、Copy-ItemでフォルダBへコピーしたらいいのかなと思うかと思います。

この時、フォルダAのファイルを全部コピーするだけなら何も気にしなくてもいいのですが、フォルダAの中のあるファイルはコピーしたくないという事情がありました（実際は、フォルダAは開発環境でフォルダBが実行環境となっています。開発環境には作成中やテスト中のコードがあり、それを実行環境へコピーしたくなかったというのが本当の事情です。そのままコピーしてもいいけど実行環境に不完全なごみができると何かいややなぁという意図です）

パイプの先に渡す前の問題なので、パイプは一旦置いておいて、Get-ChildItemの挙動を見てみます。まず、調べると「-Exclude」オプションで取得したくないものを指定できるというのがわかりました。

「-Exclude」オプションのテスト結果


        # このフォルダ内のファイル
        #   C:\Temp
        #     ├ Check-Fuga.ps1              … コピー対象
        #     ├ Check-Hoge.ps1              … コピー対象
        #     ├ INTEST-Get-Hoge.ps1         … コピーしなくていいファイル
        #     ├ INTEST-Make-Hoge.ps1        … コピーしなくていいファイル
        #     ├ Myデータ.csv                … コピーしなくていいファイル
        #     ├ OLD）Update-MyHoge.ps1      … コピーしなくていいファイル
        #     ├ ReadMe_Show-MyFuga.txt      … コピーしなくていいファイル
        #     ├ ReadMe_Update-MyHoge.txt    … コピーしなくていいファイル
        #     ├ Show-MyFuga.ps1             … コピー対象
        #     ├ Show-MyHoge.ps1             … コピー対象
        #     ├ Update-MyHoge.ps1           … コピー対象
        #
        PS > $excludeList = @("INTEST*", "KARI*", "OLD*")          # 除外するファイルのキーワード
        PS > Get-ChildItem -Path C:\TEMP -Exclude $excludeList
        #
        結果）  
        Check-Fuga.ps1              # $excludeListのキーワードで始まるファイル（INTEST*、OLD*）は除外されている
        Check-Hoge.ps1              # しかし、リストにないtxtファイルやcsvファイルは残っている。これは当たり前
        Myデータ.csv                # -Exclude は一見正常動作している
        ReadMe_Show-MyFuga.txt
        ReadMe_Update-MyHoge.txt
        Show-MyFuga.ps1
        Show-MyHoge.ps1
        Update-MyHoge.ps1

上記のテスト結果では「-Exclude」オプションで指定したファイルは表示されなかったので一見テストはOKに見える。ただし、txtファイルやcsvファイルは、先頭がINTESTやOLDなどの除外キーワードで始まっていないので、Get-ChildItemの結果に含まれてしまう。じゃ、Get-ChildItem の -Filterで「*.ps1」ファイルだけにしたらいいやんと思って試してみた結果・・・

以下の通り何も表示されなくなってしまった。 -Filterが悪いのかなと思い、-Filter "*.ps1" だけを実行するとちゃんとps1ファイルだけが表示される。なので、-Filter と -Exclude を組み合わせて使うと正しい結果が得られないように見える。このスイッチは排他ではないので原因はわからない状態。 


      PS > $excludeList = @("INTEST*", "KARI*", "OLD*")          # 除外するファイルのキーワード
      PS > Get-ChildItem -Path C:\TEMP -Filter "*.ps1" -Exclude $excludeList     # -Filter "*.ps1" を追加
      #
      結果）  
            # *** ← 何も表示されなくなった ***

      # -Filterが問題かと思い、-Filter "*.ps1" だけ試してみた結果
      PS > Get-ChildItem -Path C:\TEMP -Filter "*.ps1"     # -Filter "*.ps1" だけをテスト
      結果）
      Check-Fuga.ps1              # ps1ファイルだけが表示されている
      Check-Hoge.ps1              # なので、-Filter "*.ps1" は正しい
      INTEST-Get-Hoge.ps1
      INTEST-Make-Hoge.ps1
      OLD）Update-MyHoge.ps1
      Show-MyFuga.ps1
      Show-MyHoge.ps1
      Update-MyHoge.ps1

回避方法

真の原因はよくわからないが、Webを見ると「-Exclude」オプションを使わずに、Get-ChildItemの結果をパイプでWhere-Objectに渡して、そこで正規表現で、除外キーワードを含むファイルをマッチさせないように運用があることが分かった。それを参考にした処理が以下

  1. $excludeListの内容を少し変える。$excludeList = @("INTEST","KARI","OLD")。*を取る
  2. $excludeListを使って正規表現パタンを作成する

    ^(INTEST|KARI|OLD) これは、INTESTまたはKARIまたはOLDで始まる というパタン

  3. Get-ChildItemの結果をパイプでWhere-Objectに渡して除外ファイルをフィルタする
  4. 修正結果 
    
          #// 以下のキーワードで始まるファイルはUpdate（コピー）しない
          $excludeList = @('INTEST', 'OLD', 'WORK')
  
          #// $excludeListを正規表現パタンに変換する
          $excludePattern = '^(' + (
            ($excludeList | ForEach-Object { [Regex]::Escape($_) }) -join '|'
          ) + ')'
          
          #// Get-ChildItemの結果をパイプでWhere-Objectにわたす
          Get-ChildItem -Path $SRC -Filter "*.ps1" | Where-Object {$_.Name -notmatch $excludePattern}
          
          結果）
          #// 以下の通り、除外キーワードで始まらないps1ファイルが取り出されているので成功
          Check-Fuga.ps1
          Check-Hoge.ps1
          Show-MyFuga.ps1
          Show-MyHoge.ps1
          Update-MyHoge.ps1

修正内容の詳細説明

  1. $excludeListの修正

    $excludeList = @('INTEST*', 'OLD*', 'WORK*') → $excludeList = @('INTEST', 'OLD', 'WORK')
    この修正は各配列要素の末尾に「*」を取る。なんでかというリストではワイルドカードで使っているが、正規表現の変換でそのまま文字とした正規表現パタンになってしまうため。"INTEST*"という文字で始まるパタンでは「INTEST-Hoge.ps1」などがマッチしなくなり除外できないから

  2. $excludeListを正規表現パタンに変換する 
    
          #// $excludeListを正規表現パタンに変換する
          $excludePattern = '^(' + (                  #// パタン先頭の文字列は、'^('
            #// 1. $excludeList をパイプで渡す
            #// 2. ForEach-Objectで[Regex]::Escape() で $_の特殊文字を含むものをエスケープする
            #//    | でjoinする。これでORになる
            ($excludeList | ForEach-Object { [Regex]::Escape($_) }) -join '|'
          ) + ')'     #// パタンの最後の文字列は、')’
          
          出来上がったパタン
          ^(INTEST|KARI|OLD)
  3. Where-Objectで除外ファイルをフィルタ

    Get-ChildItemで*.ps1ファイルだけ取り出して、Where-Objectで除外パタンにマッチしないものだけ出力する

    
          Get-ChildItem -Filter "*.ps1" | Where-Object {$_.Name -notmatch $excludePattern}
