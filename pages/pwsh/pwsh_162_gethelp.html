Get-Helpとは

PowerShellのコマンドレットは、Cmd.exeの頃の Helpオプション（/hや/?など）とは違い、ヘルプ処理を行うコマンドレットが用意されています。つまり、各コマンドレットのヘルプ表示を行うコマンドレットがあるということです。それが、このGet-Helpです

Get-Helpコマンドレットを使えば、他のコマンドレットの仕様を調べることができます


        #// Get-Help 調べたいコマンドレット
        > Get-Help Get-ChildItem     # Get-Help コマンドレット名
        > Get-Help ls                # Get-Help エイリアス名でも可

        NAME
            Get-ChildItem
        #//オーバロードされているので複数のSyntaxがある    
        SYNTAX
            Get-ChildItem [[-Path] <string[]>] ....   
            Get-ChildItem [[-Filter] <string>] ....
        #//このコマンドレットのエイリアス一覧
        ALIASES
            gci
            ls
            dir
        #//注意事項。コマンドレットのヘルプファイルが見つからなかったメッセージが出ている
        #//ここでは省略しているけど、本当の画面では他の方法もサジェストされている
        REMARKS
            Get-Help cannot find the Help files for this cmdlet on this computer....

昔風な（コマンド名にヘルプオプションをつける）ヘルプ表示も可能。だけどGet-Helpに統一した方が使い方を覚えられるしPowerShellっぽいのでいい


        > Get-ChildItem -?

Get-Help：もっと詳しく調べる方法

Get-Helpもコマンドレットなので、引数を持っている。「-Detailed」や「-Online」を指定するともっと詳しいヘルプ表示が出るようになる（-OnlineはWebページ）

もっと詳しく調べる方法


        #// -Detailedオプションを指定した詳細ヘルプ表示
        > Get-Help Get-ChildItem -Detailed
        
        #// -Onlineオプションを指定した詳細な調べ方（Webページが開く。これが一番詳しい）
        > Get-Help Get-ChildItem -Online

Get-Helpの表記方法

Get-Helpで表示されるかっこには意味があります。これはDOSからの流れなので、昔の人は無意識にこの思考になっているかもしれませんが、一応書いておきます。


        #// 角かっこは省略可能を示しています
        #// 以下の意味は、Get-HogeHogeには -Attribute というパラメータ指定が可能であり、それが[]で囲まれている
        #// よって、
        #// Get-HogeHoge                     ← 全部省略した表記も可能
        #// Get-HogeHoge -Attribute ReadOnly ← 全部省略しない書き方もOK
        #// Get-HogeHog ReadOnly             ← -Attributeを省略した書き方もOK
        Get-HogeHoge  [[-Attribute] { ReadOnly | Hidden | System }]
        
        #// 波かっこは、その中から1つを選択するという事を示しています
        #// { ReadOnly | Hidden | System } は、この中のどれか1つを選択
        #// よって、
        #// Get-HogeHoge -Attribute ReadOnly ← ReadOnly値を指定した例
        #// Get-HogeHoge -Attribute Hidden   ← Hiddenを指定した例
        Get-HogeHoge  [[-Attribute] { ReadOnly | Hidden | System }]
