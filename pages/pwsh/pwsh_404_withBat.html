バッチファイルからPowerShellへ配列の引数を渡す

バッチファイルとの連携

まず最初にバッチファイルとPowerShellが連携しないといけないのは何故かを説明します（PowerShellだけを使っていたらこの問題は起きません）
PowerShellを使うには、「少し準備」が必要となっています。このため、PowerShellを知らない人の環境で実行してもらうには、説明して使えるように設定して・・とハードルがあります。

また、GUIになれている人はCUI操作は不慣れな事が多いです（PowerShellのコードはダブルクリックしても動かない）

そこで、PowerShellのコードをバッチファイルで包んでリリースすれば、GUIでバッチファイルをダブルクリックして実行することもできるし、コマンドラインからバッチファイルを実行させることもできて、この問題が解決できます

実際に、部内にPowerShellスクリプトをリリースする時は、この方法で行っています

バッチファイルからPowerShellへ配列の引数を渡す

バッチファイルからPowerShellを実行させる方法は、PowerShellを知らないユーザには有効でこの方法でやっていたのですが、あるケースで問題が起きました

  • プログラム概要

    バッチファイルを起動すると、ユーザに対象のファイルタイプを指定してもらいます。この時複数のファイルタイプがある場合は「,」カンマで区切って指定してもらいます（例：*.csv, *.txtなど）

    これを「EXT」という変数に格納して、この変数をPowerShellの引数にしてPowerShellスクリプトを呼び出します

    PowerShellは、この引数をString[]型で受け取り、このファイルタイプのファイルを取得し処理を行います

  • 発生した問題

    ファイルタイプを複数指定した場合、PowerShell側では対象ファイルが０件となって処理が終了してしまう

    発生した事象を見ると以下のような状況でした

    • PowerShellスクリプト単独で実行する場合は、問題は発生しない
    • バッチファイルからファイルタイプを1つだけPowerShellに渡す場合は、問題は発生しない
    • バッチファイルから複数のファイルタイプをPowerShellに渡すと、問題は発生する

    以上より、バッチファイルから複数のファイルタイプを配列で渡す時に問題が起きていることが分かります

  • 原因

    バッチファイルが渡す値が配列になっていない事が原因でした。

    バッチファイルが起動してユーザが「*.csv, *.txt」と入力したとします。この意図は「*.csv」「*.txt」という複数の拡張子のファイルが対象ですよというものですが、バッチファイルはこれを「"*.csv, *.txt"」という１つの文字列として渡します

    このため、PowerShell側では「"*.csv, *.txt"」という拡張子のファイルを検索して、結果0件でしたとなっていました

バッチファイルからPowerShellへ配列を渡す方法

バッチファイル側（こっちは基本何も変わらない）


        set "DEFAULT_EXT=*.csv"
        ...
        rem ///////////////////////////////////////////////////////////////////////////
        rem // 拡張子（配列）の入力
        set /p EXT="拡張子を指定してください（複数ある場合はカンマで区切る） : "
        if "%EXT%"=="" (set "EXT=%DEFAULT_EXT%")
        ...
        rem ///////////////////////////////////////////////////////////////////////////
        rem // PowerShellコール
        powershell -NoProfile -ExecutionPolicy RemoteSigned -File %BIN_DIR%\hoge.ps1 -fileTypes "%EXT%"

PowerShell側は、バッチファイルから渡されたデータを配列にする処理を追加する

渡された -fileTypes引数が、1つでかつカンマが含まれているかを調べる（バッチから渡されたものか調べる）。YESなら正規表現「空白が0個以上ありカンマがあり空白が0個以上」のパタンで分割して、fileTypesに再代入する（これで配列になる） 


        Write-Debug ("before -fileTypes = " + $fileTypes)
        # 以下の処理を追加する
        # ------------------------------------------------------------------------------------------------
        # バッチファイルは複数のファイルタイプも「1つの文字列」として渡すため、PowerShell側で配列に変える
        if ($fileTypes.Count -eq 1 -and $fileTypes[0] -match ",") {
            $fileTypes = $fileTypes[0] -split "\s*,\s*"
        }
        # ------------------------------------------------------------------------------------------------
        # ちゃんと分解できたかデバッグ表示してみる
        Write-Debug ("after -fileTypes = " + $fileTypes)
        Write-Debug ("type = " + $fileTypes.GetType())      # ← String[]になっている
