ZoneID問題

発生した課題・問題とは

自宅で作成したスクリプトをメールで会社に送り実行しようとしたら・・

以下のように「このhoge.ps1は、デジタル署名されていません・・・」というメッセージが表示されて、実行できない問題がおきました


          PS> ./hoge.ps1
            #「このhoge.ps1は、デジタル署名されていません・・・」というメッセージが表示される

当初、管理者権限のせいかと思い、以下を実行してみた


          PS> isAdmi
          False
            # isAdmiは今のユーザが管理者権限かを調べる自作関数。Falseは管理者権限ではない

管理者権限じゃないから実行できなかったのかなと思い、管理者権限で起動しなおして試してみたが、同じエラーが出てスクリプトが実行できなかった


          PS> isAdmi
          True    # 管理者権限になっている
          PS> ./hoge.ps1
            #「このhoge.ps1は、デジタル署名されていません・・・」というメッセージが表示される

ちなみに、実行ポリシーがRestrictedだったら「スクリプト実行が無効になっているので・・・」というようなメッセージが出るので、本件は実行ポリシーの問題ではない。

また、先ほどの確認で管理者権限の問題でもないことがわかった。なんで？

これは「ZoneID」のせいであった

そもそもZoneIDとは

WindowsXp SP2以降に導入された概念。ファイルにZoneID というセキュリティ情報を持たせて、インターネットから入手したファイルを区別できるようにしている。これにより、そのファイルの実行時にユーザへ実行可否を問い合わせることでセキュリティを保つ仕組みを実現させるための情報

インターネットから入手した *.ps1 スクリプトはローカルに保存していても外から来たファイルであることがZoneIDに書かれているので実行時の挙動が変わる

ZoneIDはどこに格納されている？

ファイルにZoneIDという情報が付いているのはわかったけど、これはどこに格納されている？

一般にファイルは単にバイナリデータの集合だけど、NTFSなどの「ストリーム」をサポートしたファイルシステムでは、1つのファイルに複数のストリームというデータを持たせることができる（ストリームはトラックみたいなもので、メインデータが格納されているストリームと、補助的な情報が格納されるストリームを持つことができる。

ストリームを指定しない or ストリームを解釈しないファイルシステムの場合は、メインのデータストリームだけが見える

ZoneIDは「Zone.Identifier」ストリームに格納されており、インターネットから入手したファイルの値は「３」である

ZoneIDの確認方法

ZoneIDを調べる方法は各ストリームを表示させて「Zone.Identifier」ストリームがあるかを調べ、その値を確認すればいい

Get-Itemでストリームを表示させて、Get-Contentで「Zone.Identifier」の値を確認する

  • 「Get-Item 対象ファイル -Stream *」

    まず、そのファイルの全ストリームを表示させてみて「Zone.Identifier」ストリームがあるかを調べる

  • 「Get-Content 対象ファイル名 -Stream Zone.Identifier」

    そのファイルに「Zone.Identifier」ストリームがあれば値を表示させる

まず、自作のファイルのZoneIDを調べてみる。

以下は「Get-Item 対象ファイル -Stream *」でそのファイルのストリームを表示させてみた結果。この結果の「Stream」の項目を見ると「:$DATA」という名前になっていることがわかる。これは本データを示すものでデータストリームである。

また、ストリームはこの「:$DATA」しかなく「Zone.Identifier」ストリームは存在していない。

つまり、このファイルはインターネット経由のファイルではない（自作ファイルなので当たり前）


      > Get-Item .\tmp_2.zip -Stream *

      PSPath        : Microsoft.PowerShell.Core\FileSystem::C:\TEMP\tmp_2.zip::$DATA
      PSParentPath  : Microsoft.PowerShell.Core\FileSystem::C:\TEMP
      PSChildName   : tmp_2.zip::$DATA
      PSDrive       : C
      PSProvider    : Microsoft.PowerShell.Core\FileSystem
      PSIsContainer : False
      FileName      : C:\TEMP\tmp_2.zip
      Stream        : :$DATA              #← Streamは「:$DATA」なのでデータ本体のストリーム
      Length        : 21183

次にインターネットからDLして来たファイルを調べてみる

以下は、インターネットからDLしたファイルを「Get-Item ファイル -Stream *」で表示させてみた結果。この結果を見るとストリームが2つあることがわかる。1つはデータ本体「:$DATA」で、もう1つは「Zone.Identifier」ストリームである。

つまり、このファイルには「Zone.Identifier」ストリームという情報が付いている

ただし「Zone.Identifier」ストリームがついていても、まだインターネットからDLしたものとは断定できない。なので、このストリームの値を確認してみる。その結果が「3」なのでインターネットからDLしたファイルであることが確認できた 


      > Get-Item .\tmp_2.zip -Stream *
      PSPath        : Microsoft.PowerShell.Core\FileSystem::C:\TEMP\th.jpg::$DATA
      PSParentPath  : Microsoft.PowerShell.Core\FileSystem::C:\TEMP
      PSChildName   : th.jpg::$DATA
      PSDrive       : C
      PSProvider    : Microsoft.PowerShell.Core\FileSystem
      PSIsContainer : False
      FileName      : C:\TEMP\th.jpg
      Stream        : :$DATA              #← Streamは「:$DATA」なのでデータ本体のストリーム
      Length        : 32624

      PSPath        : Microsoft.PowerShell.Core\FileSystem::C:\TEMP\th.jpg:Zone.Identifier
      PSParentPath  : Microsoft.PowerShell.Core\FileSystem::C:\TEMP
      PSChildName   : th.jpg:Zone.Identifier
      PSDrive       : C
      PSProvider    : Microsoft.PowerShell.Core\FileSystem
      PSIsContainer : False
      FileName      : C:\TEMP\th.jpg
      Stream        : Zone.Identifier     #← 「Zone.Identifier」ストリーム
      Length        : 149

      #「Zone.Identifier」ストリームがあるけど、インターネットからDLしたものかはまだ分からない
      #「Get-Content ファイル名 -Stream Zone.Identifier」で値を調べる
      > Get-Content .\th.jpg -Stream Zone.Identifier
      [ZoneTransfer]
      ZoneId=3        # ← ZoneIDが「3」なのでインターネットからDLしたファイルである
      ReferrerUrl=https://www.bing.com/
      HostUrl=https://th.bing.com/th?id=OPAC.opx%2b5Ofs29Ekew474C474&w=592&h=550&o=5&pid=21.1

ファイルのプロパティによる確認方法

ストリームを表示やZoneID値を見る事は出来ないがGUIでも確認することができる。ローカルファイル、インターネットからDLしたファイルそれぞれのファイルを右クリックしてプロパティを開くと表示に違いがある
