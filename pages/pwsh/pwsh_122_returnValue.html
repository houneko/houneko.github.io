PowerShellの複数の値を返す関数

複数の値を返す関数

PowerShellの関数はreturnで1つの値を返すが、場合によっては複数の値を返したい場合がある。例えば、文字列を変換する関数は「変換した文字列」を返すととともに「関数の成否」も返したいようなケースである。

複数の値を返す関数の作成方法

他の方法があるかもしれないが[PSCustomObject]でキャストした連想配列を返すようにすれば複数の値を返せる

つまり[PSCustomObject]＠{キー=バリュー....} を返す ってこと

    [PSCustomObject]でキャストした連想配列で値を返す関数 
    
          # 
          # 複数の値を返すの関数のテスト
          #
          [cmdletbinding()]
          param()

          #////////////////////////////////////////////////////////////////////////
          # 複数の値を返す関数 hoge
          function script:hoge {
            [CmdletBinding()]
            param(
              [String]$orgString
            )  
              #--------------------------------------------------------
              # PSCustomObjeでキャストして各メンバに値をいれて返す
              # 変数はコール側からもらわなくてもいい
              if ([String]::IsNullOrEmpty($orgString)) {
                # 空の文字列が渡された場合
                return [PSCustomObject]@{                           #// 連想配列@{} を [PSCustomObject]型にキャストして返している
                  status = $false                                   #// .statusキーと値、.convStringキーと値 で複数の値を返している
                  convString = $null                                #// 
                }  
              } else {
                return [PSCustomObject]@{
                  status = $true
                  convString = $orgString.ToUpper()
                }  
              }  
          }    

          #////////////////////////////////////////////////////////////////////////
          # メインブロック
          $myVersion = "v1.00.00"
          #--------------------------------
          # 関数コール
          $result = hoge "moto no moji"                             #// コール側は連想配列型の引数を渡さなくてもいい
          if ($result.status) {                                     #// 関数の成否結果を.statusメンバ（キー）で判別している
            Write-Host ('$result.status =', $result.status)
            Write-Host ('$result.convString = ', $result.convString)
          } else {
            Write-Error("conv失敗しました")
          }  

          実行結果）
          #// 2つの値を受け取っている
          $result.status = True                 #// 関数が成功していることがわかる
          $result.convString =  MOTO NO MOJI    #// 変換後の大文字になった文字列

    この関数は、引数で文字列をもらいそれを大文字変換して返還後の文字列を返す関数である。この時、関数の処理結果も返したいので[PSCustomObject]でキャストした連想配列を返している

    • 注意点１

      関数コール側は、連想配列を引数として渡さなくてもいい。Cとかのイメージでは構造体型の引数を渡してそのメンバに値をセットして返してもらうけど、Powershellではコール側で連想配列型を用意してそれを渡す「ではない」。
      C言語は静的型付け言語なのでコンパイル時に型の確認を行うけど、PowerShellは動的型付け言語なので関数側で作った連想配列型を返してもらうことができる。
      そうすると次に関数コール側は戻ってくる連想配列型にどんなメンバ（キー）があるのかをどうやってわかるの？という疑問が出てくるが、プログラマがhoge関数は[PSCustomObject]連想配列を返すものと知っている。各メンバ（キー）は何があるかを知っているという前提 となっている
