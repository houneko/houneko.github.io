Out-Nullコマンドレットとは

人のコードを見ていたら、Out-Nullコマンドレットというのがありました。以下のようなコードです。このコマンドレットは使ったことがなかったのですが、PowerShellの命名ルールから考えて何かをOutputする、Nullにとなります。Nullは通常、空っぽを示すので無の世界に何かを出力するって感じで想像できます。

そこまでは初見でも何となくわかったのですが、何でこれが必要かはピンときませんでした。なので、少し調べてみました


        New-Item -ItemType Directory -Path $outputDir | Out-Null

とりあえず、Get-Helpでこのコマンドレットを調べてみました


        > Get-Help Out-Null -Online

「説明 Out-Null コマンドレットは、実際には出力を NULL に送信し、パイプラインから出力を削除し、出力が画面に表示されないようにします。」というのが書いてありました。大体想像した通りですが、出力が画面に表示されないようするってのがこのコマンドレットの役目のようです

次に、前述のNew-Item操作をパイプ出力なしで実行してみました。その結果、以下のようになりディレクト作成の結果情報がコンソールに出力されてしまいます。

ということは、この人の意図はNew-Itemでディレクトリを作成したいけど、その結果メッセージは表示してほしくないってことだったという事がわかりました。そういえば、自分もps1スクリプトの中でディレクトを作るケースがあり同じような事をしていたのを思い出しました（自分は[void]でキャスト）。 


        > $outputDir = "C:\Users\xxx\Hoge\TEMP"
        > New-Item -ItemType Directory -Path $outputDir    #// ← パイプ出力しないで実行してみた

            Directory: C:\Users\xxx\Hoge                          #// ← New-Itemの実行結果がコンソールに表示される

        Mode                 LastWriteTime         Length Name    #// ← 作成されたディレクトリ情報
        ----                 -------------         ------ ----
        d----          yyyy/mm/dd    hh:mm                TEMP

このパイプでOut-Nullに出力するというのがPowerShellの文化にあっているように思います。なので今後は自分もこっちの書き方にしようかなと思います（可読性もこっちの方が高いんじゃないかな）

Out-Nullコマンドレットと同様な処理

  1. 代入して捨てる

    これでNew-Item結果メッセージはコンソールに出なくなるけど、$myNull変数に代入して後で使う？などの疑問が出そうで可読性を考えるとあまりきれいではないのかなと今は思っています

    
            > $myNull = New-Item -ItemType Directory -Path $outputDir
  2. [void]でキャストする

    自分はこの書き方でやっていた。New-Itemの処理全体を()で囲み、それを[void]でキャストする

    
            > [void](New-Item -ItemType Directory -Path $outputDir)

なお、Webページには New-Itemの「-OutVariable」オプションを使う方法もあったけど、これはコンソールに出力されるのでだめ
