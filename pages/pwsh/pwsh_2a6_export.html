Exportについて

モジュール内関数の公開

モジュール内関数の公開とは

モジュールは、多数の便利な関数を記述したファイルと言えるかと思います。そうすると、中には内部ローカル用の関数も作ったりすることが出てきます。この場合、内部関数は公開したくないという事態になると思いますが、外部に見せる、見せないの制御が関数の公開という事です。

モジュール内関数の公開方法

モジュール内の関数を公開する方法は2種類あります。psm1モジュールファイルに「Export-ModuleMemberコマンド」で公開する関数を指定する。psd1マニフェストファイルに「FunctionsToExportキー」で公開する関数を指定するという方法です。以下のサンプルがpsm1ファイル、psd1ファイルに公開関数を指定した例です 


          # psm1モジュールファイルに書く
          function Get-HogeHoge {       #// 公開したい関数
            ....
          }
          function Get-FugaFuga {       #// 公開したい関数
            .....
          }
          ....
          function MYLocalFunction {    #// ローカル関数（公開しない）
            ....
          }

          # //公開する関数リスト
          $publicFunctions = @(
            'Get-HogeHoge',
            'Get-FugaFuga'
          )
          # //公開する関数リストを公開する。psm1ファイルの場合Export-ModuleMemberコマンドで公開する
          Export-ModuleMember -Function $publicFunction 
          

          # psd1マニフェストファイルに書く
          @{
            ....
            RootModule        = 'My.Hardware.Memory.psm1'       #// RootModuleでモジュールファイルを示す  
            FunctionsToExport = @(                              #// 公開する関数はfunctionsToExportキー（配列）で
              'Get-HogeHoge',                                   #// 指定する
              'Get-FugaFuga'
            )
            ....
          }

そうすると、2つのファイルに同じことを書かないといけないのか？2つのファイルの内容が違っていた公開する関数はどうなるのか？などの疑問が出ると思います。
答えは以下の通りです

  • 2つのファイルに同じことは書かないといけない？

    答え：ノー。2つのファイルにそれぞれ公開関数を書く必要はないです（書いてもいいけど冗長だし保守が2倍になる）

    じゃ、どうするのか？

    自分の運用は、psm1ファイルは何も書かない。psd1ファイルで公開を制御するです。つまり、psm1ファイルは関数を列挙するだけのファイルで「Export-ModuleMember」は書かない。そうするとpsm1的には全関数が公開扱いですが、psd1ファイルで「FunctionsToExport」指定した関数だけが公開されます

  • psm1ファイルでの公開内容と、psd1ファイルでの公開内容が違う場合

    自分の運用は上記の通り、psd1ファイルの「FunctionsToExport」だけで公開をコントロールするので、このような両ファイルで公開の差が発生することはありません。でももし両方に公開関数を書いて、それが違っていたらどうなるか？

    答え：「両方で一致する関数が公開される」となります。やはり2ファイルに公開関数を定義するのはこういう間違いや意図しない公開になってしまうので、1ファイルで公開を制御する方がいいです

公開した関数の確認方法

モジュールファイル、マニフェストファイル、公開を全て行えば指定した関数が公開されてコマンドラインから実行したり、別のスクリプトにインポートして取り込み再利用できるようになります

今、あるモジュールについてどのような関数が公開されているかを調べる方法があります。Get-CommandでModuleを指定してやれば、そのモジュールが公開している関数が一覧表示されます


          > Get-Command -Module My.Hardware.Memory
          CommandType     Name                  Version    Source
          -----------     ----                  -------    ------
          Function        Get-MyMemoryInfo      1.0.0      MY.Hardware.Memory
          Function        Get-MyMemoryUsage     1.0.0      MY.Hardware.Memory
