PowerShellでEverythingを使う

PowerShellでEverythingを使う

Everythingを使えば、ファイル検索が超高速に実現できます。また、EverythingにはCLIツール（es.exe）もあり、コマンドラインからEverythingを使う事もできます（es.exeを使う場合は、Everythingが起動している必要があります）。

PowerShellで大量のファイルを検索する場合、並列処理を行う事で高速化できますが、Everythingがインストールされている（かつEverythingが起動している）環境であれば、EverythingのCLIツール（es.exe）を使った方が高速です

まず、es.exe を使ってみる。es.exeをパスが通った所におきコマンドラインから「es」と入力したら全ファイルが表示されます（この使い方は現実的ではないですが、かなり高速であることがわかります。途中でCtrl+Cで止められます）。また、コマンドに「-help」オプション（hは小文字）をつけて実行するとコマンドヘルプが表示されます 


        > es -help
        ES 1.x.x.xx
        ES is a command line interface to search Everything from a command prompt.
        ES uses the Everything search syntax.

        Usage: es.exe [options] search text
        Example: ES  Everything ext:exe;ini

        Search options
          -r <search>, -regex <search>
                Search using regular expressions.
          ....
          ...

次に、サンプルとしてesの検索結果をPowerShellに渡して、PowerShellでもらったデータを処理できるか確認してみます。以下のサンプルのようにewをPowerShellで使うことができるのが分かります 


          # myfuncを含むps1ファイルが一気に検索される
          > es *.ps1 | Where-Object {$_ -like "*myfunc*"}
          C:\My\MyCmd\myfunc_Hoge.ps1
          D:\TEMP\INTEST\myfunc_Fuga.ps1
          ...

PowerShellでEverythingを使う手順（① Everything）

Everything（es.exe）を使うためには、Everything（es.exe）が使えるかという点と、NTFSファイルシステムを使ったドライブかという点と、ネットワークドライブではないローカルドライブであるという点を調べて全部がOKならEverythingが使えます

  1. es.exeコマンドが存在しているかを調べる

    Everythingをインストールしている人でも、CLIツールをインストールしていない場合があります。その場合はコマンドラインからEverythingを使う事はできないため、スクリプトを実行する前にes.exeがカレントPCに存在するかを調べておきます 

    
            # カレントPCに「es.exe」が存在しているかを調べる
            # PowerShellは、es.exeが存在していない場合は、エラーとなりますが、停止しないエラーとなります
            # -ErrorAction SilentlyContinueを付けるのは、エラーを表示しないようにするため
            if (Get-Command es.exe -ErrorAction SilentlyContinue) {
              # es.exe は存在する
            } else {
              # es.exeは存在しないため、Everythingは使用不可
            }
  2. Everythingが起動しているかを調べる

    Everythingプロセスが起動しているかをGet-Processで調べる（この処理はesが動かくをテストする事で代行できる）

    
            # カレントPCで「Everythingプロセス」が起動しているか調べる
            if (Get-Process Everything -ErrorAction SilentlyContinue) {
              # Everythingプロセスは起動しています
            } else {
              # Everythingプロセスは起動していません
            }
  3. Everythingサービスが実行されているかを調べる

    Everythingがサービス起動しているかをGet-Serviceで調べる（この処理はesが動かくをテストする事で代行できる）

    
            # カレントPCで「Everythingサービス」が実行されているか調べる
            $myEverything = Get-Service -Name Everythin -ErrorAction SilentlyContinue            
            if ($myEverything -and $myEverything.Status -eq "Running") {
              # Everythingサービスは実行中です
            } else {
              # Everythingサービスは実行されていません
            }
  4. es.exeが実行できるかを調べる

    Everythingプロセスが起動しているか？、サービス起動しているか？を調べる事でesが使えるかどうかは想定できますが、本当にes.exeが使えるかどうかは厳密にはesを実行しみるのが一番確実です。このためes.exeをテスト実行して確認できれば、「Everythingが起動しているかを調べる」「Everythingサービスが実行されているかを調べる」という確認はしなくてもいいです。 

    
            # es.exeで1ファイルだけ検索してエラーにならなければ、es.exeは動作するという判断
            try {
              es "" -n 1 > $null
              return $true
            } catch {
              return $false
            }

これらをまとめて、es.exeが存在するか使用可能かを判定するテスト関数を作成してそれをコールすればいい


        #//////////////////////////////////////////////////////////////////////////////////////////////////////
        #// function
        #//////////////////////////////////////////////////////////////////////////////////////////////////////
        function script:Test-EverythingAvailable {
          param ()
          Write-Debug ("Enter Test-EverythingAvailable()")

          #// es.exe（EverythingのCLIツール）が存在するか調べる
          if (-not (Get-Command es.exe -ErrorAction SilentlyContinue)) {
            Write-Debug ("Exit Test-EverythingAvailable() -- es.exe does not exist.")
            return $false
          }
          try {
            #// es.exeが動くかを調べる。全ファイルを検索して1つだけ検索し結果は捨てる
            #// es.exeで例外が発生しなければ実行できたので、$trueを返す
            #// 失敗したらcatchに入るので$falseを返す
            es "" -n 1 > $null
            Write-Debug ("Exit Test-EverythingAvailable() -- es.exe is available!")
            return $true
          } catch {
            Write-Debug ("Exit Test-EverythingAvailable() -- es.exe was found, but it does not work.")
            return $false
          }
        }

PowerShellでEverythingを使う手順（② NTFSファイルシステム）

次に、対象ドライブがNTFSかを調べます

  1. UNCパスかどうか調べる

    渡されたパスが「\\*」であればネットワークなので対象外にする

    
            # 渡されたパスが「\\*」なら、$falseを返す
            if ($myPath -like "\\*") {return $false}
  2. FileSystemプロパティを調べる

    ドライブレターから論理ボリュームを取得し、その論理ボリュームのFileSystemプロパティを調べる。プロパティ値が「NTFS」の場合は$trueで、それ以外は$falseを返す

    
            #// ドライブレター取得（例: C:）
            $driveLetter = Split-Path $myPath -Qualifier
            Write-Debug ("driveLetter = " + $driveLetter)
            #// 論理ボリュームを取得
            $logicalVol = Get-CimInstance Win32_LogicalDisk -Filter "DeviceID='$driveLetter'" -ErrorAction SilentlyContinue
            Write-Debug ("logicalVol = " + $logicalVol)
            Write-Debug ("logicalVol.FileSystem = " + $logicalVol.FileSystem)
            
            #// 存在しない論理ボリュームなら$falseを返す
            if (-not $logicalVol) {return $false}

            Write-Debug ("Exit Test-NTFS()")
            return $logicalVol.FileSystem -eq "NTFS"

これもNTFS化をテストする関数にして、NTFSだったら$trueを返すようにしたらいいです


        #//////////////////////////////////////////////////////////////////////////////////////////////////////
        #// function
        #//////////////////////////////////////////////////////////////////////////////////////////////////////
        function script:Test-NTFS {
          param ($myPath)
          Write-Debug ("Enter Test-NTFS()")
          Write-Debug ("myPath = " + $myPath)
          
          # UNCは基本Everything対象外なのでFalse扱い
          if ($myPath -like "\\*") {return $false}
          
          #// ドライブレター取得（例: C:）
          $driveLetter = Split-Path $myPath -Qualifier
          Write-Debug ("driveLetter = " + $driveLetter)
          #// 論理ボリュームを取得
          $logicalVol = Get-CimInstance Win32_LogicalDisk -Filter "DeviceID='$driveLetter'" -ErrorAction SilentlyContinue
          Write-Debug ("logicalVol = " + $logicalVol)
          Write-Debug ("logicalVol.FileSystem = " + $logicalVol.FileSystem)
          
          #// 存在しない論理ボリュームなら$falseを返す
          if (-not $logicalVol) {return $false}

          Write-Debug ("Exit Test-NTFS()")
          return $logicalVol.FileSystem -eq "NTFS"
        }

PowerShellでEverythingを使う手順（③ ネットワークドライブ）

ネットワークドライブ先のサーバがWindowsでNTFSだったとしても、ネットワーク越しにMFT情報は取得できない ので、結果的にネットワークドライブはEverything高速化の恩恵は受けられない。このため、対象がネットワークドライブかどうかを調べます

  1. UNCパスかどうか調べる

    渡されたパスが「\\*」であればネットワークなので対象外にする

    
            # 渡されたパスが「\\*」なら、$falseを返す
            if ($myPath -like "\\*") {return $false}
  2. 対象のドライブレターがネットワークドライブか調べる

    渡されたパスからドライブレターを取り出し、そのドライブレターがネットワークドライブか調べる

    
            $driveLetter = Split-Path $myPath -Qualifier
            $myID = Get-CimInstance Win32_LogicalDisk -Filter "DeviceID='$driveLetter'" -ErrorAction SilentlyContinue
            #// DriveType
            #//   2 = リムーバブル
            #//   3 = ローカル固定
            #//   4 = ネットワーク
            #//   5 = CD-ROM
            #//   6 = RAM Disk

これもネットワークドライブテスト関数にして、ネットワークドライブか調べるようにしたらいいです


        #//////////////////////////////////////////////////////////////////////////////////////////////////////
        #// function
        #//////////////////////////////////////////////////////////////////////////////////////////////////////
        function script:Test-NetworkPath {
          param ($myPath)
          Write-Debug ("Enter Test-NetworkPath()")
          Write-Debug ("myPath = " + $myPath)
          
          #// UNCパスならネットワークなので、$tureで即リターン
          if ($myPath -like "\\*") {return $true}
          
          #// $myPathからドライブレターを取り出し、そのドライブレターがネットワークドライブかを調べる
          $driveLetter = Split-Path $myPath -Qualifier
          $myID = Get-CimInstance Win32_LogicalDisk -Filter "DeviceID='$driveLetter'" -ErrorAction SilentlyContinue
          Write-Debug ("driveLetter = " + $driveLetter)
          Write-Debug ("myID = " + $myID)
          Write-Debug ("myID.DriveType = " + $myID.DriveType)
          
          Write-Debug ("Exit Test-NetworkPath()")
          #// DriveTypeを見てネットワークかどうかを判別して結果を返す
          #//   2 = リムーバブル
          #//   3 = ローカル固定
          #//   4 = ネットワーク
          #//   5 = CD-ROM
          #//   6 = RAM Disk
          #//
          return ($myID -and $myID.DriveType -eq 4)
        }
