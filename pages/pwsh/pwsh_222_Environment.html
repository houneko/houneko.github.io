Environmentクラスのスタティックメソッド

[Environment]::GetEnvironmentVariable

[Environment]::GetEnvironmentVariable

このメソッドは、カレントプロセスから環境変数を取得するためのスタティックメソッド。メソッドはオーバロードされているので引数を１つ取るものと２つ取るものがある（詳細）。
自分のケースでは、Path環境変数を取得する時にこのメソッドを使った。

Environment.GetEnvironmentVariable メソッド（Microsoft）


        #// カレントユーザの Path を取得
        $currentPath = [Environment]::GetEnvironmentVariable('Path', 'User')

[Environment]::SetEnvironmentVariable

[Environment]::SetEnvironmentVariable

このメソッドは、GetEnvironmentVariableのSet版で環境変数を設定するためのスタティックメソッド。こちらもオーバロードされている。（詳細）。
自分のケースでは、Path環境変数を設定する時にこのメソッドを使った。

Environment.SetEnvironmentVariable メソッド（Microsoft）


          #// ユーザ環境変数Pathを設定する
          #// ※$newPathは、既存のパスと新たに追加するパスの合計
          [Environment]::SetEnvironmentVariable('Path', $newPath, 'User')

環境変数Pathの設定時における失敗

[Environment]::GetEnvironmentVariable、[Environment]::SetEnvironmentVariableメソッドにより、環境変数Pathの値を取ってきて、追加したいパスを設定することができるという事はわかった。これで早速やってみたところパスは通ったので安心していたのですが、実は大きな失敗をしていました。

どう言うことかというと、同じパスが環境変数Pathに重複して登録されてしまう問題が発生


        # 環境変数を表示させてみた結果
        [Environment]::GetEnvironmentVariable('Path', 'User') -split ';'

        C:\Program Files\PowerShell\7\;       # ← 同じパスが複数登録されてしまっている
        C:\Users\xxx\.dotnet\tools;
        C:\Program Files\dotnet\;
        ...
        ...
        C:\Program Files\PowerShell\7\;       # ← 同じパスが複数登録されてしまっている
        C:\Users\xxx\.dotnet\tools;
        C:\Program Files\dotnet\;
        ...

コードは以下のようになっており、指定されたパスが環境変数Pathに存在するかを判断してから追加しているので、このような事が起こるはずないと思っていたのですが、結果は上記の通りです

では何が問題だったのか？

答えは「Path」と「PATH」を混在して使っていたから

PathもPATHも論理的には同じはずだけど、Windows、.NET、PowerShellの組み合わせでは副作用がでることがある。今回起こったことは、ユーザ環境変数Pathとシステム環境変数Pathが混ざって、それが[Environment]::SetEnvironmentVariable('PATH', $newPath, 'User') でユーザ環境変数Pathに書き込まれたようである。


        #// カレントユーザの Path を取得
        $currentPath = [Environment]::GetEnvironmentVariable('Path', 'User')

        #// セミコロン区切りで各パスを分解、既に存在するかチェック（大文字小文字・末尾 \ 無視）
        $paths = $currentPath -split ';'
        $exists = $paths | Where-Object {
            $_.TrimEnd('\') -ieq $binPath.TrimEnd('\')
        }

        #// 存在しなければ追加。存在していれば何もしない
        if (-not $exists) {
            #// カレントPATHの最後に「;」がある場合と無い場合があるので見切って追加する
            if ($currentPath -and $currentPath[-1] -ne ';') {
                #// 末尾にセミコロンが無ければ追加
                $newPath = "$currentPath;$binPath"
            } else {
                #// 末尾にセミコロンがあればそのまま追加
                $newPath = "$currentPath$binPath"
            }
            #///////////////////////////////////////////////////////////////////////////
            #// ここが環境変数Pathに設定しているところ
            #// *** 「PATH」になっているため問題が発生 ***
            #// *** 「Path」と「PATH」を混在させるとだめ! ***
            #///////////////////////////////////////////////////////////////////////////
            [Environment]::SetEnvironmentVariable('PATH', $newPath, 'User')
            Write-Host ('パスを追加しました')
            exit 0
        } else {
          Write-Host ('既にパスは設定されています')
            exit 1
        }
