Out-Hostとは

Out-Hostは、画面表示量をコントロールする時に使うコマンドレット（他の使い方もあるかもしれないけど自分はほぼこの使い方だけ）。Cmd.exeの時の「-More」に相当する使い方

パイプで前段のコマンドレット結果をもらい「Out-Host -Paging」で表示を1ページ単位に制御する。 とりあえずこの使い方だけ覚えておけば、出力が長くなるいろいろなコマンドレットで使える


        > Get-Command
        #出力結果（大量に表示され画面がスクロールする）
        CommandType     Name                            Version    Source
        -----------     ----                            -------    ------
        Alias           Add-AdlAnalyticsDataSource      1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlAnalyticsFirewallRule    1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlStoreFirewallRule        1.3.1      Az.DataLakeStore        
        ...
        ...

Get-Commandの出力をパイプで「Out-Host -Paging」に渡す

1ページ表示した最後に「SPACEで次のページ、リターンで次の1行、Qで終了」のメッセージが出て表示をコントロールできる


        > Get-Command | Out-Host -Paging
        #出力結果（1ページ毎の表示に制御されるようになる）
        CommandType     Name                            Version    Source
        -----------     ----                            -------    ------
        Alias           Add-AdlAnalyticsDataSource      1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlAnalyticsFirewallRule    1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlStoreFirewallRule        1.3.1      Az.DataLakeStore        
        ...
        ...
        Alias           Disable-StorageDiagnosticLog    1.0.0.0    VMDirectStorage
        <SPACE> next page; <CR> next line; Q quit

実はPowerShellでも「More」は使える。Moreは「More.com」としてWindowsには入っておりパイプで「More」に渡してページ表示を制御できる。これでもいいけど、PowerShell文化に則り「Out-Host -Paging」で覚えていた方がいいかなと思います。


        > Get-Command | More
        #出力結果（1ページ毎の表示に制御されるようになる）
        CommandType     Name                            Version    Source
        -----------     ----                            -------    ------
        Alias           Add-AdlAnalyticsDataSource      1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlAnalyticsFirewallRule    1.0.3      Az.DataLakeAnalytics
        Alias           Add-AdlStoreFirewallRule        1.3.1      Az.DataLakeStore        
        ...
        ...
