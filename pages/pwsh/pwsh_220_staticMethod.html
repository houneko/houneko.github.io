.NETのスタティックメソッド

.NETのスタティックメソッドとは

PowerShellは、.NET上で実行されています。ある程度PowerShellのコードを書くようになると、.NETのスタティックメソッドを使うことも増えてきます。
では、.NETのスタティックメソッドとは何か？

スタティックメソッドは、インスタンスを生成せずに直接呼び出すことができるメソッド。通常、xxクラスのメソッドはそのクラス型のインスタンスを生成すれば使えるようになるけど、スタティックメソッドはインスタンスを生成しなくても使えるようになっています

PowerShellでの、.NETのスタティックメソッドの呼び出し方

角かっこでクラス名を囲み、::（コロン2つ）でメソッド名を指定する

例： [System.IO.File]::ReadAllBytes

参考）C#も.NET上で実行されているので、同じスタティックメソッドを使うことができる。ただし呼び出し方は少し違う

  • PowerShellの場合

    [System.IO.File]::ReadAllText("test.txt")

  • C#の場合

    System.IO.File.ReadAllText("test.txt");

.NETのクラスが持つスタティックメソッドを調べる方法

調べ方はいろいろあると思いますが、1つの方法として以下の2ステップで調べることができます

  1. クラスをパイプでGet-Memberに渡してどんなメソッドがあるか調べる

    そのクラスが持つスタティックメソッドはどのようなものがあるかを調べるには、以下のようにGet-Member -staticで調べることができる。

    [System.IO.File] | Get-Member -Static 

    
            # [System.IO.File]クラスのスタティックメソッド。めちゃくちゃいっぱいある
            > [System.IO.File] | Get-Member -Static
            Name                 MemberType Definition
            ----                 ---------- ----------
            AppendAllBytes       Method     static void AppendAllBytes(string path, byte[] bytes), ...
            AppendAllBytesAsync  Method     static System.Threading.Tasks.Task AppendAllBytesAsync(string path, ...
            ...
            ReadAllBytes         Method     static byte[] ReadAllBytes(string path)
            ...
  2. 気になるメソッドがあれば公式ドキュメントで調べる

    Microsoftの技術ドキュメント

    このトップページから「.NET」をクリックして、その中にある「.NET APIリファレンス」を開く。.NET APIブラウザで「System.IO.File.ReadAllBytes」などのキーワードで検索する

スタティックメソッドのもっと調べる方法

あるクラスがどんなスタティックメソッドをもっているかは「.NETのクラスが持つスタティックメソッドを調べる方法」 で調べることができます。この章は、そこで見つかったあるスタティックメソッドについて、もっと深く調べる方法についてまとめています

例：[System.IO.Path]::GetFileNameWithoutExtension

とりあえず、[System.IO.Path]をGet-Memberで調べて、GetFileNameWithoutExtension() というメソッドが見つかった。じゃ、これを使ってみようと思ったという想定での例です

GetFileNameWithoutExtensionメソッドを使うには、どんなメソッドか知らないといけないですが、以下のように深堀することができます。

  1. [System.IO.Path] を Get-Member で調べる

    まずはこれが第一歩で、このクラスが持つスタティックメソッドを調べる

    
              # [System.IO.Path]クラスのスタティックメソッド。当然いっぱいある
              > [System.IO.Path] | Get-Member -MemberType Method -Static
              
              TypeName: System.IO.Path
              
              Name                         MemberType Definition
              ----                         ---------- ----------
              ChangeExtension              Method     static string ChangeExtension(string path, string extension)
              Combine                      Method     static string Combine(string path1, string path2), static string …
              ...
              GetFileNameWithoutExtension  Method     static string GetFileNameWithoutExtension(string path), ...
              ...
  2. 例として GetFileNameWithoutExtension を調べてみる

    Get-Helpで調べられるか？、答えはNo。Get-Helpは、PowerShellのコマンドレットや関数などが対象のため

    じゃ、どうするか？

    Get-Memberには、-Name というオプションがあるので対象のメソッドを指定して調べる

    
            # -Nameオプションで対象のメソッドを指定して調べる（-Staticもつける）
            > [System.IO.Path] | Get-Member -Name GetFileNameWithoutExtension -Static

              TypeName: System.IO.Path

            Name                        MemberType Definition
            ----                        ---------- ----------
            GetFileNameWithoutExtension Method     static string GetFileNameWithoutExtension(string path), static ...

    Definitionに関数プロトタイプが書かれているようだけど文が長いので省略されている

  3. GetFileNameWithoutExtension のDefinitionを調べる

    [System.IO.Path] | Get-Member -Name GetFileNameWithoutExtension -Static でこのメソッドの概要を調べることができるのはわかったけど、Definitionに書かれている内容が長文のため省略されている。これを全部表示させる

    この結果をFormat-Listで表示させる

    
            #// Format-Listで成形して全部表示させる
            > [System.IO.Path] | Get-Member -Name GetFileNameWithoutExtension -Static | Format-List *
            TypeName   : System.IO.Path
            Name       : GetFileNameWithoutExtension
            MemberType : Method
            Definition : 
              static string GetFileNameWithoutExtension(string path), 
              static System.ReadOnlySpan[char] GetFileNameWithoutExtension(System.ReadOnlySpan[char] path)

    Definitionから分かる事

    Definitionには、以下の2つが書かれている。これは関数プロトタイプが2つあることを示しており、つまりオーバロードされている事がわかる

    また、それぞれのメソッドの戻り値や引数もわかる

    
              # このGetFileNameWithoutExtension()は、戻り値がstringで、引数はstring型のpath
              # pathを渡せば、拡張子を除くファイル名のStringが返ってくる（と想像できる）
              static string GetFileNameWithoutExtension(string path), 
              
              # このGetFileNameWithoutExtension()は、戻り値がSystem.ReadOnlySpan[char]、
              # 引数は、System.ReadOnlySpan[char]型のpath。どっちもわからん。
              # 戻り値も引数も何かの配列っぽいけどわからん。だけど関数プロトタイプはなんとなくわかった
              static System.ReadOnlySpan[char] GetFileNameWithoutExtension(System.ReadOnlySpan[char] path)
  4. クラスのGetMethods()でも調べることができる 
    
            [System.IO.Path].GetMethods() | 
              Where-Object Name -eq 'GetFileNameWithoutExtension' | 
              foreach {
                $_ | Format-List Name, ReturnType
                $_.GetParameters() | Format-Table ParameterType
              }  

              Name       : GetFileNameWithoutExtension
              ReturnType : System.String
              ParameterType
              -------------
              System.String

              Name       : GetFileNameWithoutExtension
              ReturnType : System.ReadOnlySpan`1[System.Char]
              ParameterType
              -------------
              System.ReadOnlySpan`1[System.Char]
  5. まとめ

    各クラスのスタティックメソッドを調べるには、①まずはクラスをパイプでGet-Memberに渡してどんなスタティックメソッドがあるかを調べる、②次に知りたいスタティックメソッドを深堀するという手順になる 

    
            #まとめると
              ① [クラス名]の持つメソッドをGet-Memberで調べる  
                    [クラス名] | Get-Member -Static -MemberType Method
                        ↓
              ② 調べたいメソッドが見つかれば深堀する          
                    [クラス名] | Get-Member -Name 対象のメソッド名 -Static
                        または
                    [クラス名] | Get-Member -Name 対象のメソッド名 -Static | Format-List *
