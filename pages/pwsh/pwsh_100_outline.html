PowerShellって何

  • PowerShellはCLIツール

    PowerShellは、WindowsServer2008 R2/ Windows7から標準実装されたCLIツール。2006年にPowerShell 1.0がリリースされた（当時WindowsXpには標準ではなくパワーキットで追加でインストール）

    バージョンの確認方法は、自動変数「$PSVersionTable」に設定されている値を見ればバージョンが分かる。また、Get-Hostコマンドレットでもバージョンを確認することができる 

    
            #// $PSVersionTableでバージョンを確認してみる
            PS> $PSVersionTable
            結果の例）

            #// Get-Hostコマンドレットで確認する例

  • PowerShellは動的型付け言語

    動的型付け言語なので型の宣言はしなくてもいい。変数に値を代入すると型が類推されて設定される。また、明示的に指定することも可能。この場合は角かっこで型指定する。
    例：[String]$hoge = "1020"

  • PowerShellでは、大文字小文字を区別しない

    Cmd.com、Cmd.Exeの流れを考えると、まぁそうかなって感じ。特にない

  • コマンドレットで操作

    コマンドレットはPowerShellにおけるコマンドのこと（日常会話ではコマンドでも通じるけど本当はコマンドレット）。コマンドレットは綺麗な整理ができており、統一感のある設計になっている。

    • 動詞-名詞 の表現に統一されている

      これにより多数あるコマンドレットを初見でも大体どんなことをするものか想像できるようになっている。例えば「Copy-Item」で考えてみると「Copyする」「Itemを」となるので、何らかのコピー処理を行うコマンドレットであることが推察できる。

    • オプションは「-」をつけて指定する

      全部ハイフンで始めることに統一されているので「/」とか「--」とかで悩まなくてもいい。例：「-Force」とか

  • PowerShellはオブジェクト指向で「.NETオブジェクトを返す」

    これが一番でかい特徴。従来のCmd.exeやUnixのシェルは、コマンド結果としてテキストデータを返してくる（そら、昔はオブジェクト指向の概念がないからしゃーない）。1つのコマンド結果をパイプで次のコマンドに渡す場合、次のコマンド実行のために前段のコマンド処理結果（テキスト）を次のコマンドのために整形する必要がある。
    しかし、PowerShellのコマンドレットはオブジェクトを返すのでパイプで後続コマンドにもオブジェクトが渡される。なので渡された先で好きなように加工すればいい。
    つまり、後続のコマンドのためにテキストデータを加工する必要がない（というかオブジェクトが返ってきている） 

    
            # .NETオブジェクトを返す例

            PS> Get-Childitem | Where-Object {$_.Length -ge 1MB}	      
            #// このスクリプトは、Get-Childitemでディレクトリ内の一覧を取り、その結果をパイプで次のコマンドレットに渡している
            #// この時、.NETオブジェクトで渡され、$_でオブジェクトを受け取っている。で、.Lengthプロパティでサイズをフィルタしている
            結果）                                                        #// 
            Mode                 LastWriteTime         Length Name        
            ----                 -------------         ------ ----
            -a---          yyyy/mm/dd    hh:mm        1906254 hoge1.txt
            -a---          yyyy/mm/dd    hh:mm        2906254 hoge2.txt
            ...
  • Monad（モナド）

    元々の英語の意味は、単一体や原子などの意味。PowerShellの開発コード名。2006年にPS1.0がリリース

  • Windows Powershell と PowerShell Core

    PowerShell Coreは、2018年1月にMicrosoftが発表したPowerShellの新しいエディション。クロスプラットフォーム対応でWindows以外のOSでも使える。
    また、Windows PowerShell（こっちはWindows用のPowershell）は開発終了しておりもう伸びしろがない。なので、MicrosoftはPowershell Coreを勧めているみたい。例えば、Windows Powershell を起動すると以下のようなメッセージが出る
    「新しいクロスプラットフォームの PowerShell をお試しください https://aka.ms/pscore6」

    WindowsPowershellとPowerShell Coreの2つがあり少し混乱する（最初の設計時にマルチプラットフォームで考えていたらこうならんかったのになぁと思う。自分的にはMSの失敗かな）

    • Windows PowerShellの起動方法： Win+R → PowerShell
    • PowerShell Coreの起動方法： Win+R → pwsh

    このページでは「PowerShell」は、マルチプラットフォーム対応の「PowerShell Core」を意味しています
