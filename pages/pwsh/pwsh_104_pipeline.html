パイプ（パイプライン）

パイプ（パイプライン）とは

パイプ（パイプライン）とは「|」により、左辺のコマンドレットの結果を右辺に渡す機能です。コマンドレットA | コマンドレットB のように複数の処理をつなげて全体として複雑な処理を実現しています。この例の場合、コマンドレットAの結果をコマンドレットBに渡してAの結果をBで処理した結果という機能が実現できています

これはPowerShell独自の機能ではなく、シェルが一般的に備えている基本的な機能かと思いますが使いこなすと便利です。（以下パイプ）

パイプの動作イメージ

例）パイプを使わず変数を経由して次の処理を行う


          > $files = Get-ChildItem -File    # $filesには複数のファイルオブジェクトが代入される
          > foreach ($file in $files) {     # $files変数を介して、foreach文で１つずつ処理
            Write-Host $file.FullName
          }

例２）パイプを使って例と同様な処理を行う


          > Get-ChildItem -File | ForEach-Object {$_.FullName}

例２はパイプを使ってGet-ChildItemの結果を次のコマンドレットに渡していますが、この時パイプにはどのように渡されるかを正しく理解しないと混乱すると思います（自分がそうだった）

自分は最初、Get-ChildItemの結果のファイル達全体のオブジェクトのかたまりが渡されると思っていましたが、これは間違いです。

つまり、列挙可能なもの（１つずつ取り出せるもの。配列やコレクションなど）をパイプに流す場合、１つずつ渡されるようになっています

  1. Get-ChildItem -File で、ファイルAのオブジェクトが取得される
  2. ファイルAのオブジェクトがパイプで ForEach-Objectに渡され、そのスクリプトブロックに記述されている処理が実行される
  3. Get-ChildItem -File で、ファイルBのオブジェクトが取得される
  4. ファイルBのオブジェクトがパイプで ForEach-Objectに渡され、そのスクリプトブロックに記述されている処理が実行される
  5. ・・・全部のファイルオブジェクトに対して繰り返される

そうすると配列をパイプに渡す場合も、配列要素が１つずつ渡されるということになります（列挙可能だから）。以前、Get-Memberを使って配列オブジェクトのメンバを調べた 時に意図した動作にならなかったのは、このパイプの性質のためだったということです

パイプの動作イメージの疑問

列挙可能なオブジェクトをパイプに渡す場合、オブジェクトが1つずつ渡されるということはわかったのですが、そうすると別の疑問がでてきました（これは、ForEach-Objectの理解不足によるものだったのですが）

パイプで1つずつ渡すのであれば、ForEach-Object を使わなくてもいいんじゃない？ というのが当時の疑問でした

つまり、1つずつ渡されることが繰り返されているので、パイプ動作自体がループのようになっているため、ForEach-Objectを書く意味が分からなかったということです

テスト１

これはそもそも文法上エラー。$_自動変数はスクリプトブロック内でしか使えない自動変数なので、この書き方自体ができませんでした


            > Get-ChildItem -FIle | $_.FullName    # $_はこのような書き方はできないので文法レベルで間違ってる・・

テスト２

これは意図した動作になった。やっぱりForEach-Objectは使わなくてもいいんじゃね？（ちがう）

この時、Write-Hostには引数が何もないけど、ファイルオブジェクトN が渡されておりそれを表示しています。これだけだったらForEach-Objectを使わなくても同じですが、複数の事を実行したければやっぱりForEach-Objectが必要になります。


            > Get-ChildItem -FIle | Write-Host

ForEach-Objectを使わないと複数の事は書けない


            > Get-ChildItem -File | {  # ForEach-Objectを使わないでスクリプトブロックを書こうとしたらエラーになった
            >> $count++
            >> Write-Host $count
            >> }
            ParserError:
            Line |
              1 |  Get-ChildItem -File | {
                |                        ~
                | Expressions are only allowed as the first element of a pipeline

ForEach-Objectを使うと複数の事を書ける


            > Get-ChildItem -File | ForEach-Object {
            >> $count++
            >> Write-Host $count
            >> }
            1   # ForEach-Objectを使うと正しく動作した
            2
            3
            ...
