コマンドレットオプションの色を変える方法

コマンドレットオプションの色の問題

コマンドレットオプションの色の問題とは

コマンドラインからコマンドレットを実行する場合、「-xxx」というオプションをつけて指定する事が多々あります。この時、デフォルトの色が背景色の黒に近いグレー色なので、見えにくいという問題がありました。

初めてPowerShellを使った時は、いろいろな事を知らなかったので、問題解決するまでしばらくストレスでした

ちなみに、ここに記述している解決方法は当時見つけた方法と違う気がするのですが、昔の資料が無いのと、これで問題解決するので一旦解決方法として残しておこうと思います

現在の色設定を確認する

現在、オプションがどのような色に設定されているかを確認する方法が「Get-PSReadLineOption」というコマンドレットです。これで「ParameterColor」がオプションに指定されている色です


          > Get-PSReadLineOption
          #// このコマンドレットでコマンドラインの設定が分かる（色以外にもいろいろな設定がされている）
          EditMode                               : Windows
          AddToHistoryHandler                    : System.Func`2[System.String,System.Object]
          HistoryNoDuplicates                    : True
          HistorySavePath                        : C:\Users\xxx\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
          HistorySaveStyle                       : SaveIncrementally
          ...
          #// この辺から色に関する設定がわかる
          CommandColor                           : "`e[93m"
          CommentColor                           : "`e[32m"
          ...
          OperatorColor                          : "`e[90m"
          ParameterColor                         : "`e[90m"     #// ParameterColorがオプションの色を指定している
          ...                                                   #// もともとはこの色は「グレー」になっていた

解決方法

この問題は「ParameterColor」の色がグレーに設定されていたからです。なので、この設定を見やすい色に変えたらいいです。変更は「Set-PSReadLineOption」コマンドレットで行います


          #// ParameterColorではなく「Parameter」に変更したい色を設定する
          >  Set-PSReadLineOption -Colors @{Parameter = "`e[96m"}

この設定は、このセッション中だけ有効なので、PowerShellを閉じると設定が消えてしまうので、恒久的に変更した五場合は、$Profileに「Set-PSReadLineOption -Colors @{Parameter = "`e[96m"}」を追加しておけばいい

※しかし、自分の環境では$Profileには追加していないのに、変更した設定がずっと有効になっている（なんで？）
