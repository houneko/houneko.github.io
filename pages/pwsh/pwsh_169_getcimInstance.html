Get-CimInstanceとは

Get-CimInstanceは、Windows専用のコマンドレットで、CIM（Common Information Model）を通してWindowsの内部情報を取得することができます。

CIM（Common Information Model）とは、WMI（Windows Management Instrumentation：これもCIMベースで作られたWindows仕様モデル）の後継の概念モデルで、PCやハードウェアの個別な情報を共通の形で表現した仕様・仕組みです

CIMは、DMTFという団体が策定した標準仕様であり、Windowsだけのための仕様ではないです。Windows PowerShellでは、WMIを使うケースがありましたが、現在はCIMが推奨されています

Get-CimInstanceと同じようなコマンドレットで、Get-WmiObjectがありますがPowerShell Coreではサポートされていないです。Get-CimInstanceは、Windows PowerShellでもサポートされています

  1. 例1）コマンドレットの処理時間を測定 
    
              # 例）コマンドレットの処理時間を測定
            # Get-Commandの処理時間を測定した結果。日、時、分、秒、・・と各単位ごとに処理時間が返ってくる
            > Measure-Command {Get-Command}
            Days              : 0
            Hours             : 0
            Minutes           : 0
            Seconds           : 0
            Milliseconds      : 460
            Ticks             : 4605306
            TotalDays         : 5.33021527777778E-06
            TotalHours        : 0.000127925166666667
            TotalMinutes      : 0.00767551
            TotalSeconds      : 0.4605306
            TotalMilliseconds : 460.5306        
            # 例）複数のコマンドレットを測定することもできる
            # Get-CommandとGet-ChildItemの2つを測定した例。また、TotalSecondsプロパティだけ表示させている
            > (Measure-Command {Get-Command; Get-ChildItem}).TotalSeconds
            0.4452348
  2. 例2）ブロック処理の処理時間を測定 
    
            # ループ処理ブロックを指定した例
            > (Measure-Command {
            >> for ($i=0; $i -lt 10000; $i++) {
            >> write-host $i
            >> }
            >> }              
            6.3306243
  3. 例3）ps1ファイルの処理時間を測定 
    
            # スクリプトファイルを指定した例。*.ps1ファイルを指定することもできる
            > (Measure-Command {..\..\MyCmd\INTEST_Get-MyHoge.ps1}).TotalSeconds
            237.9020867
  4. 例4）外部コマンドの処理時間を測定 
    
            # 外部コマンドの処理時間を測定
            > (Measure-Command {cmd /c fc .\measureTImeTest.ps1 .\old-measureTImeTest.ps1}).TotalSeconds
            0.1124901

Get-Dateで簡易測定

精度は落ちますが、自分が自作スクリプトでよく使う方法は、Get-Dateを使ったものです。プログラムの先頭と最後にGet-Dateで時間を取得しその差分で処理時間を表示したりしています


          $startTime = Get-Date    # ← [DateTIme]::Nowメソッドでもいい
            ...
            ...
          Write-Host ("done.. {0:N2} 秒" -f ((Get-Date) - $startTime).TotalSeconds)

          done.. 0.35 秒 のように表示される
