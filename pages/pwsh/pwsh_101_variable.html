PowerShellの変数

PowerShellの変数は、3つのタイプがあります。これは自動変数、環境設定変数（これも自動変数の1つ。ユーザ設定変数とも言う）、ユーザ変数です。

PowerShellは動的型付け言語なので、変数宣言に型指定しなくてもいいが（内部的には.NETの型があるし、明示的に型指定することも可能）、変数名のルールとして以下がある。後半にあげたものは仕様として可能なだけで一般的には使うメリットは無い（こんな変数があると読みにくなるだけだし、チームでやっていたらドン引きされると思うで）

  • 変数名は「$」で始める。例：$myVersion
  • 変数名には、英字とアンダーバーが使用できる
  • 数字の変数名も可能（だけど可読性や誤解を考えると使わない方がいい）、例：$12Neko
  • 予約語も変数名に使える（だけど紛らわしいので使わない方がいい）、例：$if
  • 2バイト文字も使用できる（だけど可読性が下がるので使わない方がいい）、例：$猫

PowerShellの本当の型。PowerShellは.NETオブジェクトを対象としているので本当の型は.NET形式の型となるが、通常はエイリアスが使われている

型を調べる方法

  • 変数名をGetType()メソッドで調べる方法

    PowerShellは全てが.NETオブジェクトなので変数もオブジェクトになっている。このため変数自身の型を調べるメソッドがある。それがGetType()メソッド

    
            PS> $name = "Neko"     #// $name変数に文字列「Neko」を代入
            PS> $name.GetType()    #// GetType()メソッドで型を調べる
            結果）
            IsPublic IsSerial Name      BaseType
            -------- -------- ----      --------
            True     True     String    System.Object
  • [型名]をFullNameプロパティで調べる方法 
    
            PS> [int].FullName     #// int型のFullNameプロパティを表示
            System.Int32              #// intの本当の型は、System.Int32 であることが分かる
