PowerShellの実行方法

PowerShellを使いだすと、自分の仕事をプログラムにしていつでも実行できるようにしたくなると思います（まぁよくある話）。これは自作のスクリプトファイル（*.ps1）や関数（関数も*.ps1ファイル内に書く）を作ることで実現できるのですが、それを使うにあたり少しめんどくさい手続きがいります。

バッチファイルであれば、パスが通った所に置けばどのパスからも実行できるが、ps1ファイルはパスが通った所にあっても、そのパスまで行って指定するか、フルパスで指定しないといけない（「Profile.ps1」を使えばこのめんどくささは回避できる）

PowerShellの実行方法は、ps1スクリプトを実行する方法と、関数を実行する方法があります。

スクリプトで実行する方法

スクリプトで実行する方法

Powershellのスクリプトを実行する方法

  • 「そのスクリプトがあるフォルダでスクリプトファイルを実行する」
  • 「別のフォルダからスクリプトファイルのフルパスを指定して実行する」

の2つの方法がある（この2つの方法しかない）。

パスが通った所にこのps1ファイルを置いていていも、そのps1ファイルがあるフォルダまで移動するか、そのps1ファイルをフルパスで指定してあげないと実行できません

そうすると、このps1スクリプトを実行しようと思うと、この2つの方法のいずれかで実行しないといけないので面倒。これを解消するようしたものが「Profile.ps1」という起動時に実行されるスクリプトである

「runTest.ps1」ファイルの作成 

        #////////////////////////////////////////////////
        # runTest.ps1
        #/////////////////////////////////////////////////
        [cmdletbinding()]
        param([String]$name)

        # //----------------------------------------
        # //関数 testFuncAのプロトタイプ宣言
        function script:testFuncA {
          [cmdletbinding()]
          param([String]$arg)
          Write-Host "write $arg from testFuncA"
        }

        # //----------------------------------------
        # //関数 testFuncBのプロトタイプ宣言
        function script:testFuncB {
          [cmdletbinding()]
          param($arg)
          write-host "write $arg from testFuncB"
        }
  
        # //----------------------------------------
        # // testFuncA、testFuncBをコール
        testFuncA -arg Neko
        testFuncB -arg Inu
スクリプト実行方法と結果 

        # -----------------------------------------------------------------------------
        # ps1ファイルがあるフォルダに行ってスクリプト名を指定して実行する方法
        PS C:\Temp\TestCode> .\runTest.ps1

        # -----------------------------------------------------------------------------
        # フルパスでスクリプト名を指定して実行する方法
        PS C:\> C:\Temp\TestCode\runTest.ps1

        結果）
        write Neko from testFuncA   # ← スクリプト実行で、testFuncA が呼び出されている
        write Inu from testFuncB    # ← スクリプト実行で、testFuncB が呼び出されている

内部の関数を指定して実行する方法

内部の関数を指定して実行する方法

内部の関数を指定して実行する場合、「PS> 関数名 引数」では実行できない。これはなんでかというと、Powershellのセッションにはこの関数はロードされていないから。ps1スクリプトの実行が終わると消えてしまう。


        PS> testFuncA -arg Usagi
        結果）
        以下のようにエラーになる。エラーメッセージを見ると testFuncA関数が認識されていないことが分かる
        tstfunca: The term 'tstfunca' is not recognized as a name of a cmdlet, function, script file, or executable program.
        Check the spelling of the name, or if a path was included, verify that the path is correct and try again.

じゃ、どうやって呼び出すかは以下のように.ドットソースでps1スクリプトをロードする。これで関数名を指定して実行ができるようになる 


        PS>  . .\runTest.ps1       # ←「ドット スペース ドット」でスクリプト名を指定する。これでロードされる
        PS> testFuncA -arg Usagi   # ← ドットソースでロードしたので「関数名を直接呼べる」ようになる

        結果）
        write Usagi from testFuncA    # ← testFuncA関数が呼び出しできていることが分かる

関数もスクリプトがあるフォルダまで降りていくかフルパスで指定して、ドットソースでps1ファイルをロードしてやっと関数名で実行できるようになる。これは使い勝手が悪い。なので関数名で実行するケースも「Profile.ps1」という起動時に実行されるプロファイルスクリプトを利用している
