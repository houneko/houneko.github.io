Write-Debugで配列要素をデバッグ表示する方法

配列要素のデバッグ表示

配列要素のデバッグ表示する時に発生した問題と対応方法

あるデバッグ作業で、スクリプトに渡されたオプション引数を確認しようと思った時に意図しない動作となりました。

仮に配列変数が$Hogeだったとして「Wrie-Debug $Hoge」だと$Hogeの型が表示されてしまい、$Hogeの各要素は表示されません。このため$HogeをパイプでOut-StringしてそれをWrie-Debugで表示するようにすればうまくいきます


          #//
          #// TEST Program
          #//
          [Cmdletbinding()]
          param(
            [Int]$intNumber,
            [Switch]$swHoge,
            [String]$stName
          )
          #// 意図してるのは、この変数の要素を表示して欲しいのに
          #// 以下の書き方だと、$PSBoundParameters変数の型名が表示されてしまう
          Write-Debug ('$PSBoundParameters = ' + $PSBoundParameters)
          #// 以下の書き方にする各要素が表示される
          Write-Debug ('$PSBoundParameters = ' + ($PSBoundParameters | Out-String))

          #// 実行
          > .\mytest2.ps1 -intNumber 10 -swHoge -stName Neko -Debug
          
          #// Write-Debug ('$PSBoundParameters = ' + $PSBoundParameters) の結果
          #// $PSBoundParametersの型が表示されてしまっている
          DEBUG: $PSBoundParameters = System.Management.Automation.PSBoundParametersDictionary
          
          #// Write-Debug ('$PSBoundParameters = ' + ($PSBoundParameters | Out-String)) の結果
          #// 正しく要素が表示された！
          DEBUG: $PSBoundParameters =
          Key       Value
          ---       -----
          intNumber    10
          swHoge     True
          stName     Neko
          Debug      True
