PowerShellでやりたい事を実現させるには

PowerShellはコマンドレットで操作するので、コマンドレットを知らないと処理が書けない。でもコマンドレットってどのようなものがありどう使うのか？自分がしたい事を実現するコマンドレットは何なのか？などが最初の壁になると思います。これは自分で探して理解をつけていくしかないのかなと思いますが、自分はこんな感じで理解していったという話です。

付け焼き刃で分かった気になるよりも、なんで？なんで？を突き詰めて行った方が近道では？と思います。昔のことわざの「急がば回れ」は良く言ったものです

例：今実行中のサービスを調べたい

とりあえず、今実行中のサービスを調べたいとなったとして、どうやって実現するか

  1. Get-Service でサービスが調べられることを思い出す

    PowerShellは、動詞-名詞で統一された構造になっているので、Get-系であることと「Service」という名詞で、Get-Serviceを思いつく

    と言っても全く最初だと思いつくも何もないので、全く最初の場合は、とりあえず「Get-Command」を覚えてください。Get-Commandで、コマンドレット一覧が出てくるので、GetとServiceなどのキーワードでそれっぽいコマンドレットを見つける

  2. Get-Serivce で何が取れるかを、Get-Member を使って調べる

    Get-Serive | Get-Member -MemberType Property を実行

    
              > Get-Serive | Get-Member -MemberType Property
              
              Name                MemberType Definition
              ----                ---------- ----------
              BinaryPathName      Property   System.String {get;set;}
              CanPauseAndContinue Property   bool CanPauseAndContinue {get;}
              CanShutdown         Property   bool CanShutdown {get;}
              CanStop             Property   bool CanStop {get;}
              ・・・
              StartupType         Property   Microsoft.PowerShell.Commands.ServiceStartupType {get;set;}
              Status              Property   System.ServiceProcess.ServiceControllerStatus Status {get;}
              UserName            Property   System.String {get;set;}
  3. それっぽいやつで、Statusというプロパティがあることがわかる

    Definitionの内容を見ると、System.ServiceProcess.ServiceControllerStatus型 のStatus{} という関数でget という処理をしていることがなんとなくわかる。System.ServiceProcess.ServiceControllerStatus型は .NETを勉強しないとわからんけど名前からサービスのステータスの型っぽいのがわかる。
    でこれをgetしているので、このステータスをみたらいいじゃねってのが見えてくる

  4. Statusというプロパティがどんな値を持つかをGet-Helpで調べる 
    
              > Get-Help Get-Service -Online

    そうするといろいろな説明の中に、Statusプロパティの説明があるのでそれを見ると「サービスの Status プロパティは、状態の名前が整数値を表す列挙値です。」とあり、このプロパティでサービスの状態が確認できるのが明確となる。

    もう少し説明を調べると、この列挙型の詳細は別のリンクになっており、ServiceControllerStatus 列挙型のところで説明されていることがわかる

    名前空間:System.ServiceProcess

    アセンブリ:System.ServiceProcess.ServiceController.dll

    この列挙型は数値でサービスの現在の状態を表しており以下となっていることがわかった

    名前 値 意味
    ContinuePending 5 サービスの継続は保留中。 Win32 のSERVICE_CONTINUE_PENDING定数と同じ
    Paused 7 サービスは一時中断。 Win32 のSERVICE_PAUSED定数と同じ
    PausePending 6 サービスの一時中断は保留中。 Win32 の SERVICE_PAUSE_PENDING定数と同じ
    Running 4 サービスは実行中。 Win32 の SERVICE_RUNNING定数と同じ
    StartPending 2 サービスは開始中。 Win32 の SERVICE_START_PENDING定数と同じ
    Stopped 1 サービスは実行されていません。 Win32 の SERVICE_STOPPED定数と同じ
    StopPending 3 サービスは停止中。 Win32 の SERVICE_STOP_PENDING定数と同じ
  5. StatusプロパティがServiceControllerStatus列挙型で、列挙名かがわかった

    この中の「Running」となっているサービスが実行中のものなのでこれを表示させればいいことがわかる

  6. Get-Serviceで、Statusが「Running」のサービスを表示させる 
    
            > Get-Service | Where {$_.Status -eq "Running"}

            Status   Name               DisplayName
            ------   ----               -----------
            Running  AarSvc_fb89259     Agent Activation Runtime_fb89259
            Running  AdobeARMservice    Adobe Acrobat Update Service
            ・・・
            ・・・
