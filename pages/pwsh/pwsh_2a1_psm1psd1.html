psm1ファイルとpsd1ファイル

psm1モジュールファイル

psm1

モジュールファイルの拡張子はps1ではなく「psm1」となります。このファイルは関数の集まりで部品集みたいなファイルです。これらの関数は、外部に公開するものとしないものをプログラマが決めることができます。
公開する関数は、Export-ModuleMemberコマンドレットで関数名を指定したら外部から参照することが可能になります

psm1ファイルの構造

モジュール化の仕組み、構成

モジュール化は、モジュールファイル「*.psm1」とマニフェストファイル「*.psd1」それと、モジュールを使うスクリプトファイル「*.ps1」で構成されています。

モジュールフォルダとファイルの構造

モジュールフォルダの下に「psm1ファイル」と「psd1ファイル」を置きます。フォルダ名とファイル名は同じにします。同じでなくても動作的には問題は無いですが、慣習的に同じにしています（名前が同じだとわかりやすいメリットもある） 


          #サンプル例
          …\myModules
            ├ My.System.Processor フォルダ          … モジュール用フォルダ
                ├ My.System.Processor.psm1ファイル  … モジュールファイル
                ├ My.System.Processor.psd1ファイル  … モジュールマニフェストファイル

psd1マニフェストファイル

psd1

psd1ファイルは、マニフェストファイル。psm1モジュールファイルを説明するためのメタファイル。このファイルは無くてもモジュール関数を作成する事が可能です。

psd1ファイルの自動作成

psd1ファイルは、自動作成するコマンドレットが用意されています。それが「New-ModuleManifest」です


          > New-ModuleManifest -Path .\MYTESTModule.psd1 -RootModule MYTESTModule.psm1 -Author "HouNeko"

ただしこの生成ではフルスペックのマニフェストファイルとなるので、必要ないキーも多々あります。このため自分的にはフォーマット確認などに使う程度かなと思います。最低限必要なキーは「RootModule」と「FunctionsToExport」かなと思います

psd1ファイルの構成例


          #
          <#############################################################################################################
          # マニフェストファイル： My.Hardware.Memory.psd1
          #   ModuleVersion         このモジュールバージョン
          #   GUID                  [GUID]::NewGuid()
          #   Author                作成者
          #   Description           説明
          #   PowerShellVersion     PowerShellの最低バージョン
          #   RootModule            ロードするモジュール名
          #   FunctionsToExport     公開する関数
          #   CmdletsToExport       公開するコマンド（通常空でいい）
          #   VariablesToExport     公開する変数
          #   AliasesToExport       公開するエイリアス名
          #   RequiredModules       依存モジュール（あれば）
          #############################################################################################################>
          @{
            ModuleVersion     = '1.00.00'
            GUID              = 'xxxxxx-.....'
            Author            = 'HouNeko'
            Description       = 'Hardware系のMemory関係のユーティリティモジュール'
            RootModule        = 'My.Hardware.Memory.psm1'       #// RootModuleでモジュールファイルを示す  
            FunctionsToExport = @(                              #// 公開する関数はfunctionsToExportキー（配列）で
              'Get-MyMemoryInfo',                               #// 指定する
              'Get-MyMemoryUsage'
            )
            CmdletsToExport   = @()
            VariablesToExport = @()
            AliasesToExport   = @()
            RequiredModules   = @()
          }
