Get-Memberとは

Get-Memberは、他のコマンドレットが返す結果（つまりオブジェクト）が、どんなメンバを持っているかを調べるためのコマンドレットです。このため、あるコマンドレットの結果をパイプで渡してもらうという使い方が多いかなと思います。 


        > cmdlet-A | Get-Member   ← cmdlet-Aの結果（オブジェクト）のもつメンバを表示する
        > cmdlet-B -Option 値 | Get-Member    ← cmdlet-Bを-Option 値で実行した結果のオブジェクトが持つメンバを表示する
        > cmdlet-C | Get-Member -MemberType Property ← cmdlet-Cの結果オブジェクトが持つ、プロパティメンバだけ表示する

自分はよく間違うのですがGet-Memberは、「コマンドレットのメンバでなく、コマンドレットの結果オブジェクトのメンバ」を調べるためのものです。コマンドレットの結果はオブジェクトなので、そのオブジェクトがどんなプロパティやメソッドを持っているかがわかれば、さらにプロパティ値から情報を取得できたりできます（どんなプロパティやメソッドを持っているか知らないと、その先のことができないのでこのコマンドレットは結構便利） 


        # Get-ChildItemの結果オブジェクトがどんなメンバを持っているか（大量にある）
        > Get-ChildItem | Get-Member
        Name                      MemberType     Definition
        ----                      ----------     ----------
        LinkType                  CodeProperty   System.String LinkType{get=GetLinkType;}
        Mode                      CodeProperty   System.String Mode{get=Mode;}
        Target                    CodeProperty   System.Collections.Generic...
        ....
        # Get-ChildItemの結果オブジェクトがどんなメンバを持っているか（大量にある）
        > Get-ChildItem | Get-Member

配列をGet-Memberに渡すと

配列などのコレクションをパイプでGet-Memberに渡すと、配列要素オブジェクトのGet-Memberになります。配列オブジェクト自体のGet-Memberを意図していたら結果が違うので注意が必要

パイプの動作についても参照してみてください


        > $myarray = @("neko", "inu", "usagi", "sika")     # $myarray配列
        > $myarray | Get-Member -MemberType Properties     # $myarray配列のプロパティメンバを調べたい意図
        Name   MemberType Definition                          # あれ？思ったより少ないな…
        ----   ---------- ----------
        Length Property   int Length {get;}

        # $myarray | Get-Memberは、$myarrayの要素がパイプを通って渡されるので、$myarray[n] のメンバを調べていることになる
        # つまり、以下と同じ
        > $myarray[0] | Get-Member -MemberType Properties
        Name   MemberType Definition                          
        ----   ---------- ----------
        Length Property   int Length {get;}

        # $myarray[0].getType() はStringなので、以下と同じでもある
        > "mystring" | Get-Member -Membertype Properties
        Name   MemberType Definition                          
        ----   ---------- ----------
        Length Property   int Length {get;}

じゃ、配列自体のメンバを調べたい場合はどうするのか？

Get-Memberには、パイプで渡す以外にも-InputObjectというオプションがあるのでこれで配列を指定すればいい


        > Get-Member -InputObject $myarray -MemberType Properties    # -InputObjectオプションで「$myarray」配列を指定
        Name           MemberType    Definition                         # 配列オブジェクトが持っているプロパティ
        ----           ----------    ----------
        Count          AliasProperty Count = Length
        IsFixedSize    Property      bool IsFixedSize {get;}
        IsReadOnly     Property      bool IsReadOnly {get;}
        IsSynchronized Property      bool IsSynchronized {get;}
        Length         Property      int Length {get;}
        LongLength     Property      long LongLength {get;}
        Rank           Property      int Rank {get;}
        SyncRoot       Property      System.Object SyncRoot {get;}  

        # Countというプロパティがあるのが分かったので、これを表示させてみる。
        # また、Countは AliasPropertyで、Lengthのエイリアスであることもわかる
        > $myarray.Count
        5                       # 配列要素数を持っているプロパティ
