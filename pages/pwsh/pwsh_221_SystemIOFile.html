System.IO.Fileクラスのスタティックメソッド

[System.IO.File]::ReadAllBytes() と [System.IO.File]::WriteAllBytes()

[System.IO.File]::ReadAllBytes() と [System.IO.File]::WriteAllBytes()

ファイルをリードするコマンドレットやメソッドは複数あるが、[System.IO.File]::ReadAllBytesは、データをバイトイメージでリードするスタティックメソッド。
例えば、Get-Contentもファイルをリードするが、文字コードや改行コードを変えてしまう可能性がある。しかし、[System.IO.File]::ReadAllBytesはバイトイメージでリードするので文字コードや改行コードを変えることはない。

業務でcsvファイルを扱うことがあるがこの時文字コードや改行コードを変えると意図した結果が得られなくなるのでGet-Contentは使えないということもある。そういう時はこのスタティックメソッドが使える

サンプル例

このサンプルでは、UTF8で改行コードがLFのCSVファイル「Test.csv」をバイトリードしてバイトライトした結果とテキストリードしてテキストライトした結果を比べてみるためのものです


        [cmdletbinding()]
        param()

        Write-Debug('start TEST-ReadAllBytes')
        $inputCsv = Join-Path -Path $PSScriptRoot -ChildPath "Test.csv"
        $outputBinCsv = Join-Path -Path $PSScriptRoot -ChildPath "CopiedBin.csv"
        $outputTextCsv = Join-Path -Path $PSScriptRoot -ChildPath "CopiedText.csv"
        write-debug('$inputCsv = ' + $inputCsv)

        # ///////////////////////////////////////////////////////////////
        # // [System.IO.File]::ReadAllBytes()でバイトリードする
        $myBytes = [System.IO.File]::ReadAllBytes($inputCsv)                # ReadAllBytes()でバイトリード
        write-debug('$myBytes = ' + $myBytes)                               # このデバッグでバイトリード内容が表示してみる
        [System.IO.File]::WriteAllBytes($outputBinCsv, $myBytes)            # WriteAllBytes()でバイトデータをライト出力する

        # ///////////////////////////////////////////////////////////////
        # // Get-Contentでリードする
        $work = Get-Content $inputCsv                                       # 比較用のGet-Contentでのテキストリード
        Write-Debug('$work = ' + $work)                                     # 比較用のSet-Contentでのテキストライト
        Set-Content $outputTextCsv $work

        Write-Debug('end TEST-ReadAllBytes')

以下は実行時のデバッグ表示画面

$myBytesは、バイトリードされた値が格納されているのがわかる。また$workは、Get-Contentでリードした時点で文字化けしていることがわかる（これはテストした環境がWindows PowershellなのでSJISでリードしているから）

このスクリプト結果は、以下のようになっておりReadAllBytesでバイトリードした内容をWriteAllBytesでバイトライトした結果は文字コードや改行コードは変更されていないが、Get-ContentとSet-Contentでテキストリード、テキストライトしたものは文字コード、改行コードが変わっている

[System.IO.File]::OpenRead()

[System.IO.File]::OpenRead()

このメソッドは、指定されたファイルをリードオンリーで開き、そのファイルを扱うためのファイルストリームを返す。

OpenReadスタティックメソッドはファイルをストリームとして扱うためのファイルオープン。$fsはファイルストリームとして扱えるためのオブジェクト。なので、$fs.Readメソッドは指定したバイト数でのリードができる

ファイルをストリームとして扱うことで、そのファイルの文字コードを意識しなくてもいいようになる（単にバイト列のかたまりとして扱う）

ちなみに、ファイルハンドルとファイルストリームは違う

ファイルハンドラ

ファイルハンドラは、OSが管理しているファイルの識別子IDみたいなもの

ファイルストリーム

ファイルストリームは、ファイルハンドラを含む高レベルなファイルを操作するためのオブジェクト。オブジェクトなのでプロパティやメソッドがある


        # $file.FullNameファイルに対するファイルストリームObjが生成される
        $fs = [System.IO.File]::OpenRead($file.FullName)
        # .NETの固定長バッファを作成する
        $buffer = New-Object byte[] $bytesCount                   
        # $fsファイルストリームのReadメソッド。$bufferにリードし、リードした結果を$readBytesCounte
        $readBytesCount = $fs.Read($buffer, 0, $bytesCount) 
        # $fs.Closeで、$file.FullNameファイルをクローズする
        $fs.Close()
