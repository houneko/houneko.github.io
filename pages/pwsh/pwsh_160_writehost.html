Write-Hostコマンドレット

Write-Hostは、名前から想像できるように画面に引数で指定したデータを表示してくれるコマンドレット。自分の使い方は、あるプログラム（hoge.ps1）を作った時に処理状況をその時の変数値と一緒に表示する場合によく使っている。同様のコマンドレットに「Write-Debug」もあるがこればデバッグモードになっている時に出力されるもので開発時に使う。そう考えるとWrite-Hostは通常動作に使うということになるのかな

Write-Hostコマンドレットの使い方

自分の使い方は上に書いた通りプログラム中に「xx処理中： $hoge変数 = 値」のように途中結果を表示したりすることが多い。ログみたいな感じ。で、この時Write-Hostに渡す引数指定でよく、どうするんやったっけ？と忘れるのでここで整理しておく

以下の結果を見ると「Write-Host ('name = ' + $msg)」が一番使い勝手がいいかな

  • Write-Host ('name = ' + $msg)

    この結果は、一番イメージにあっているのでこれを使っている。丸かっこで囲んで'変数名 = 'と「+」でその変数名を指定する。
    表示結果は「name = Neko-desu」

  • Write-Host 'name = ', $msg

    この結果は「name =  Neko-desu」となる。=の後にもう１つスペースが入っている。これは「'name = '」と「$msg」の2つの引数がスペースをはさんで表示される。1つ目のスペースは「= 」で、もう1つはWrite-Hostが2つ目の引数の間に入れている。
    これが意図したものであればいいが、スペースが2個あるのでなんかバランスが悪い

  • Write-Host ('name = ', $msg)

    上の「Write-Host 'name = ', $msg」と一緒

  • Write-Host 'name = ' + $msg

    この結果は、「name =  + Neko-desu」となる。つまり「+」も引数データとみなされている。これだと使えん

  • 
            > $msg = "Neko-desu"
            > Write-Host ('name = ' + $msg)
            結果）name = Neko-desu                  # 一番意図したもの

            > Write-Host 'name = ' , $msg
            結果）name =  Neko-desu                 # イコールの後に余計なスペースが入っている
            > Write-Host ('name = ' , $msg)
            結果）name =  Neko-desu                 # 同上
            > Write-Host 'name = ' + $msg
            結果）name =  + Neko-desu               # 同上に加えて「+」も表示されてしまっている

Write-Hostコマンドレットのいろいろなパラメータ

コマンドレットのオプション。いろいろあるが使ったりすることがあるものをまとめておく

  • -Foregroudcolor と -Backgroundcolor

    文字の色や背景の色を変えることができるオプション。以下の例は文字色を赤で、背景の色をグレーにしている

  • -NoNewline

    改行しないでWrite-Host出力を行う

    
            # -NoNewlineオプションがあるのでこの表示は改行されない
            Write-Host ('No newline : ') -NoNewline              
            Write-Host ('2nd Msg') -Foregroudcolor Green
