新モジュールの作成手順

新しいモジュール関数の作成手順をサンプルモジュール関数「Get-MyProcessorInfo」作成を例にして説明します

  1. myModulesフォルダの下にモジュールフォルダ、psm1ファイル、psd1ファイルを作成

    「My.System.Processor」モジュールを作成し、psm1ファイルとpsd1ファイルを作成する。psm1ファイル、psd1ファイルは空でいい

    モジュール名（フォルダ）は、各自のルールで作成したらいいです。自分の場合は、「My」というプリフィクスを付けて、その次に「ジャンルとしてSystem系」、最後に「その系内の項目としてProcessor」という名前にしています 

    
              …\myModules
                ├ My.System.Processor フォルダ          … モジュール用フォルダ
                    ├ My.System.Processor.psm1ファイル  … モジュールファイル
                    ├ My.System.Processor.psd1ファイル  … モジュールマニフェストファイル

  2. モジュール関数「Get-MyProcessorInfo」をpsm1ファイル内にコーディングする

    以下のコーディングはテンプレート

    
              function Get-MyProcessorInfo {
                <#                                 # ← Get-Help用のコメントブロックを最初に書く
                  Get-Help用のコメントブロック
                #>

                [CmdletBinding()]                     # ← 無くても可
                Param()

                $MYNAME = ...                         # ← 自分用のモジュール名等。無くても可
                $MYVERSION = ...

                $myProcessor = Get-CimInstance Win_32_Processor   # ← これが本体
                $myProcessor | ForEach-Object {
                  [PMCustomObject]@{                              # ← PMCustomObject型にキャストした辞書
                    自作プロパティ1 = $_.xxx                      # 独自構造体型にメンバを設定するみたいなもん
                    ...
                    自作プロパティN = [PMCustomObject]@{          # ← PMCustomObject型の中にPMCustomObject型メンバを
                      自作プロパティN1 = ...                      # を格納することも可能（構造体メンバみたいなもん）
                      ...
                    }
                  }
                  ...
                }
              }  
              # 次の関数定義（あれば）
              function Get-HogeHoge {...}
              function ...

              #// 関数の公開設定は「psd1」ファイルで一元化し、psm1ファイルでは設定しない
  3. psd1ファイルを作成

    マニフェストファイルとして大事な項目はとりあえず以下。これを辞書として作成する

    
              @{
                ModuleVersion     = '...'                       # ← バージョン
                GUID              = '...'                       # ← [GUID]::NewGuid()で作成可能
                RootModule        = 'My.System.Processor.psm1'  # ← psm1モジュールファイル名
                FunctionsToExport = @(                          # ← 公開する関数名の配列
                  'Get-MyProcessorInfo'
                )
                ...
              }
  4. インポート用スクリプト myScript\Import-MyModules.ps1（基本的に変更不要）

    インポート用のスクリプトファイル「Import-MyModules.ps1」は、myScriptフォルダの下に作っており、このps1スクリプトファイルを実行すると指定したモジュールフォルダ（今はmyModulesフォルダ）のパス下にある全部の「psd1」ファイルをImport-Moduleする

    このため、このファイルは変更しなくてもいい

    
              $moduleRoot = "C:\Users\....\myModules"     # ← このパスが変わらなければ変更不要
              Get-ChildItem $moduleRoot -Directory | ForEach-Object {
                $psd1 = Join-Path $_.FullName "$($_.Name).psd1"
                Write-Debug ("import file = $psd1")
                if (Test-Path $psd1) {
                  Import-Module $psd1 -Force              # ← $moduleRoot配下のpsd1ファイルを全部Import-Moduleする
                }                                         # なので、新規に作ったモジュールもインポートされる
              }                                           # ∴ このファイルは変更不要
  5. $Profileファイル（基本的に変更不要）

    $Profileは、PowerShellが起動する時に実行される特別なファイルです

    $Profileは、自分用にカスタマイズしており以下の処理をおこなっています

    • myFunctionsフォルダ

      myFunctionsフォルダには自作関数があり、$Profile内でこれらの関数を全部ロードしている。これでコマンドラインから関数名でコマンドのように実行できるようになっています

    • myScriptフォルダ

      myScriptフォルダには自作スクリプトがあり、$Profile内でこれらのスクリプトをスクリプト名で実行できるようにAlias化しています。これでコマンドラインからスクリプト名で実行できるようになっています

    • Import-MyModules.ps1

      $Profile内にて、ドットソースでImport-MyModules.ps1を実行しています。Import-MyModules.ps1はmyModulesフォルダ配下のpsd1を全部インポートするしので、新規のモジュールも自動的にインポートされます

  6. 完成

    この時点で、コマンドラインからモジュール関数をコマンドのように呼び出す事が可能になっています

    
              > Get-MyProcessorInfo
              ProcessorName        : AMD Ryzen 5 7430U with Radeon Graphics
              Manufacturer         : AuthenticAMD
              Architecture         : @{typeNo=9; typeName=x64}
              MaxClockSpeedMHz     : 2301
              CurrentClockSpeedMHz : 2010
              Cores                : 6
              LogicalProcessors    : 12
              L2CacheKB            : 3072
              L3CacheKB            : 16384
              Socket               : FP6
              Virtualization       : True

    また、この時点で他のスクリプトにインポートして使う事が可能になっています

    
              #// TEST Program
              [Cmdletbinding()]
              param()
              Import-Module .\mymodules\MY.System.Processor\My.System.Processor.psd1  # psd1ファイルのインポート

              #// call 
              Get-MyProcessorInfo   # モジュール関数のコール
