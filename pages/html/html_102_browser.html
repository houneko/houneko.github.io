先行実装とベンダープレフィックス

HTMLやCSSの技術はW3Cによって策定されており、草案が出るとワーキンググループが議論を行い勧告となります。この時、策定中の機能はWebブラウザに先行実装されて検証されます。先行実装は各ブラウザのメーカが判断するので、ブラウザによっては先行実装されているが別のブラウザでは先行実装されていないという状況があります

このため、ベンダープレフィックス（ベンダープレフィックスは今はほとんどつかわれていない） という仕組みを使って正式仕様と区別できるようにしていました。

ベンダープレフィックス
プレフィックス 対応するブラウザ
-webkit- Chrome、Safari
-moz- Firefox
-ms- Internet Explorer、旧Edge
-o- Opera

ベンダープレフィックスの書き方

linear-gradient関数が新機能だった頃の例。ユーザが使っているブラウザ（ユーザエージェント）に合わせて複数のベンダープレフィックスを書き、最後に標準仕様のlinear-gradient関数を書く

この例で、ブラウザがChromeだったとすると、以下のようにCSSが解釈されます。これでChromeでは「-webkit-linear-gradient()が実行されるということです。また、標準仕様のlinear-gradientが本当に実装されたら、最後のbackgroudの設定は理解できるようになっているので、最後に指定されている方が使わるようになります

  1. 最初の「-webkit-linear-gradient(...)は、理解できる
  2. 次の「-moz-linear-gradient(...)は、理解できない。よって無視される
  3. 次の「-ms-linear-gradient(...)は、理解できない。よって無視される
  4. 次の「-o-linear-gradient(...)は、理解できない。よって無視される
  5. 次の「linear-gradient(...)は、理解できない。よって無視される

          .button {
            /* Chrome, Safari */
            background: -webkit-linear-gradient(top, #4CAF50, #2E7D32);

            /* Firefox */
            background: -moz-linear-gradient(top, #4CAF50, #2E7D32);

            /* IE10 */
            background: -ms-linear-gradient(top, #4CAF50, #2E7D32);

            /* Opera */
            background: -o-linear-gradient(top, #4CAF50, #2E7D32);

            /* 標準仕様 */
            background: linear-gradient(to bottom, #4CAF50, #2E7D32);
          }
