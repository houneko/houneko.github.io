HTMLの基本事項

HTMLの基本的な構造

開始タグと終了タグでマークアップする

HTMLは、<xx>～</xx> のタグのペアで表示したい情報を囲んで表現している。この時、<xx> を開始タグ、</xx> を終了タグと言う。表示したいテキスト等を開始タグと終了タグで囲んで文字を表現していくことをマークアップという

要素とコンテンツ

表示したいテキストを開始タグと終了タグで囲んでマークアップしていくことがhtmlでのソースコード作成になるけど、この開始タグと終了タグで囲んでものを「タグも含めて要素」という
以下の例は、pタグで囲んだ要素なので、p要素と言ったりする

また、開始タグと終了タグを除いた中身をコンテンツという


          <p>HelloWorld</p>   
          <!--  <p>HelloWorld</p> 全体を要素という-->

DOCTYPE宣言

HTMLコードの1行目は、このDOCTYPE宣言を書く。DOCTYPE宣言は、HTMLのバージョンを示すもので、HTML5や HTML4.x、XHTML1.0などがある

以下の例のように、HTML5はすごくシンプルになっている。逆にHTML4.01はこの時点え書くのがいやになりそうなめんどくささ。新規で書く場合はHTML5にすればいいので気にしなくてもいいけど、HTML5をきれいに整理してくれた人たちに感謝 


          <!-- HTML5のDOCTYPE宣言 -->
          <!DOCTYPE>

          <!-- HTML4.01のDOCTYPE宣言 -->
          <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN"
            "http://www.w3.org/TR/html4/loose.dtd">

おまけ）VSCodeで開発する場合は、 Emmet が効くので手で入力しなくてもDOCTYPE宣言（他の全体構造も含めて）のコードができる

基本構造

htmlファイルには、必ず「html要素」「head要素」「body要素」が含まれる。html要素が全体を包んだ状態になっておりhtmlドキュメントを示している。html要素の中にhead要素とbody要素があり、head要素にはそのhtmlファイルの情報（メタデータ）を書き、bodyにブラウザに表示されるコンテンツを書く 


          <!-- htmlが全体を包んでいる -->
          <html lang="ja">
                              
            <!-- htmlの中にheadがある。headはメタ情報を書く要素でブラウザには表示されない -->
            <head>                
                ...                     
            </head>
          
            <!-- htmlの中にbodyがある。bodyの内容がブラウザに表示される -->
            <body>
                ...
            </body>

        <html>

html要素

html要素は、htmlタグで囲まれた部分でDOCTYPE宣言の後に書く。htmlタグはhead要素やbody要素を格納する土台的なコンテナの役割になっている

lang属性をつけるのが推奨となっている（なのでEmmetでもlang属性がついているのかな）。この属性が指定されていると読み上げソフトがこの言語にあった音声で読み上げてくれる。
