C言語の開発環境をつくる

C言語の開発環境を作る

コンパイラのインストール

Mingw（ミンジーダブリュー）をインストールする。Mingwは、Windows環境でGCCコンパイラを使うための環境です。昔はMicrosoftのCコンパイラを使っていたと思うけど、ググるとMingwが出てくるのでこれで環境を作ります

インストールやパスの設定は、巷のページを参照してください（すみません、省力化ということで・・）

「Windowsで始めるC言語！MinGWだけで超シンプルな開発環境を作る方法」を参考にインストールとパス設定をしました。Mingwのインストールや設定は、自分が理解しやすいページですすめたらいいです


インストール、環境設定の確認

インストール、環境設定が終われば設定等が正しいかを確認します（コンパイラにパスが通っており、コマンドラインからコンパイラを呼び出せるかを確認する）


  PS C:\> gcc --version
  
  #コンパイラのインストール、設定が成功していたら以下のようなメッセージが出ます

VSCodeの設定

  1. VSCodeにC言語の拡張機能を追加

    Microsoftの「C/C++ Extension Pack」をインストールします

  2. C/C++ Edit Configurations設定

    コマンドパレット（Ctrl+Shift+P）で「C/C++ Edit Configurations」を開き、コンパイラとインテリセンスの設定を行います

    これで.vscodeフォルダに「c_cpp_properties.json」というCの設定ファイルができます

    このjsonファイルの中に「compilerPath」というキーと「intelliSenseMode」というキーがあるのでそれぞれ以下のように設定します。

    コンパイラのパスは、Where gcc.exeで探して自分にあったパスを指定します

    
  {
      "configurations": [
          {
              "name": "Win32",
              "includePath": [
                  "${workspaceFolder}/**"
              ],
              "defines": [
                  "_DEBUG",
                  "UNICODE",
                  "_UNICODE"
              ],
              "compilerPath": "C:/Program Files/mingw64/bin/gcc.exe",   /*コンパイラのパス*/
              "intelliSenseMode": "windows-gcc-x64"                     /*インテリセンスの設定*/
          }
      ],
      "version": 4
  }
  3. VSCodeを再起動
  4. launch.jsonを作成

    「c_cpp_properties.json」ファイルがある.vscodeフォルダにlaunch.jsonファイルを作成します（このファイルが無いとデバッグできない） 

    
  {
    "version": "0.2.0",
    "configurations": [
      {
        "name": "C Debug (gcc)",
        "type": "cppdbg",
        "request": "launch",
        "program": "${fileDirname}\\${fileBasenameNoExtension}.exe",
        "cwd": "${fileDirname}",
        "MIMode": "gdb",
        "miDebuggerPath": "C:/Program Files/mingw64/bin/gdb.exe",
        "externalConsole": false,
        "preLaunchTask": "build c"
      }
    ]
  }

Cプログラムのビルドで実行

その前に1点注意事項：Mingw、gdb、VSCodeの環境では、パスに2バイト文字は使わない方がいいです。最初パスに2バイト文字があり、F5で実行しようとしてもパスを見つけらずエラーになってしまいました。 


  #include <stdio.h>
