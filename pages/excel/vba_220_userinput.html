ユーザ入力エリアに入力された情報を取得する

「ユーザ入力エリアに入力された情報を取得する」とは

自分が以前書いていた方法は、対象の複数セルを定数定義しておき、その先頭行アドレスから最後の指定セルの最終行アドレスをループで回していたのですが、あんまり使い勝手が良くないことで、もっといい書き方無いかなと思っていました。

サンプルコード


        '// セルのイメージ
        '// A列には説明文があり、B列にユーザの設定を入力してもらう仕様
        '// B1セルからB4セルがユーザの入力するセル
              A                                 B                                 C
        -------------------------------------------------------------------------------
        1     猫フォルダ名を入力してください    ***   ← ***がユーザ入力値
        2     犬フォルダ名を入力してください    ***  
        3     鳥フォルダ名を入力してください    ***  
        4     兎フォルダ名を入力してください    ***  
        
        '//
        '// 以前の書き方
        '//   この書き方だと定義が増えていくので、面倒だし最後の定義が変わったらループの終了値の
        '//   指定も変えないといけないので、変更に弱い
        '//
        Const USER_INPUT_CAT_FOLDER       As String = "B1"
        Const USER_INPUT_DOG_FOLDER       As String = "B2"
        Const USER_INPUT_BIRD_FOLDER      As String = "B3"
        Const USER_INPUT_RABBIT_FOLDER    As String = "B4"
        Dim lp                            As Long

        For lp = Range(USER_INPUT_CAT_FOLDER).Row To Range(USER_INPUT_RABBIT_FOLDER).Row
          ...
        Next

セル範囲を指定してループを回す方法

このテクでは、ユーザ入力するセル範囲をString型で指定し（例えば、USER_INPUT定数に「B1:B4」）、Range(USER_INPUT)の範囲を、For Eachで取り出すという処理です。
この書き方だったら、変更があってもループ処理は変えなくてよく、定数定義の範囲を変えるだけでいい


      '/////////////////////////////////////////////////////////////////////////////////////////
      '// このテクニックを使った書き方
      '// この書き方はセル範囲を定義しループはその範囲で回す。
      '// 変更があれば範囲定義だけ変えればいいので変動にも強いし可読性もいい
      '/////////////////////////////////////////////////////////////////////////////////////////
      Const USER_INPUT As String = "B1:B4"
      Dim myCell As Range

      For Each myCell In ws.Range(USER_INPUT)
      If myCell.Value <> "" Then
        '// ここにユーザが何か入力していた場合の処理を書く
      EndIf
      Next
