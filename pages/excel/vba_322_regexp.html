VBAのライブラリ：正規表現

正規表現とは

特定の文字列で検索するとその文字列しか探せないですが、正規表現パタンで検索するとそのパタンにマッチする複数の文字列を検索することができます

正規表現はVBAの機能ではなくコンピュータを使った検索・置換方法です。正規表現

VBScript.RegExp

VBAには標準で正規表現を持っていないので、CreateObject("VBScript.RegExp")で正規表現クラスのインスタンを生成することで使えるようになります

正規表現インスタンスの生成


          Option Explicit
          Dim regEx                   As Object
          
          '//---------------------------------------------------------------
          '//正規表現インスタンスの生成
          Set regEx = CreateObject("VBScript.RegExp")

正規表現のパタンマッチ結果

正規表現結果はコレクションに格納されます


          Option Explicit
          Dim regEx                   As Object   '//正規表現インスタンス
          Dim Matches                 As Object   '//パタンマッチ結果を受け取る変数
          Const TEST_STRING           As String = "123-ABC 456-DEF"
          
          '//正規表現インスタンスの生成
          Set regEx = CreateObject("VBScript.RegExp")
          '//パタン定義
          regEx.Pattern = "(\d+)-([A-Z]+)"        '//数字が1つ以上 - 英字が1つ以上のパタン
          regEx.Global = True                     '//全ての一致にマッチさせる（Falseの場合は最初にマッチしたものだけ）
          regEx.IgnoreCase = False                '//大文字小文字を区別する（False：無視しない）
          '//正規表現パタンマッチの実行
          Set Matches = regEx.Execute(TEST_STRING)
          If Matches.Count > 0 Then            '//マッチがあればカウントがある
            Debug.Print Matches(0).Value
          EndIf

          '//Matchesへの格納結果イメージ
          Matches(0)
            ├ .Value      ... 123-ABC
            ├ .SubMatches
                ├ (0)     ... 123
                ├ (1)     ... ABC
          
          Matches(1)
            ├ .Value      ... 456-DEF
            ├ .SubMatches
                ├ (0)     ... 456
                ├ (1)     ... DEF
