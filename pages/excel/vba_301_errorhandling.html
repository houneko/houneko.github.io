エラーハンドリング

Functionプロシージャ毎にErrorHandler等のラベルを作り、On Error Goto ErrorHandler のようにエラー処理をする

なんでエラーハンドリングした方がいいか？例えば、ある処理を行う前に「Application.Calculation = xlCalculationManual」で再計算を止めて何らかの処理を実行し、終われば「Application.Calculation = xlCalculationAutomatic」に戻すようなケースで途中の何等かの処理中にエラーが起きてマクロが停止したら、Excelが手動計算になってしまっているので、ユーザはExcelが壊れたと思ってしまう

エラーハンドリングを入れていた方が良いと思われるケース

  • ブックオープン処理があるようなマクロ
  • ファイル保存などがあるようなマクロ
  • Calculation設定変更があるようなマクロ
  • EnableEvents変更があるようなマクロ
  • 画面のScreenUpdating変更があるようなマクロ

一般形


          Private Function DoSomethingFunc(...) As Boolean
            '// ここがtryブロックみたいなもの
            On Error Goto ErrorHandler 
            
            ...メイン処理
            ...
            DoSomethingFunc = True
            Goto Finally

          ErrorHandler：
            '// ここがcatch相当のブロック
            ...エラー処理（オープンしたブックのクローズとかの後始末）
            DoSomethingFunc = False

          Finally:
            '// 正常処理でも通るブロック。Finallyブロック相当
            ...正常形でも行う後始末
          End Function
