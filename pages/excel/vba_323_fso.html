ファイルシステムオブジェクト

VBAでは、CreateObject("Scripting.FileSystemObject")を実行することでファイルシステムオブジェクトを生成して、そのオブジェクトが持っているプロパティやメソッドでファイル操作を行う事ができます 


          '/////////////////////////////////////////////////////////////////////
          '// ファイルシステムオブジェクトの生成
          '/////////////////////////////////////////////////////////////////////
          Dim fso     As Object
          Set fso = CreateObject("Scripting.FileSystemObject")
          
          '/////////////////////////////////////////////////////////////////////
          '// fsoを使ってフォルダの存在を調べる方法
          '/////////////////////////////////////////////////////////////////////
          If fso.FolderExists(調べるフォルダ名) Then
          'フォルダが存在していた場合の処理
          Else
          'フォルダが無かった場合の処理'
          EndIf
          
          '/////////////////////////////////////////////////////////////////////
          '// fsoを使ってフォルダ内のファイルを取得する
          '/////////////////////////////////////////////////////////////////////
          Set Folder = fso.GetFolder(フォルダ名)
          For Each file In Foloder.Files
          'フォルダ内のファイル fileに対する処理
          Next
