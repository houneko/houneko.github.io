wsl2のインストールとアンインストール

wsl2のインストール

PowerShellを管理者権限で起動し以下の手順を実行してインストールする

インストール手順

  1. wslコマンドで現在有効なディストリビューションを確認する

    「wsl --list --online」でリストを確認する

    
            > wsl --list --online
            
            #いろいろなディストリビューションがあることがわかる
            NAME                            FRIENDLY NAME
            Ubuntu                          Ubuntu
            ...
            openSUSE-Tumbleweed             openSUSE Tumbleweed
            ...
            kali-linux                      Kali Linux Rolling
            ...
            Debian                          Debian GNU/Linux
            ...
            ...
            Ubuntu-20.04                    Ubuntu 20.04 LTS
            ...
  2. wslコマンドでインストール実行

    「wsl --install」または「wsl --install -d Ubuntu-20.24」のようにディストリビューションを指定する。指定しない場合は、Ubuntuの最新版が指定されたことになる。
    「wsl --install -d Ubuntu-20.24」の例だと、Ubunt 20.24LTS版（LTSは長期サポート版）がインストールされる

    
            > wsl --install
  3. 再起動
  4. wsl2がインストールされたかを確認する

    VERSIONが2ならWSL2

    
            > wsl -l -v
              NAME      STATE           VERSION
            * Ubuntu    Running         2
  5. Ubuntuのユーザとパスワードを設定する

    Ubuntuにログインしたら、一応バージョンを見てみる「lsb_release -a」

    
            % lsb_release -a
            No LSB modules are available.
            Distributor ID: Ubuntu
            Description:    Ubuntu 20.04 LTS
            Release:        20.04
            Codename:       noble
  6. パッケージのリポジトリを国内にする

    パッケージは、プログラムと設定ファイルをまとめたもの。デフォルトでは海外のリポジトリとなっているのでアクセス先を国内に変更する

    パッケージは、 /etc/apt/source.list に記載されている

    
            % cd /etc/apt
            % ls
            source.listがある

            % sudo sed -i.bak -e "s/http:\/\/archive\.ubuntu\.com/http:\/\/jp\.archive\.ubuntu\.com/g" sources.list
  7. インストールされているソフトウェアの更新 
    
            % sudo apt update
            % sudo apt upgrade -y
  8. インストールしたいパッケージの検索

    例）sudo apt search language-pack-ja

    
            % sudo apt search 検索したいパッケージ名
  9. ソフトウェアのインストール

    例）sudo apt install パッケージ名, …

    
            % sudo apt install パッケージ名
  10. インストールされているソフトウェアを調べる

    which 調べたいソフトウェア名

    
            % which python3
            /usr/bin/python3
  11. 日本語環境にする 
    
            % sudo update-locale LANG=ja_JP.UTF-8
            % exit
            % echo $LANG
              ja_JP.UTF-8
            % date
              yyyy年mm月dd日
  12. タイムゾーンをJSTにする

    GUIの地域選択画面になるのでカーソルキーでアジアを選び、TABキーで了解。東京を選び、TABキーで了解。
    JSTが表示されたらOK 

    
            % sudo dpkg-reconfigure tzdata
            % date
              yyyy年mm月dd日 …JST
            % exit
            % echo $LANG
              ja_JP.UTF-8
            % date
              yyyy年mm月dd日
  13. manの日本語化

    「man ls」で、lsの説明が日本語になっていたら成功

    
            % sudo apt install manpages-ja manpages-ja-dev
            % man ls
  14. X-Windowの利用

    「&」をつけてバックグラウンドで実行する

    
            % sudo apt install x11-apps -y
            % xeyes &
  15. gnome-terminalをインストールする

    自分は使わない感じなのでインストールする場合は以下の参考ページを参照

参考ページ：「Windows 11上でのWSL2＋Ubuntu 20.04LTSの初期設定」

wsl2のアンインストール

PowerShellを管理者権限で起動し以下の手順を実行してアンインストールする

アンインストール手順

  1. インストールされているwsl2ディストリビューションを確認する

    wslコマンド「wsl -l -v」でwsl2ディストリビューションを確認する。以下の例だと、Versionが2なのでWSL2で、Ubuntuがインストールされている

    
              > wsl -l -v
              NAME      STATE           VERSION
              * Ubuntu    Running         2
  2. WSL2を停止する

    wslコマンド「wsl --shutdonw」でwsl2を停止させる

    
              > wsl --shutdown
  3. Ubuntuを削除する

    wslコマンド「wsl --unregister Ubuntu」でUbuntu を削除する

    
            > wsl --unregister Ubuntu
  4. WSL2を無効化する

    dismコマンドでWSL2を削除する

    これでWSL2のアンインストールは完了です

    
            > dism.exe /online /disable-feature /featurename:Microsoft-Windows-Subsystem-Linux /norestart
            > dism.exe /online /disable-feature /featurename:VirtualMachinePlatform /norestart
