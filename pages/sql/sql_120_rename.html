SQLの列名の変更

AS句で別名を設定する

AS句で列名を別の名前で定義することができる。「元の列名」AS「新しい列名」で指定する。ただし元のテーブルの列名は変更されない。メモリ上のテーブルで列名を別名で表示させている。
書式） 元の列名 AS 新しい別名


        select
          customerCode	as "顧客コード",    -- 元の列名「customerCode」が表示上は「顧客コード」と表示される
          customerName	as "顧客名"         -- 元の列名「customerName」が表示上は「顧客名」と表示される
        from                                -- 元のテーブルの列名は変更されないので注意
          customers
        ;

元の列名に演算を行い、その結果をAS句で別名にする

列名priceに演算を行い、その結果を別名として設定するようなケース。AS句の一般的な使い方だと思う。
普通のプログラミング言語だとこの演算結果を変数に代入して使うようなケースが考えられるけど、SQLでは変数という概念はないので、演算結果をAS句で別名に定義するのが一般的らしい（SQLによっては変数があるけど、仕様依存が大きいので使わない方が他のSQLでも動作しやすくなる） 


        select
          price * 1.08	as "税込み価格"     -- 元の列名を1.08倍して「税込み価格」として別名を設定する
        from                              
          customers
        ;

別名をつける時の注意事項

注意事項というほどではないが、SQLの列名の基本形は「英字で始まり英数字とアンダースコアのみ」
このため「日本語名」や「％」などの記号を使う列名は、ダブルクォーテーションで囲む必要がある
