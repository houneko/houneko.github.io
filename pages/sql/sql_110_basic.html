PostgreSQLのインストール

個人で使うSQLはいくつかあるが、PostgreSQLをインストールするケースをドキュメント化しておく

どのプラットフォームで、どのような方法でインストールかでいくつかのやり方に分かれるが、インストーラを使うやり方がWindowsユーザには一般的だと思う。他の方法等はまとめているページを探して参考にすればいい

「PostgreSQLをWindowsにインストールするには」などのページを参考

環境変数の設定

インストールが終われば、環境変数にパスを通しておく

環境変数Pathに「C:\Program Files\PostgreSQL\xx\bin」を追加すればいい。※xxはバージョン（例：15）を示すパス

パスを通せば、コマンドラインから「psql」コマンドが使えるようになる。例： psql --version

SQLの基本事項

SQL（Structure Query Language）

SQLはデータベースを操作するための言語で、Structure Query Language の略。構造化問合せ言語。非手続き型の言語である。

SQLの特徴

  • 多くの方言がある

    SQLは、ANSIの標準仕様があるけど、各SQLでの独自拡張があり1つのSQLコードが別のSQL仕様ではそのままでは動かないことも多いらしい。というか、ANSIの標準化があるんならそれに統一するのが普通では？

  • SQLは大文字、小文字を区別しない
  • 変数の概念はない（SQL仕様によってはあるが依存性が高くSQLでは使わない方がいいみたい）
  • RDBMSデータベースの用語
    • テーブル： 表のこと
    • レコード： 行のこと
    • カラム　： 列のこと
    • ビュー　： テーブルに対してある操作をした結果イメージ（物理的なものではない）
  • 出力順は規程されない

    あるテーブルから特定のカラムを取り出した時、順序はテーブルに記録されている順と異なる場合があるが、SQLでは順序が規程されていないので、これは正しい。

  • コメント文
    • 行コメントは、「--」で始める
    • ブロックコメントは、「/* ... */」
  • 文の終わりを「;」セミコロンで区切る

    文の終わりは「どのテーブルから、どのデータを、どういう条件で、〇〇する」という一連が文のかたまりとなるのでこの最後に「；」セミコロンをつける

SQLの書き方

SQLは、データベースを操作するための言語で、①〇〇する → ②どのテーブルから？ → ③どのデータを？ → ④どういう条件で？ という人間の思考順にSQLを構成する。つまり、この思考順にSQLという言葉で書けばいい。

  1. 〇〇する

    まずは「select」だけ書き、selectの中身がないまま「；」文を終わらせていい

    
              select          -- ① 「select」で、〇〇する。まずは、中身は無いまま「；」セミコロンで終わっていい
              ;
  2. どのテーブルから

    1で作成した骨子に「fromテーブル名」を追加する

    
              select        
              from            -- ② fromでどのテーブルから読み込むかを追加する
                MyDataTable   -- 
              ;
  3. どのデータを

    1、2の手順で作成した骨子に「どのデータを」を追加する

    
              select        
                nekoName      -- ③ 「nekoName列のデータを」を追加する
              from            
                MyDataTable   
              ;
  4. どういう条件で

    1、2、3の手順で作成した骨子に「どういう条件で」を追加する

    
              select        
                nekoName
              from            
                MyDataTable   
              where           -- ④「どういう条件で」を追加する
                age > 10
              ;

複数データ列を指定する

SQLは、複数の列を取得することができる（当然やろ）。この時、列名Aと列名Bと…を「,」カンマで区切ればいい。カンマ位置は決まっていないが、SQLを書く人は次の列名の先頭にカンマをつける方が多いらしい。


          select
            myName
            , myAge         -- 「,」カンマは次の列名の先頭に置くように書いている
            , myAddress     -- この例では、myName、myAge、myAddress の列をselectしている
            …

同じ列を複数回指定することもできる


          select
            myName
            , myAge         
            , myName        -- myName例は 2回 selectしている
            …
