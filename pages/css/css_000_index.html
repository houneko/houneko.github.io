CSS3のページ

このページはCSS3に関するページです。CSSは「Cascading Style Sheets」の略で、Webページの見栄えを指定するもの。大昔はHTMLだけでデザインなどの見栄えも記述するようなことがあったが、htmlは人間の文章をマークアップしてWebページにする役割、CSSはページのデザインを担うというように役割分担が明確化された。CSSが無かったら昨今の綺麗なページはできないので、CSSの功績は大きいと思います。
