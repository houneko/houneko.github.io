CSSのショートハンド記法

ショートハンド記法とは

例えば、marginプロパティは、margin-top、margin-right、margin-bottom、margin-leftとあり、個別に指定すると以下のようになります


    margin-top: 10px;       /* marginの上と下は同じ値 */
    margin-bottom: 10px;
    margin-right: 20px;     /* marginの左右は同じ値 */
    margin-left: 20px;

この例は、上下の値と左右の値が同じなのでショートハンドを使えば、以下のように書ける


    margin: 10px 20px;       /* marginの上下に10px、左右に20px指定したのと同じ */

ショートハンドの省略パタン

  • 値が１つのショートハンド

    この場合、全てのプロパティが同じ値を指定したので同じ意味になる

    
      /* 値が１つのショートハンド */
      margin: 10px;

      /* 以下と等価で全て10pxで指定したのと同じ */
      margin-top: 10px;
      margin-right: 10px;
      margin-bottom: 10px;
      margin-left: 10px;
  • 値が２つのショートハンド

    プロパティ: 値1 値2; のように値を2つスペースを空けて指定する方法。この場合、値1が上下の値を示し、値2が左右を指定している

    
      /* 値が２つのショートハンド */
      margin: 10px 20px;

      /* 以下と等価 */
      margin-top: 10px;
      margin-right: 20px;
      margin-bottom: 10px;
      margin-left: 20px;
  • 値が３つのショートハンド

    プロパティ: 値1 値2 値3; のように値を3つスペースを空けて指定する方法。この場合、値1が上、値2が左右、値3が下を示している

    
      /* 値が３つのショートハンド */
      margin: 10px 20px 30px;
  
      /* 以下と等価 */
      margin-top: 10px;
      margin-right: 20px;
      margin-bottom: 30px;
      margin-left: 20px;
  • 値が４つのショートハンド

    プロパティ: 値1 値2 値3 値4; のように値を4つスペースを空けて指定する方法。この場合、値1が上、値2が右、値3が下、値4が左を示している。値を4つ指定した場合、時計の12時から始まり、3時、6時、9時の位置のイメージになっている

    
      /* 値が４つのショートハンド */
      margin: 10px 20px 30px 40px;
  
      /* 以下と等価 */
      margin-top: 10px;
      margin-right: 20px;
      margin-bottom: 30px;
      margin-left: 40px;

いろいろなプロパティのショートハンド

ショートハンドが使えるプロパティはいろいろあり、paddingなどはmarginと同じで上下左右の方向で指定するが、方向で指定しないプロパティもある（当たり前）

  • borderプロパティのショートハンド

    borderプロパティは、border-width、border-style、border-colorがあり
