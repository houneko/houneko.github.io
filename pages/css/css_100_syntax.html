cssの基本的な書き方

このページは、CSS3の基本的な構造、書き方をまとめた章です。このページのCSSはCSS3のことです。
CSSは「Cascading Style Sheets」の略で、Webページの見栄えを指定するもの。大昔はHTMLだけでデザインなどの見栄えも記述するようなことがあったが、htmlは人間の文章をマークアップしてWebページにする役割、CSSはページのデザインを担うというように役割分担が明確化された。

CSSの基本の前の基本

親要素、子要素

htmlは、要素（開始タグから終了タグまでの一連のかたまり）は入れ子の構造となっている。これを親子で考えたものが親要素、子要素。CSSの設定をする場合、どこにCSSスタイルを適用するかを考えていくので親要素、子要素は理解しておく必要がある（複数の子要素や孫要素など指定方法がいろいろある） 


    <div>
      <p>Hogeです</p>
    </div>

    結果）
    この例だと、親は<div>、子は<p> ってこと（divの中にpがある）

CSSの基本

CSSの基本構造

CSSに記述している内容は「どこに」「何を」「設定する値」という形になっている。これをCSSの言葉に置き換えて宣言している。「どこに」に相当するのがセレクタ、「何を」に相当するのがプロパティ、「設定する値」が値となっている。 


  CSSの書式
  セレクタ {
    プロパティ: 値;
  }
  

  例）
  p {                 /* どこに     -> p要素に    */
    color: red;       /* 何を       -> 文字の色を */
  }                   /* 設定する値 -> 赤色にする */

CSSの記述場所

CSSの記述場所は3通りある。小さいページとか1ページだけとかの場合は、インラインスタイルやエンベディングスタイルでもいいが、何ページもあるような場合はリンキングスタイルじゃないときついと思う。全ページ同じ設定を記述したるわって根性がある場合でも、少し変えたいというような変更には柔軟に対応できないので、CSSは外部からリンクさせる方がいいと思う。

  1. インラインスタイル

    HTML内の要素に直接、style属性でCSSを書く方法。

    2.   
      <p style="color: red;">インラインスタイルでp要素を赤字に設定</p>
  2. エンベディングスタイル

    HTML内の<head>内に<style>要素を追加しCSSを書く方法

    3. 
      <head>
        <style>
          p {
            color: red;
          }
        </style>
      </head>
  3. リンキングスタイル

    CSSファイルを別に用意して、<head>内からリンクさせる書き方。href属性にCSSファイルのパスを指定する

    各ページからこのファイルをリンクさせれば、各ページで同じ設定が適用される（当たり前）。

    4. 
      <head>
        <link rel="stylesheet" href="../css/hoge.css">
      </head>
