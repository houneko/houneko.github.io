box-shadowプロパティ

box-shadowプロパティは、指定されたセレクタに影をつけるプロパティ

box-shadowプロパティの書式

セレクタ〇〇 { box-shadow: x方向 y方向 [ぼかし半径] [広がり] [色] [内側指定]; }

この書式カードは以下のCSSでデザインしている


    .format-card {
      width: 85%;
      max-width: 1200px;
      margin-left: 1em;
      margin-top: 0.5em;
      padding: 1em;
      border: 1px solid #ddd;
      border-radius: 10px;
      box-shadow: 2px 2px 6px rgba(0,0,0, 0.1);   /* これでカードに影をつけている */
      background-color: #e8f4fd;                  /* カードの背景色を薄い水色にしている */
    }

  • 値 x方向

    x方向は、box-shadowプロパティの必須な値で、影のx方向の向きと大きさを指定する。正の値だと右側に、負の値だと左側に影がつく。イメージで言うと正値の影は、対象要素の左上に光源があり右下に影がつくという感じ、負値だと右上に光源があり左下に影がつく


    例1は、x方向に+10px（y方向は+2px）
    例2は、x方向に-10px（y方向は+2px）

    x値が正の場合は右下に影ができ、負の場合は左下に影ができている（y方向はどちらも+なので下に影ができる）

  • 値 y方向

    y方向も、box-shadowプロパティの必須な値で、影のy方向の向きと大きさを指定する。正の値だと下に、負の値だと上に影がつく

  • 値 [ぼかし半径] [広がり] [色] [内側指定]

    これらの値はオプションで指定しなくても可。影のぼかし具合や色、内側に影をつけるなどを指定する
