positionプロパティ

positionプロパティとは

positionは、要素をどの位置に配置するかを指定するためのプロパティです。値の指定により何に対して位置を指定するかを決めることができます。また、要素を重ねて表示する時にも使えます

positionプロパティに設定できる値

名前 意味
static デフォルト値。topやleft等を指定しても位置は変えられない。このため、positionプロパティで、この値を使うメリットは無いと思います（自分は使わない）
relative 相対位置指定する。この相対は「本来の位置」からという意味であり、親要素からの相対ではないので注意！また、この要素の下の子要素の参照のベースとするためにも「relative」を使います
absolute positionプロパティがstatic以外で指定されている直近の先祖からの絶対位置指定
fixed 画面の決まった位置を直接指定（自分は使わない）

オフセット位置の指定方法

top/right/bottom/leftで指定します。この名前から何pxずらしてという指定になります。例えば「top: 16px;」なら、上から下に16pxの位置と指定していることになります。leftなら左から右にずらすという事です

relative値

relativeは、その要素が本来表示される位置を基準として、オフセット位置を指定するものです。以下の例は、p要素（position-test2クラス）を本来の位置から下に24px、右に32pxずらして表示させています


  <p class="position-test1">これが本来のp要素の位置</p>
  <p class="position-test2">相対位置をずらしたp要素の位置</p>
          

  .position-test1 {
    background-color: cadetblue;
  }

  .position-test2 {
    background-color: rgb(173, 247, 155);
    position: relative;                     /* relative値を設定 */
    top: 24px;                              /* 本来の位置に対して、上から24px下に指定 */
    left: 32px                              /* 本来の位置に対して、左から32px右に指定 */
  }
