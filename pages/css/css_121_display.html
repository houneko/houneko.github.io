displayプロパティ

displayプロパティ

displayプロパティは、各アイテムの画面レイアウト（縦に並べるとか横に並べるとか）を指定するプロパティ。このプロパティを使うとブロック要素をインライン要素のような配置にしたり、逆にインライン要素をブロック要素のように配置することができるようになる。指定する値（blockや、inline、inline-block、flex、・・）は多数あり、その設定値によりレイアウトの振る舞いが決まる。
※設定できる値は、VSCodeを使っていたらdisplayと入力したら候補が出るので確認できる

  • display: flex;

    displayプロパティに flex値を指定した場合、その要素はflexbox（フレックスボックス）となる

    flex（フレックスボックス）は、従来のfloatや、inline-blockでは難しかったレイアウト指定が簡単に実現できるようになる

    • おまけ：flexbox（フレックスボックス）とflex？

      flexbox（フレックスボックス）は、レイアウトの方式の名前みたいなもんで、それを指定する「値」がflex。なので、display:プロパティに、flexを指定したら、それはフレックスボックスのレイアウトが指定されたってこと

      • フレックスボックスは親コンテナの中に子アイテムという構成になっている

      例えば「flexbox-container」という親クラスを作り、このコンテナの中に各アイテムを定義する

    flex;（フレックスボックス）のサンプル例

    
        <!-- HTML -->
        <div class="flex-container">
          <div class="flex-item">ねこです</div>
          <div class="flex-item">いぬです</div>
          <div class="flex-item">うさぎです</div>
        </div>

    CSSの設定が無い状態でのデフォルトの表示： divタグは、block要素の性質を持つので各要素は親要素いっぱいの幅を持ち、次の要素は改行されて下に表示されている

    次に、CSSをあててみる

    「display:flex;」で flex-containerクラス全体をフレックスボックスにし、「flex-direction:row」でflex-containerコンテナの中身を横並びにする設定を行っている。
    この結果、divタグの要素（この例では、これがフレックスボックスの中のアイテム）が横並びになっている 

    
        .flex-container {
          display: flex;
          /* flex-directionプロパティのデフォルトはrowなのでこれは設定しなくても同じ */
          flex-direction: row;          
          background-color: #9ea4fc;
        }

    divタグはblock要素の性質を持つが、フレックスボックスの設定により横並びに表示されている

  • display: block;

    displayプロパティに block値を指定した場合、その要素はブロック要素のように扱われる。なので、この設定がかかっている場合、縦に並んで配置される。また幅は親要素の幅いっぱいに広がる

    block;のサンプル例

    
        <!-- HTML -->
        <body>
          <span>spanねこ1です</span>
          <span>spanねこ2です</span>
          <span class="test-displayBlock">blockねこ1です</span>
          <span class="test-displayBlock">blockねこ2です</span>
        </body>
        
    
        /* CSS */
        span{
          background-color: #f691fa;
        }
        .test-displayBlock{
          display: block;
          background-color: #9ea4fc;
        }

    このコードは、span要素に対して「display: block;」を設定している。
    通常のspanは、インライン要素の性質があるので横並びになっている（ピンク）が、block;設定したspan要素は縦に並んで表示されており幅も親要素の幅いっぱいになっている（ブルー）

  • display: inline;

    displayプロパティに inline値を指定した場合、その要素はインライン要素のように扱われる。なので、この設定がかかっている場合、横に並んで配置される。また幅はその要素の幅になる

    inline;のサンプル例

    
        <!-- HTML -->
        <body>
          <div class="test-displayInline">
            divねこ1です
          </div>
          <div class="test-displayInline">
            divねこ2です
          </div>
        </body>
        
    
        /* CSS */
        .test-displayInline{
          display: inline;
          background-color: #9ea4fc;
        }

    このコードは、div要素に対して「display: inline;」を設定している。
    これにより、divがインライン要素として扱われ、横に並んで表示されている

  • display: inline-block;

    displayプロパティに inline-block値を指定した場合、その要素はインライン要素のように横に並ぶが、各要素はブロック要素のように幅・高さ・余白が指定できる

    inline-block;のサンプル例

    
        <!-- HTML -->
        <body>
          <span class="test-displayInlineBlock">ねこです</span>
          <div class="test-displayInlineBlock">うさぎです</div>
        </body>
        
    
        /* CSS */
        .test-displayInlineBlock{
          display: inline-block;
          background-color: #9ea4fc;
        }

    このコードは、span要素もdiv要素も横並びにして、各要素をブロック要素のように表示している

  • display: grid;

    displayプロパティに grid値を指定した場合、その要素はグリッドレイアウトが可能となる

    グリッドレイアウトでは、ページを方眼紙みたいな縦横に箱があるイメージで扱うことができるようになります

    1. 親コンテナをgridに指定する

      親コンテナに display:grid; を指定する。これだけだとグリッドレイアウトになっているようには見えないが設定としてはできている（他のプロパティでグリッドレイアウトっぽくなる）

      
            <style>
              .container {display: grid; }    <!-- これでグリッドレイアウト設定になる -->
              .childs {border: 1px solid;}
            </style>
            <body>
              <div class="container">   <!-- このハコ内がグリッドレイアウトになる -->
                <div class="childs">グリッドレイアウトされる箱1</div>
                <div class="childs">グリッドレイアウトされる箱2</div>
                <div class="childs">グリッドレイアウトされる箱3</div>
                <div class="childs">グリッドレイアウトされる箱4</div>
              </div>
            </body>


      親コンテナをdisplay:gridで、グリッドレイアウトに指定しただけ。この状態での表示は縦に並んだままでグリッドには見えないが内部的にはグリッドレイアウトの設定はできている（グリッドレイアウトの他のプロパティ指定を追加したらいい）

    2. grid-template-columnsプロパティで横方向の（列の）数や幅などを指定する

      このプロパティはグリッドレイアウトの列数や幅を指定するプロパティ（列なので横方向のマス目の数や幅の指定になる）。repeat関数で指定することもできる

      このプロパティを親コンテナに指定する

      （※縦方向の数を調整する場合は、grid-template-rowsプロパティを指定する）

      
            <style>
              .container {
                display: grid;                    <!-- これでグリッドレイアウト設定になる -->
                grid-template-columns: 1fr 1fr;   <!-- 横方向は2つ -->
              }      
              .childs {border: 1px solid;}
            </style>

      1frは、fraction（割合）のことで、利用可能な領域を分割したうちの1つという意味。

      例えば、1fr 1fr 1fr; と3つ指定した場合は、3分割。1fr 2fr 1fr; であれば、最初が1/4サイズ、2つ目が2/4サイズ、3つ目が1/4サイズとなる


      親コンテナにgrid-template-columnsを入れて横方向は2列に指定したので、2列で折り返している。各列は1frになっているので、利用可能な領域を半分に分けて子アイテムに割り当てられている

    3. gapプロパティで子アイテムの間隔を指定する

      従来は、marginプロパティでアイテム間のスペースを指定していたが、marginは1つず指定しないといけないのと、最初と最後は個別に指定しないといけないし面倒だったけど、gapは子アイテム間のスペースをダイレクトに指定できるのでこちらの方が使い勝手がいい 

      
            <style>
              .container {
                display: grid;                    <!-- これでグリッドレイアウト設定になる -->
                grid-template-columns: 1fr 1fr;   <!-- 横方向は2つ -->
                gap: 1em;                         <!-- 子アイテム間のスペースを1emに指定 -->
              }      
              .childs {border: 1px solid;}
            </style>


      各子アイテム間に1em分のスペースができている
