repeat関数

repeat関数とは

repeat関数は基本的にはグリッドレイアウトのWebページでグリッドの列数や行数の繰り返しを指定する時に使う関数です

グリッドレイアウトの列数や行数は、grid-template-columnsプロパティや、grid-template-rowsプロパティで指定ができるが、いくつも書かないといけないなど面倒。この時、repeat関数が使える 


    <style>
      .container {
        <!-- これでグリッドレイアウト設定になる -->
        display: grid;                    
        <!-- 横方向は4つ（4列）にする -->
        <!-- repeat関数を使うと、1fr 1fr 1fr 1fr と指定するのと同じ -->
        <!-- grid-template-columns: 1fr 1fr 1fr 1fr;    -->
        grid-template-columns: repeat(4, 1fr);   
        <!-- 子アイテム間のスペースを1emに指定 -->
        gap: 1em;                         
      }      
    </style>

repeat関数(第1引数, 第2引数)

  • 第1引数は繰り返し回数を指定する

    
        /* 例１ */
        repeat(3, 100px);   /* 100pxの箱を3つ */
        /* 例２ */
        /* 第1引数がauto-fillの場合、空き領域に指定したサイズの箱が入るだけ並ぶ */
        repeat(auto-fill, 100px);   /* 100pxの箱を入るだけ */

  • 第2引数はサイズを指定する

    
        /* 例１ */
        repeat(3, 1fr);   /* 3分割した1つ分 */
        /* 例２ */
        /* minmax関数で最小値と最大値を指定する */
        repeat(3, minmax(100px, 1fr));   /* 最小100px、最大1fr */
