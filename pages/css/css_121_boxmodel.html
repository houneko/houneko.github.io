ボックスモデルの余白

余白は2種類ある

ボックスモデルにおける余白。余白は2種類あり要素の外側にあるのがmarginで、要素の内側にあるのがpaddingです（要素の外側、内側はborderを表示させるとわかりやすいです）
また、この余白には、-top（上）、-right（右）、-bottom（下）、-left（左）と4つ種類があります

サンプル例：marginは全部0px、paddingも全部0px


        <head>
          <style>
          p {
            /* 上から時計回りで個別指定できる。以下は、上 右 下 左 で指定している */
            margin: 0px 0px 0px 0px;
            padding: 0px 0px 0px 0px;
            background: pink;
            /* 要素の境界線を4pxの赤線で表示させる */
            border:solid 4px red;
          }
          </style>
        </head>
        <body>
          <p>ねこです</p>
          <p>Hoge</p>
        </body>

marginが0、paddingが0 のサンプル表示結果


このp要素は線（border）を赤で4pxにしているので、この線で囲まれた部分がp要素

marginが0なので、次の要素とくっついている

paddingが0なので、線内には空白がない

marginが10px、paddingが10px のサンプル表示結果


このp要素は線（border）を赤で4pxにしているので、この線で囲まれた部分がp要素

marginが10pxなので、次の要素との間（borderの外側）に空白ができている

paddingが10pxなので、線内には空白ができている

marginは相殺される

以下のサンプルは、p要素にmarginを40pxつけたものです。この例を見ると何か違和感がないでしょうか？

p要素の「ねこです」には下marginが40px、次のp要素の「Hoge」には上marginが40px指定されているので、合計80pxになるのでは？と思いませんか？でも見る限り、p要素「ねこです」と次のp要素「Hoge」の間の空白は、他の空白と同じ位しか空いていないです。

なぜか？これは、要素が前後に並びそれぞれのmarginが重なる時、どちら大きい方が使われるというルールがあるので、40px＋40pxで80pxの余白にならないためです


p要素の「ねこです」には下marginが40pxついている。また、次のp要素の「Hoge」には上marginが40pxついている

そうすると、40px + 40px で80px の空白ができるのでは？ なんで80pxにならないの？


この図のようにmarginが重なっている場合、大きい方が使われる

「ねこです」の下marginと「Hoge」の上marginが重なっているので、和にならずどちらか大きい方が使われる（例はどちらも40pxなので結果40px分の空白があく）

ボックスモデルの余白とWidth/Height

要素のWidth/Heightを指定した場合

要素のwidthとheightを指定すると、そのサイズはどこを指定したことになるか？paddingはその指定にふくまれるか？という疑問が出たのですが、これはwidthやheightにはpaddingは含まれません。

以下の例は、marginが40px、paddingが30px、widthが160、heightが80pxの設定です。またborderを4pxにしています

横幅は、= ボーダー 4 + padding 30 + width 160 + padding 30 + ボーダー 4 = 228px

縦は、= ボーダー 4 + padding 30 + height 80 + padding 30 + ボーダー 4 = 148px


        <head>
          <style>
          p {
            /* 上から時計回りで個別指定できる。以下は、上 右 下 左 で指定している */
            margin: 40px 40px 40px 40px;
            padding: 30px 30px 30px 30px;
            width: 160px;
            height: 80px;
            background: pink;
            /* 要素の境界線を4pxの赤線で表示させる */
            border:solid 4px red;
          }
          </style>
        </head>
        <body>
          <p>ねこです</p>
          <p>Hoge</p>
        </body>
