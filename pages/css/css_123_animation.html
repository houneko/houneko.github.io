CSSのプロパティ animation

animationプロパティ

animationプロパティとは

動きのあるWebページを作る場合、JavaScriptを考えるかと思いますが、CSSだけでもアニメーションを実現することができます。このためのプロパティが用意されておりそれがanimationプロパティです

実際には「animation」はショートハンドなので、以下のものがアニメーションに関するプロパティです

アニメーションを行うには最低、animation-nameプロパティとanimation-durationプロパティが必要

animation関係のプロパティ
プロパティ名 意味 その他
animation-name キーフレームの名前 アニメーションには最低限、animation-nameとanimation-durationが必要
animation-duration アニメーション時間 アニメーションには最低限、animation-nameとanimation-durationが必要
animation-timing-function アニメーション速度
animation-delay アニメーション起動までの遅延時間
animation-iteration-count アニメーション回数
animation-direction ループ再生時のアニメーション方向
animation-fill-mode アニメーション前後の状態
animation-play-state アニメーションの再生・一時停止
  • animation-nameプロパティ

    animation-nameプロパティは「@keyframes」というアニメーションを定義する@ルール名を指定するプロパティ。
    このため、animation-nameプロパティを指定しただけではだめで、@keyframes（複数形）を定義しないとアニメーションはかからない

    また、animation-nameと@keyframesが指定されていても、animation-durationが指定されていないと0秒のアニメになって、見かけ何もアニメーションがされない

    つまり最低限、animation-nameプロパティ（@keyframesも）とanimation-durationプロパティの指定が必要

  • animation-durationプロパティ

    animation-durationプロパティは、アニメーションが開始から終了までにかかる時間を指定します。つまり何秒間アニメーションするかを指定するということです。指定しない場合、デフォルト値の0秒が指定されるため0秒のアニメーションになります（実質アニメーションしない） 

    • 
        
        
    
        /* @keyframes名を指定するプロパティ */
        .my-animation { 
          animation-name: myFadeIn; 
          animation-duration: 9s;
        }   

        /* @keyframe fromは開始状態、toが最終状態 */
        /* この例だとopacity0.35から、opacity1（完全な不透明）にアニメーションする */
        @keyframes fadeInOpacity {
          from { opacity: 0.35; }
          to { opacity: 1; }
        }
