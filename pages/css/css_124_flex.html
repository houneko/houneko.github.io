CSSのプロパティ flex

flexプロパティ

flexプロパティとは

まず最初に、displayプロパティとflexプロパティは別のプロパティ（関連はある）

flexプロパティは、親にdisplayプロパティで「flex」を指定した場合に意味を持ち、子アイテムに伸び縮みを設定するためのプロパティ。flexは以下の3つショートハンド

  • flex-grow（ビューポートの余白をどう分配するかを指定。0は余白を使わないという設定）
  • flex-shrink（親要素より子要素が大きい場合の縮めるかを指定する）
  • flex-basis（基準値を指定する。autoなら元のwidthやheightを使う）

flexボックスを指定すると（display:flex; を指定すると）、子アイテムには自動的に「flex:0 1 auto;」が適用される（flex-direction:row;もデフォルトで設定される）

flexプロパティのデフォルトとflex:1; の比較

flexプロパティは、親（コンテナ）がflexボックスになっている時に意味を持つが指定しない場合はデフォルト値が使われる。

  • flexプロパティ指定なしの場合

  • flex-grow: 0; ...ビューポートに余白があっても使わない
  • flex-shrink: 1; ...親要素の領域より子要素が大きい場合は縮む
  • flex-basis: auto; ...元のwidthやheightを使う
    • 
        <head>
        <style>
          section{      <!-- section要素をflexボックスにする -->
            display: flex;
            background-color: blue;
          }
          .neko {       <!-- flexボックスの子アイテムだが、flexプロパティはデフォ -->
            color:pink;
            border: solid 1px;
          }
          .usagi {      <!-- flexボックスの子アイテムだが、flexプロパティはデフォ -->
            color:greenyellow; 
            border: solid 1px;
          }
          .inu {        <!-- flexボックスの子アイテムだが、flexプロパティはデフォ -->
            color: red;
            border: solid 1px;
          }
        </style>
        </head>
        <body>
          <!-- section要素は、親コンテナでflexボックス -->
          <section>                                       
            <div class="neko">ねこ</div>            <!-- neko は flexボックスの子アイテム-->
            <div class="usagi">ウサギです</div>     <!-- usagi は flexボックスの子アイテム-->
            <div class="inu">犬でぇーす</div>       <!-- inu は flexボックスの子アイテム-->
        </section>
        </body>


    親コンテナ（section要素）は、flexボックスになっているので、中の子アイテムはflexボックスになる。
    例ではflexプロパティは指定されていないので、flex-grow:0;（ビューポートの余白は使わない）、flex-shrink:0;、flex-basis:auto;（元のサイズを基準にする）

  • flex:1; の場合

    良く使われる設定で「flex:1;」があるので、これをサンプルとしてどのように動作（表示）が変わるかをみてみる

    flex:1; はショートハンドで以下となる

  • flex-grow: 1; ...ビューポートの余白を「1/N」で割り当てる
  • flex-shrink: 1; ...親要素の領域より子要素が大きい場合は縮む
  • flex-basis: 0; ...元のwidthやheightは使わず、flex-growの指定に依存する
    • 
        <style>
          section{      <!-- section要素をflexボックスにする -->
            display: flex;
            background-color: blue;
          }
          .neko {       
            color:pink;
            border: solid 1px;
            flex: 1;    <!-- flexボックスの子アイテムの flexプロパティ設定 -->
          }
          .usagi {      
            color:greenyellow; 
            border: solid 1px;
            flex: 1;    <!-- flexボックスの子アイテムの flexプロパティ設定 -->
          }
          .inu {        
            color: red;
            border: solid 1px;
            flex: 1;    <!-- flexボックスの子アイテムの flexプロパティ設定 -->
          }
        </style>


    各子アイテムのflex-grow:1。なのでビューポートの余白が1/3ずつ各子アイテムに分配される。
    次にflex-basis:0;なので、各子アイテムの元のwidthは使われない。
    よって3つの子アイテムは均等なサイズとなっている
