CSSの変数

CSSの変数とは

CSSは変数を持つことができます。変数はCSSカスタムプロパティで実現しており、CSS変数と言われることもある。

変数の宣言と定義

変数の宣言と定義は疑似クラス「:root」内で行います


    :root {
      変数名 : 値;
    }

変数を宣言する場所

変数宣言はCSSの先頭（@charset "utf-8"; の後）に書きます


    /* 変数宣言は、CSSの先頭（charset "utf-8"; の後）に書く */
    @charset "utf-8";
    /* =========================
        変数定義エリア
      ========================= */
    :root {
      --breadcrumb-height: 24px;
      --content-max-width: 2400px;
      --content-padding: 16px;
    }

変数名のルール

変数名は「--（ハイフン2個）」で始める


    /* 例：パンくずリストの高さの値を定義する変数： --breadclumb-height
        変数にしておけば今後仕様が変わって高さが40pxになってもこの変数値だけ変えればいい */
    :root {
      --breadclumb-height : 24px;
    }

変数の参照方法

変数の参照は「var(変数名)」で参照することができます。また第二引数を指定することで、変数の参照ができなかった場合に代替値を指定することもできます


    /* 例：定義部 */
    :root {
      --breadclumb-height : 24px;
    }
    /* 例：変数を使って値を指定する 
        上パディングの値をリテラル値で指定せずに変数「--breadclumb-height」で指定している
        また、第二引数が指定されているので、変数がロードできなかった場合は、この代替値が使われる
    */
    セレクタxx {
      padding-top: var(--breadclumb-height, 24px);
    }

グローバル変数とローカル変数

「:root」内で宣言した変数はグローバル変数、他のセレクタで宣言した変数はローカル変数となります


    /* 例：グローバル変数 */
    :root {
      --breadclumb-height : 24px;
    }

    /* 例：ローカル変数 */
    section {
      --main-color : red;
      --main-fontsize : 32px;
    }

変数のスコープ

グローバル変数とローカル変数では、変数が参照できる範囲（スコープ）が違います（当然やろな）。。

  • グローバル変数のスコープ

    疑似クラス「:root」はhtml文書全体を示すので、グローバル変数のスコープはhtml全体になる。このためCSSファイルが複数あったとしても後から読み込むCSSにもこのグローバル変数は見える

    
        <link rel="stylesheet" href="global.css">   <!-- このCSSでグローバル変数が定義されている -->
        <link rel="stylesheet" href="main.css">     <!-- このCSSからもグローバル変数が見える -->
  • ローカル変数のスコープ

    任意のセレクタ内で宣言したローカル変数は、その要素内でだけ参照できる

    
        /* このローカル変数は「section要素」内からだけ見える */
        section {
          --main-color : red;
          --main-fontsize : 32px;
        }

変数の使い方（自分）

自分の変数の使い方は定数としてです。は？変数を定数ってどういうこと

CSSはプログラムではないので、コード中に値を変更して使うよりも「定数」として定義されたものを参照するという使い方があうと思います。そう考えると変数定義しているだけの「variables.css」のようなファイルを作って、デザインを行う「style.css」と別に分けて使うのがいいのかなと思います。
