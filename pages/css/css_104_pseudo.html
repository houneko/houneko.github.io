疑似クラスと疑似要素

疑似クラスは「:」で始まる要素の状態を指定するセレクタ。マウスオーバすると・・の動きは疑似クラスによるもの。
疑似要素は「::」で始まるHTML側には存在しない要素もどきに対してスタイルを指定する

疑似クラス

疑似クラスとは

疑似クラス（pseudo-class）は、要素の状態を指定できるセレクタのこと。コロン「：」でキーワードを指定する。

  • 疑似クラスはコロン「:」で始まるセレクタ 
    
        .my-table tr:hover {...}    /* 他の要素やclass、idに付けて定義したり */
        :target {...}               /* 単独で定義したりできる */

        tr:hover {                    /* テーブルのtr要素にマウスオーバするとその行が yellow になるというCSS設定 */
          backgoround-color: yello;
        }
  • 疑似クラスは「ある状態になった時に」を定義する

    疑似クラスにより、Webページ上の対象がある状態になった時に指定したデザインが適用される。結構便利。またある状態でなくなった場合はCSSのデザインが解除される。例えば、マウスオーバで文字を赤くするデザインがあったとして、マウスオーバが無くなると元の文字色に戻る

  • 疑似クラスに対応する定義はhtml上には無い

    疑似クラスは状態を示すものなので、html上には疑似クラスに対応する定義はない。つまり、HTML側では疑似クラスに対する何かを記述する必要はない

  • 疑似クラスの「クラス」は、class属性とは無関係

    html要素の属性に「class」というのがあるが、読みが一緒なだけで疑似クラスの「クラス」とは無関係。疑似クラスは要素名、class、idに適用できる

  • いろいろな疑似クラス

    疑似クラスの一例。他にもいっぱいある

    疑似クラス名 意味 その他
    :hover マウスオーバした時の状態 タグ全般に適用可能
    :active 対象要素をクリックした状態 タグ全般に適用可能
  • おまけ）疑似セレクタ？

    疑似セレクタは俗称でCSSの正式名ではない。疑似セレクタは「疑似クラス」「疑似要素」を総じて使われているなんちゃって用語

マウスオーバで色を変える疑似クラスのサンプル例


  <head>
    <style>
      .hoge{
          width: 80px;
          height: 80px;
          margin: 4px;
          background-color: skyblue;
      }

      .hoge:hover {                           //疑似クラス hover 「.hogeクラスの要素にマウスオーバした」という状態
          background-color: pink;             //「.hogeクラスの要素にマウスオーバした」という状態に対して色を変更している
      }                                       //
    </style>
  </head>

  <body>
    <div class="hoge">hogeです</div>
  </body>
hogeです
(マウスオーバすると色が変わる)

疑似要素

疑似要素とは

疑似要素とは、HTMLには書かれていない「要素もどき」に対してスタイルを指定できるもの。疑似要素を使えば、HTMLコードを変更することなくCSSで要素を追加したりデザインを変えることができる。実際には存在しない「要素もどき」に対しての設定なのでHTML本体には影響を与えない。
疑似要素は各セレクタ（タグ名やid名、クラス名）の後に「::」タブルコロンで指定する。 


    h1::before {
      content: "hogeです";
      ・・
    }

上記例は、h1要素の前に「before」という要素もどきがあるとして、beforeに対して設定を行う。beforeが疑似要素という事になる。

疑似要素いろいろ 疑似要素 ::first-letter（要素の一文字目を指定）

これはテキストの1文字目という要素もどきがあるとして、その要素もどきに対してのスタイル設定になる。例えば1文字目を赤色にしたいなどの用途などが実現できる。
これを疑似要素を使わないで実装すると以下のようにHTML側のp要素全てにspanタグで先頭一文字を囲み定義しないといけないので、変更があった場合などに保守しにくい。というか疑似要素を使わなければ、HTML側を変更せずに実現することはできない


    <!-- 疑似要素を使わずにHtmlドキュメントの先頭文字を赤色にする -->
    <style>
      p span { color: #FF0000; }
    </style>
    <p><span>先</span>頭の文字だけ赤にする</p>

次に、疑似要素を使って「先頭の文字だけ赤にする」場合
HTML側はpタグで普通に文全部をマークアップするだけ。CSS側で「::first-letter」という疑似要素にて先頭文字だけを修飾する。HTMLには、first-letter という要素は無いがこういう要素があったとして、それに対してCSSのデザインが適用される。


    <!-- 疑似要素を使ってHtmlドキュメントの先頭文字を赤色にする -->
    <style>
      p::first-letter { color: #FF0000; }
    </style>

    <p>先頭の文字だけ赤にする</p>   <!-- HTML側はマークアップするだけ。spanで先頭を切り出す必要は無い -->

先頭の文字だけ赤にする

疑似要素いろいろ 疑似要素 ::before（要素の前に追加する）

HTMLには、before という要素は無いがこういう要素があったとして、それに対してCSSのデザインが適用される。例はこのページで使っているHTML/CSSだが、CSSでh2のタイトルの前に「□」を追加させている。
::befor疑似要素のおかげで、h2タイトルのHTMLコードはそのままでタイトル「hogehoge」の前に「□」というコンテンツが追加されて表示される。 


    .h2chapter-title::before {
      content: "□";               /* 先頭に表示するマーク */
      color: black;                /* マークの色 */
      font-size: 1.4em;            /* マークのサイズ */
      margin-right: 8px;           /* 章タイトルとの間隔を調整 */
    }
