clamp関数

clamp関数とは

clamp関数は、最小値、理想値、最大値を一気に設定できる関数。レスポンシブにしたいけど、そのままだと小さぎてしまう、あるいは大きすぎなどを割ける事ができる


    セレクタ {
      プロパティ: clamp(最小値, 理想値, 最大値);
    }

    この意味は、以下のようになっている
    例）
        .my-class {
          font-size: clamp(14px, 2vw, 24px);
        }
    1. 最小値は14px。これは、画面が小さい場合などで 2vwの値が14pxを下回ってしまう場合、下限として14pxのフォントが使われる
    2. 理想値は2vw。2vwはビューポート幅の2%を示すもの。今の画面サイズでのフォントが14px～24pxに収まる状態であれば、2vwが使われる
    3. 最大値は24px。画面が大きく、2vwが24pxを超えてしまう場合、上限として24pxが使われる

よく使われる使い方の例


    xx {font-size: clamp(20px, 4vw, 48px);}   /* フォントサイズの最小値～理想値～最大値 */
    xx {padding: clamp(16px, 5vw, 64px);}     /* パディングの最小値～理想値～最大値 */
    xx {width: clamp(300px, 80vw, 1200px);}   /* 幅の最小値～理想値～最大値 */
