CSSのクラス設計

CSSの設計とは

例えば、1か所だけだからインラインスタイルでいいやと「<span style="color:red;>」のように書いているところがありました。最初は1か所だったけど他の所も赤色で強調したいところが増えてきて2か所、3か所と増えてきました。そうするとインラインだときつくなってくるのでリンキングスタイルでclassを定義していくと思いますが、その時どう設計するかという話です。

プロジェクトで開発しているなら、プロジェクト内のルールでやればいい。個人でやっている場合でも個人の中で設計方針を決めてやるということかなと思います。なのでこの章は「自分の」設計ということです

考え方の推移

  1. 最初のクラス名 .text-red {color: red;}

    最初、.text-red {color: red;} と作ってみた。HTMLは<span class="text-red"> とすればいいので、OKかなと思ったのですが、これはだめ

    何でだめかというと、協調したい色は赤よりも青がいいとなった時、クラス名が合わなくなってしまう。つまり見た目をクラス名にするのはあんまり良くない。場合によっては見た目をクラスにしてもいいかもしれないですが、この例の場合は見た目をクラス名にすると変動に弱いということです

  2. じゃどういうクラス名がいいのか？

    そもそもなんで赤色にしたかったのかを考えると、この部分は目立たせたい・強調したいというのが始まり。じゃ、意味ベースでクラス名をつけてみようということで.emphasis {color: red;} にしたらしっくり行きそう。

    「ここは強調するところです」という意味で作ったクラス名で限定していないので自由度が高い。協調の色を青にしたい場合でもhtml側はクラス名を修正する必要はなく、CSS内で青に定義したらいいだけ。

    また、boldにするというのを追加したくなっても、協調という世界感は壊れない

    意味ベースでクラス名を作るという方法はうまくいきそう

次の疑問

今、emphasisクラスを以下のように定義したとして、赤色だけを適用したい要素、ボールドだけを適用したい要素があったらどうするか？


  .emphasis {
    color: red;
    font-weight: bold;
  }

考え方の推移

  1. emphasis-colorと、emphasis-boldに分けてみる 
    
      .emphasis-color {color: red;}
      .emphasis-bold {font-weight: bold;}
      
    
      <!-- 強調とは赤色にしたいのか？太字にしたいのか？ が分からなくなる -->
      <span class="emphasis-color">赤色です</span>
      <span class="emphasis-bold">太字ですよ</span>

    一見いいように見えるけど、これはあんまり良くない

    将来的に、emphasis-xxxが増えていき元々の強調とはどれなのか？が分からなくなる。意味が発散してしまい強調というより、emphasis-というラベルが付いた装飾となってしまう。

  2. 意味ベースのクラスは1つに固定してしまう

    このサイトでは「強調」は赤色だと1つに固定する。そうすると強調という意味のクラスは1つだけなので、意味が散らからない

    太字のクラスは、状態を示すものとして定義する

    
      /* 意味としての強調を示すクラスは 1つだけ */
      .emphasis {color: red;}

      /* 太字や他のものは状態を示すものとして定義する */
      .is-bold {font-weight: bold;}
      .is-hidden {display: none;}

    こうすると、is-xxのものがいっぱいできてしまいCSSが見にくくなるのでは？という考えができるが、これは気にしなくてもいい。状態となるものは多数あるのが当たり前で、これらはいろいろな所で再利用が前提。

    状態を定義したものは、意味を語らないので他の所でも汎用的に使える（はず）

    意味ベースでクラス名を作るという方法はうまくいきそう

結論

メインとなるクラスは「意味」ベースで考える。そして意味ベースのものは同じ意味のものを複数定義しないようにする。

状態を定義するものは複数あってもいい
