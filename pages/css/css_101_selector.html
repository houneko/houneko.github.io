CSSのセレクタ

CSSのセレクタにはいくつかの種類があり、このセレクタの種類によりCSSの優先順位も決まっています

CSSのセレクタいろいろ

セレクタはCSSの設定を「どこに」適用させるかを示すもの。「どこに」を示す方法はいくつかある。

  1. タイプセレクタ（要素セレクタ）

    「どこに」を要素名で指定する方法。なので、要素セレクタと言われることもある。

    
      p {
        color: red;
      }

  2. クラスセレクタ

    「どこに」を class名で指定する方法。セレクタをclass名で指定するので、class名の前には「.」ドットが必要。HTML側でclass属性で名前を付けている要素があり、そのclass名を持つところにCSSが適用される。 

    
      HTML側
      <p class="color-red">hogeです</p>
    
    
      CSS側
      .color-red {      /* クラスを示す「.」が必要 */
        color: red;
      }

  3. idセレクタ

    「どこに」を id名で指定する方法。セレクタをid名で指定するので、id名の前には「#」が必要。

    
      HTML側
      <p id="apple-red">りんごの色は？</p>
    
    
      CSS側
      #apple-red {      /* idを示す「#」が必要 */
        color: red;
      }

  4. 属性セレクタ

    セレクタは「属性」で指定することもできる。例えば、aタグの属性で「href」があるがこのhrefをセレクタに指定できる。
    またclass、idを丸ごと属性セレクタで指定できる（classやidも属性だから）。例）[id]。これはid名ではなく全部のid属性が対象。#myid1、#myid2、…全部。

    指定方法は、セレクタを角かっこ[] で囲んで指定すればいい。例）[href] {background-color: red;}

    
        [href] {background-color: pink;}

スタイルの優先度

CSSが適用される優先度は「セレクタの種類」で決まる

上記のようにいろいろなセレクタがあることが分かった。このセレクタには優先度があり「idセレクタ ＞ クラスセレクタ ＞ タイプセレクタ」 となっている。(ただし、!importantがついているものが一番強い、またはインラインが次に強い。それ以外はこのセレクタ順となる)

上記のようにいろいろなセレクタがあることが分かった。このセレクタには優先度があり「idセレクタ ＞ クラスセレクタ ＞ タイプセレクタ」 となっている。

つまり、CSSが適用される優先度は、記述した順番ではなく「セレクタの種類」で決定される。例えば、ある要素にclassとidが設定されているHTMLがあるとして、CSS側はその要素のタイプセレクタ、クラスセレクタ、idセレクタそれぞれが定義されている場合、どのセレクタの設定が優先されるのって話。

結論は、CSS側でタイプセレクタ、idセレクタ、クラスセレクタの順番で記述していても、idセレクタ ＞ クラスセレクタ ＞ タイプセレクタ の順で優先される。つまり、CSSの記述順番ではなくセレクタで適用される優先度が変わる。なので、この例の場合、idセレクタで指定した色が適用される。はぁ。。。


  HTML側
  <p id="apple-color" class="my-green"><りんこですわ</p>
  

  CSS側
  p {                       /* タイプセレクタで、p要素の文字色を yellow に指定している */
    color: yellow;
  }

  #apple-color {            /* idセレクタで、apple-color というIDに割り当てた文字の色設定 */
    color: red;
  }

  .my-green {               /* クラスセレクタで、my-green というクラスに割り当てた文字の色 */
    color: green;
  }
