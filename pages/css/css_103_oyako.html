親子の指定方法

親の下の子への指定方法

セレクタを「親 子」で指定する

親の下の子を指定する場合、「親　子」（親「スペース」子）で指定すると親配下の子へのスタイル設定となる。注意点は、この子というのは子孫全部を指す。つまり、親 子というセレクタ指定は、その親の配下の全子孫に対する指定となる


    <style>
      .parent-a span {  <!-- これは「.parent」の中の「span」に対する指定 -->
        color: red;     <!-- 注意点として、「.parent」の中の全部の「span」に設定される -->
      }
    </style>
  
    <div class="parent-a">
      <p>私は<span>親ねこ</span>です</p>
      <div class="child">
        <p>私は<span>子ねこ</span>です</p>
        <div class="grandchild">
          <p>私は<span>孫ねこ</span>です</p>
        </div>
      </div>
    </div>

このコードの実行例

私は親ねこです

私は子ねこです

私は孫ねこです

この結果から、parent-aクラス配下の孫にもスタイル設定がかかるという事がわかる。この点を理解しておかないと、意図した表示にならない可能性がある。

セレクタを「親 > 子」で指定する

「親 子」の指定だと、親の下の子、孫・・・全てに設定がかかるので、そうではなく特定の子に対して設定したい場合は、この指定方法を使う


    <style>
      .parent-b > p > span {  <!-- 「.parent-b」の中の「p」の中の「span」に対する設定 -->
        color: red;
      }
    </style>
    <div class="parent-b">
      <p>私は<span>親ねこ</span>です</p>        <!-- これはstyle設定がかかる -->
      <div class="child">
        <p>私は<span>子ねこ</span>です</p>      <!-- これは設定がかからない -->
        <div class="grandchild">                <!-- ∵ .parent-b -> .child -> p -> span要素だから -->
          <p>私は<span>孫ねこ</span>です</p>
        </div>
      </div>
    </div>

私は親ねこです

私は子ねこです

私は孫ねこです

この指定方法は、ちゃんとDOMツリーをイメージしておかないといけない。最初「parent-b > span」と指定していたらマッチするものがなくて色がかわらなかった。この例だと、divの直下のpの中のspan なので div > p > span と指定しないといけない

セレクタを「A, B」で指定する

「,」カンマで複数要素を区切って指定する方法。この方法はカンマで区切った複数の要素に対する指定という意味になる

この書き方で注意は「,」カンマで独立して解釈されるという点。どういう事かと言うと以下の例は「.parent-c の中の .oyaneko と .magoneko」に適用する意図で書いているが、これは 「.parent-c の中の .oyaneko」 全ての「.magoneko」と解釈される。つまり、「.magoneko」クラスはどこにある.magonekoクラスであれ赤色になる。
意図通りにしたい場合は、「.parent-c .oyaneko, .parent-c .magoneko」とセレクタを指定しないといけない。自分のイメージとは違ったので最初は少し戸惑ったが、カンマで独立して解釈されるこの仕様の方がいいかな。


    <style>
      .parent-c .oyaneko, .magoneko {   <!-- 「.parent-c」の中の「.oyaneko」と「.magoneko」に対する設定 -->
        color: red;
      }
    </style>
    <div class="parent-c">
      <p>私は<span class="oyaneko">親ねこ</span>です</p>
      <div class="child">
        <p>私は<span class="koneko">子ねこ</span>です</p>
        <div class="grandchild">
          <p>私は<span class="magoneko">孫ねこ</span>です</p>
        </div>
      </div>
    </div>

私は親ねこです

私は子ねこです

私は孫ねこです

セレクタを「A + B」で指定する

「+」プラスで指定すると同じ階層のすぐ後の要素のみが指定される（ややこしいので自分はあんまり使わんかも。。）

当初、そんな感じで思っていたけど使います


    <style>
    .parent-d > p + p {
      color: red;
    }
    </style>
    <div class="parent-d">
      <p>私は<span class="oyaneko">親ねこ１</span>です</p>    <!-- .parent-dの下のp -->
      <p>私は親ねこ２です</p>   <!-- の下のp。これのみ指定される -->
      <div class="child">
        <p>私は<span class="koneko">子ねこ１</span>です</p>
        <p>私は<span class="koneko">子ねこ２</span>です</p>
        <div class="grandchild">
          <p>私は<span class="magoneko">孫ねこ</span>です</p>
        </div>
      </div>
    </div>

私は親ねこ１です

私は親ねこ２です

私は子ねこ１です

私は子ねこ２です

私は孫ねこです

当初使わないかなと思っていたのですが、これは章と章の間を空けたい時に簡潔に指定できるので便利です

以下の例のようにCSSを設定していたらsectionとsectionの間は2em空けて、最初のsectionは空けないというデザインができます


    section + section {
      margin-top: 2em;
    }

イメージ


    <article>
      <section>
        <!-- section A -->      section Aの上にはマージンは空かない
      </section>
      <section>
        <!-- section B -->      section Bの上にはマージンが付く
      </section>
      <section>
        <!-- section C -->      section Bの上にはマージンが付く
      </section>
    </article>

セレクタを「A ~ B」で指定する

「~」チルダで指定すると同じ階層のすぐ後の要素のみが指定される（ややこしいので自分はあんまり使わんかも。。）
