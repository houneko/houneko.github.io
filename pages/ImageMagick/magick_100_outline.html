ImageMagickとは

ImageMagickって何

自分のWebページの画像は、最初pngで作っていたのですがwebpの方が軽くていいみたいなので変えようとしました。しかし、その時既に数千画像あり、これを1つずつwebpに変換しようとすると地獄になるという状況でした。このため何かないかなと探してみつけたものがImageMagick（kがつく）です。
ImageMagickは、ビットマップ画像の作成、編集、合成、変換等のソフトウェアです。マルチプラットフォーム対応、CLI（magick.exe）で操作するのもの使い勝手が良くていい感じです。かなりいろいろできそうですが、自分の使ったものだけ書いています（フォーマット変換）

ImageMagickのインストール

ImageMagickの公式ページなどからインストーラをDLしてインスールします

インスールは、他のWindowsアプリと大きな差は無いかなと思いますのでウィザードに従ってインスールすればいいかなと思います（途中パスを追加するかというチェックが出てきますがこれはチェックを入れます（デフォルトでチェックオンだけど））

ImageMagickのインストール確認

ImageMagickのインストールが終わったら、コマンドラインから以下を実行してインスールが成功したか確認しておきます。バージョンが表示されない場合等はパスが通ってない可能性があるので確認してパスを通します 


        > magick -version

png画像をwebp画像にフォーマット変換する

当初したかった事で、png画像ファイルをwebpにフォーマット変換します


        # // コマンドラインから以下をタイプする
        # // インターネットの説明ページでは、mogrifyコマンドでフォーマット変換する事が書かれているが
        # // Windows環境では、magickのサブコマンドのように指定するみたい（magickから書く）
        > magick mogrity -format webp *.png

        # // そこそこ時間かかるので、Measure-Commandで時間を測ってみた例
        > (Measure-Command {magick mogrity -format webp *.png}).TotalSeconds
