VSCodeの検索と置換の使い方

VSCodeはエディタなので、基本的にはキーボードの上に両手がある状態で使う（自分は）。つまりマウスに持ちかえるのがうざいので、できるだけキーボード操作（ショートカットキー）でやるため、説明もショートカットキー操作のものが多いです。
検索は特に気にすることは無い。置換も対象を全て置換する場合はあまり気にせずリターンキーで次々と置換すればいい。一部置換したくないケースがある場合はちょっとだけ技がいる（と言うか知っているかどうかだけやけど）

VSCodeの検索

検索の使い方

検索は特に気にするものはない。エディタ内の検索は、Ctrl+Fでキーワードを指定し、リターンキーやF3キーで次の候補を続けて検索。全体で検索する場合は、Ctrl+Shift+Fとなる違い位かな。

    VSCodeの検索機能のショートカットキー
  • Ctrl + F ・・・エディタ内の検索
  • Ctrl + Shift + F ・・・プロジェクト全体の検索
  • 次の候補は、リターンキーかF3キー。前の候補は、Shift + F3（Shift + リターンは無い）

Ctrl+Fで検索を行っている画面。検索文字のhogeが4つヒットしており、ハイライト表示されている。次の候補にフォーカスを移動するには、このままリターンキーで移れる。

検索ウィンド内のショートカットキー

検索ウィンド内には3つの選択がありそれぞれにショートカットキーが割り当てられている。Alt+Cで大文字小文字区別する（しない。トグル）の検索をとなる。また、Alt+Wで単語単位の検索、Alt+Rで正規表現パタンでの検索となる

このショートカットキーは置換ウィンドでも同じ


  • Alt+C ： 大文字小文字区別する・しない
  • Alt+W ： 単語単位で検索する・しない
  • Alt+R ： 正規表現で検索する・しない

VSCodeの置換

  1. エディタ内で置換する場合

    候補を全部置換する場合は、あんまり気にすることは無い。一部の候補を置換しない（例えば、ある行のキーワードは置換しないようしたい）場合は、ちょっとだけ技が必要。

      VSCodeの置換機能のショートカットキー
    • Ctrl + H ・・・エディタ内の置換
    • Ctrl + Shift + H ・・・プロジェクト全体の置換

    置換も検索と同じようなIF

    置換も検索と同じようなIFだが、ある行の hogeは置換したくないという事がある。つまりそのhogeだけスキップして置換しないようにするユースケースがある。自分はこういう時、一旦置換を解除して置換したくない文字の次の行にカーソルを移動させてから再度、Ctrl+Hで置換を再開していたが、あまりもどんくさいやり方だった・・。

    置換中に置換したくないものをスキップする方法。この方法は自分で発見した方法で（インターネットを探せばあるかもしれないが自分が探した時はいい方法は見つからず）、置換ウィンドのフォーカスを変えて検索と置換を変える。こうすると現在の候補を置換する or 検索するを切り替えることができ、リターンキーでその操作が実行され、次の候補に移ることができる。

    例１）最初の置換候補は置換する

    置換ウィンドのフォーカスが「置換後文字」にある場合、リターンキーを入力すると最初の置換候補が置換され、その後次の候補に移る

    例２）次の硬派は、置換せずにスキップする

    次の置換候補は置換したくない場合、Shift+TABを入力する。置換ウィンドのフォーカスが「検索文字」の方に変わるので、この状態でリターンすると置換されずに次の候補に移る

    例３）その次の候補は、置換する

    その次の置換候補は置換したい場合、TABキーで置換ウィンドのフォーカスを「置換後文字」に変える。この状態でリターンすると置換され次の候補に移る

    置換ウィンド内のショートカットキー

    置換の場合の置換元ウィンドにもショートカットキーの設定があり、この設定、意味は置換ウィンド内のショートカットキーと同じ

    置換の場合、置換後ウィンドがありここにもショートカットキーがあるが、これは自分は使わないので覚える必要はないと思っています。これは元の文字列の大文字・小文字の状況にあわせて置換するという設定機能。

    
        # ① 大文字小文字区別はない設定が前提
        # ② 置換後ウィンドで置換後文字を指定した後「Alt+P」で設定
        #
        # エディタ内    置換前文字指定（大文字小文字区別なし）  置換後文字列（Alt+P）             置換結果
        # -------------------------------------------------------------------------------------------------------------------------
        # Hoge           hoge（ここは小文字指定でもいい）        neko（ここは小文字指定でもいい）  Neko（先頭が大文字になっている）
        # Hoge           hoge（〃）                              neko（〃）                        NEKO（大文字で置換されている）

  2. ワークスペース全てを対象に置換する場合

    ショートカットキーは「Ctrl+Shift+H」。この置換機能はちょっと使いにくい感じ。秀丸とかはもう少し直観的（慣れの問題か）。

    1. 置換ウィンドに置換前キーワード、置換後キーワードを指定する
    2. 置換候補が表示される
    3. 一気に置換する場合は、何も考えず「Ctrl+Alt+Enter」
    4. 置換を確認しながらする場合、「F4」で次候補、「Ctrl+Shift+1」でその候補を置換
