便利機能: Terminalへ移動するショートカットキーの作成

エディタからTerminalへ移動するショートカットキー

エディタからTerminalへ移動するショートカットキーは「無い」…。このため、例えばPowerShellのスクリプトを作成して、パネルのTerminalで実行をテストしようとした時、キーボードから手を離しマウスに持ち替えて、パネルのTerminalをクリックしてフォーカスを移動させて、やっとコマンドラインから実行できるようになる

これはめんどうなので、エディタからTerminalへ移動するショートカットキーを作ろうって話。なお、Terminalからエディタへ移動するショートカットキーはあるのでいい（Ctrl+1（イチ））

ショートカットキーの作り方

実際は作るというよりもキーを割り当てるって感じ

  1. ショートカットキーの一覧を表示する： Ctrl+K, Ctrl+S
  2. 検索ウィンドに「Terminal Focus」と入力して検索

    キーバインドされていない場合は、左に「+」があるのでクリックして自分用にキーをアサインすればいい。以下の例のように「Ctrl+T」を割り当てた。TerminalのTって覚えやすい。


この設定はどこに保存されてる？

この設定は、Settings.jsonファイルではなく、「Keybindings.json」 というファイルに登録される。

「Keybindings.json」は、Settings.jsonと同じ場所にある

とりあえず自分の「Keybindings.jsonの内容


      //
      // myVersion = v01.00.01
      // 既定値を上書きするには、このファイル内にキー バインドを挿入しますauto[]
      //  
      //  書式）
      //  [
      //      {"key": "...", "command": "...", "args": "...", "when": "..." },
      //      {"key": "...", "command": "...", "args": "...", "when": "..." },
      //      ...
      //  ]
      //
      //  ショートカットキー          意味
      //  ----------------------------------------------------------------------------------------
      //  Ctrl+T                      ターミナルにフォーカス移動させる
      //  Ctrl+K,A                    アクティビティバーの表示・非表示切替（トグル）
      //

      [
          {
              "key": "ctrl+t",
              "command": "workbench.action.terminal.focus"
          },
          {
              "key": "ctrl+k a",
              "command": "workbench.action.toggleActivityBarVisibility"
          },
      ]

その他：そもそもターミナルが表示されていない場合は、Ctrl+@でターミナルを開く
