便利機能: VSCodeのショートカットキー

VSCodeのショートカットキー

VSCodeには多数のショートカットキーがある。コードを書いている時にマウスに持ち替えてGUI操作が頻繁にあると思考が中断するし、キーボードに手を置いた状態のままで操作できるショートカットキーは便利。

ショートカットキーを調べる方法

ショートカットキーの一覧を表示する方法は2つある。1つは現在のキーバインド設定を見る、もう1つはショートカットキー一覧ページを表示するというものである

  1. 現在のキーバインド一覧（ショートカットキーの一覧）を表示する方法

    「CtrlK, Ctrl+S」 このショートカットキーにより、エディタウィンドにキーボードショートカットの一覧タブが表示される。これはショートカットキーの一覧であるが現在バインドされているキーの一覧にもなっている

  2. ショートカットキーの一覧ページを表jする方法

    コマンドパレットを開いて「Keyboard Shortcuts Reference」と入力するとブラウザにショートカットキーの一覧が表示される

よく使うショートカットキー

多数のショートカットキーがあるけどよく使うものだけ覚えておけばいい（と思います）

  • ショートカットキー一覧を表示するショートカットキー
    ショートカットキー名 意味 その他
    Ctrl+K, Ctrl+S ショートカットキー一覧を表示 一覧が開くと検索っぽいこともできる。Ctrl+Kはキー操作の基点に使わることが多いみたい。K:キーのS:ショートカットキーって覚えてる
  • デバッグ系のショートカットキー
    ショートカットキー名 意味 その他
    F5 デバッグの開始
    Shift+F5 デバッグ停止
    Ctrl+Shift+F5 デバッグ再起動
    F9 カレント行にブレークポイントの設定・解除 よく使う
    F10 ステップオーバ
    F11 ステップイン
    Shift+F11 ステップアウト
    ブレークポイント削除 Ctrl+Shift+P（コマンドパレット） > Remove All BreakPoints
  • コメント
    ショートカットキー名 意味 その他
    Ctrl+/ 1行コメント トグルなので設定・解除になる。また言語にあわせたコメントが設定される
    Alt+Shift+a ブロックコメント（覚えなくてもいい） 行範囲を選択して「Ctrl+/」の方が簡単
  • フォルダ操作・ファイル操作系のショートカットキー
    ショートカットキー名 意味 その他
    Ctrl+K, Ctrl+O フォルダを開く よく使う
    Ctrl+O ファイルを開く
    Ctrl+P ファイルを開く（クイック） Ctrl+OとCtrl+Pは似ているが違う
    「@シンボル名」でシンボル名一覧を表示する機能は使える
    Ctrl+N 新規ファイルを作成する コマンドパレットから「file: new File」でもファイル新規作成できるが、こっちのショートカットキーの方がはやい
    Ctrl+Shift+S 名前を付けて保存（Ctrl+S で上書き保存）
    Ctrl+F4 / Ctrl+W ファイルを閉じる Alt+F4 はVSCode自体を閉じる
    Shift+Alt+F フォーマッタを起動する 保存時の自動フォーマットは、"editor.formatOnSave": true

    Ctrl+O と Ctrl+P は違う

    Ctrl+O と Ctrl+P はファイルを開くという動作については同じだけど、GUIを挟む・挟まないという点、ファイルを開くだけではないという点で違いがある

    • Ctrl+O

      Ctrl+Oの場合、以下のダイアログが表示されてGUIでファイルを選ぶ。またこのショートカットキーはファイルを開くだけの機能しかない

    • Ctrl+P

      Ctrl+Pは、エディタ上にファイル名を指定するウィンドウが開きそこにファイル名を入力して開く。キーボードで完結するし動作的にもサクサクしています

      さらにカレントエディタに対してジャンプやコマンドを実行することができます（これは気になった場合に調べてください）。

      で、自分がこれはいいなと思ったのは「@シンボル名」

      使い方は「Ctrl+P」→「@シンボル名」です。@シンボル名は、検索に似た機能ですが、そのページでシンボルとして（意味として）使われているものがリストで表示されます

      これは検索と似ているけど検索とは違います。@シンボル名は、シンボルとして使われているものだけがリストアップされます。上記の例では、tocシンボルは7か所あるとリストアップされていますが、このページには文字列やコメント名にもtocがあるのですが、これらはリストアップされません。検索は、文字列としてtocを探すのでコメント文や文字列内でのtocも全部ヒットします。 

      
                  <!-- 以下のtocは、リストアップされない -->
                  <head>
                    ...
                    <meta name="breadcrumb" content="home:/index.html > VSCode/便利:/pages/vscode/vsc_0ｓ00_index.html#toc400 >">
                    ...
                  </head>

                  <!-- 以下のtocも、リストアップされない -->
                  <!-- toc20 -->
                  <p>hogeです。。。</p>

      この違いを理解していたら、この「@シンボル名」は結構使えると思います

  • エディタ内移動系のショートカットキー
    ショートカットキー名 意味 その他
    HOME / END 行頭・行末に移動 Ctrl+← または Ctrl+→ と同じ
    Ctrl+HOME ファイルの先頭行に移動
    Ctrl+END ファイルの末尾に移動
    Ctrl+G ☆指定行へジャンプ。ボックスが表示されコロンの後に行番号。コロンは削除不可
    Ctrl+Shift+\ ★対応するかっこのペアへ移動、ジャンプする
  • エディタ自体の操作系
    ショートカットキー名 意味 その他
    Ctrl+TAB ★エディタタブ間の移動 逆向きはCtrl+Shift+TAB（Ctrl+PageUp/PageDownでも可）
    Ctrl+\ ☆エディタを縦に分割 コマンドパレットから「Close Editor Group」上下・左右のエディタグループを閉じる
    Ctrl+K, Ctrl+\ ☆エディタをよこに分割 コマンドパレットから「Close Editor Group」上下・左右のエディタグループを閉じる
    Ctrl+数字 ☆分割エディタ間の移動 (1つのエディタ内でのタブ移動はCtrl+TAB)
    Ctrl+W / Ctrl+F4 ★アクティブエディタタブを閉じる（全部のタブが閉じたらエディタが閉じる）
    Alt+Z 表示をウィンドウサイズで折り返す（1行が長いHTMLコード表示などでは使えると思う）
    Ctrl+Shift++ フォントサイズを拡大（Ctrl+Shift+- でフォントサイズを縮小）
    Ctrl+,（カンマ） 設定を開く（GUIの設定。Settings.jsonではない）
    Ctrl+J パネルを開く。トグルなので開く・閉じるになる
    Ctrl+Shift+U パネルの出力タブを開く。トグル
    Ctrl+Shift+M パネルの問題タブを開く。トグル ファイル名の横に数字が出ている場合、それはワーニングやエラーがあることを示している。このショートカットキーでその一覧が表示される
    Ctrl+Shift+Y パネルののデバッグコンソールを開く。トグル
    Ctrl+1（イチ） エディタグループ１を開く
    Ctrl+数字 エディタを縦に分割して開く
    Ctrl+K, Ctrl+J グループ化されている行を全て開く 逆は、Ctrl+K, Ctrl+0（全てのグループを閉じる（こっちはあんまり使わん）
    Ctrl+Shift+P コマンドパレットを開く
  • サイドバー操作系
    ショートカットキー名 意味 その他
    Ctrl+0（ゼロ） サイドバーにフォーカス
    Ctrl+B サイドバーの表示・非表示切替トグル
    Ctrl+Shift+E サイドバーのエクスプローラを開く
    Ctrl+Shift+D サイドバーのデバッグ画面を開く
    Ctrl+Shift+G サイドバーのGitを開く
    Ctrl+Shift+X サイドバーの拡張機能画面を開く
  • アクティビティバー操作系
    ショートカットキー名 意味 その他
    Ctrl+Shift+E アクティビティバーのエクスプローラービューを選択する
    Ctrl+Shift+F アクティビティバーの検索を選択する。Ctrl+Fだとエディタ上の検索になる
    Ctrl+Shift+G アクティビティバーのソース管理を選択する
    Ctrl+Shift+D アクティビティバーの実行とデバッグを選択する
    Ctrl+Shift+X アクティビティバーの拡張機能を選択する
  • カレント行を基点とした操作
    ショートカットキー名 意味 その他
    Ctrl+ENTER カーソル行の下に1行空行を挿入する（Ctrl+Shift+ENTER でカーソル行の上に1行空行を挿入する）
    Ctrl+Shift+K カーソル行を削除（行を選んでDELキーよりも便利）
    Alt+↑ / Alt+↓ カーソル行を上または下に移動させる
    Alt+Shift+↑ カーソル行を上にコピーする（行をコピーしてCtrl+Vするよりも便利）
    Ctrl+] / Ctrl+[ カーソル行にインデントを入れる、カーソル行のインデントを削除する
    Ctrl+C / Ctrl+X カーソル行をコピー または切り取る（★行範囲を指定しなくてもいい！）
    Ctrl+l（エル） カーソル行を選択する（選択しなくていいので便利）
    Ctrl+l,Ctrl+l, カーソル行以下を選択する（Shift+↓で選択するよりもクール）
    Ctrl+D（ディ） カーソル行の単語を選択。Ctrl+Dを連続してタイプすると同じ単語を選択する（置換時に便利）
    HOME / END 行頭・行末に移動（Ctrl+← または Ctrl+→ と同じ）
    Ctrl+G ☆指定行へジャンプ。ボックスが表示されコロンの後に行番号。コロンは削除不可
  • codeコマンド
    ショートカットキー名 意味 その他
    code . VSCodeでカレントフォルダを開く
    code .\hoge\file.txt VSCodeでhogeフォルダのfileを開く
    code -d file1 file2 VSCodeで file1 と file2 を比較表示する
    code -v バージョン表示（GUIだと、三点リーダ -> ヘルプ -> バージョン情報）
    code -h コマンドヘルプ
  • コマンドパレット
    ショートカットキー名 意味 その他
    コマンドパレットを開く Ctrl+Shift+P
    Settings.Jsonを開く Preferences: Open User Settings（Preferences:はジャンルを示す接頭語）
    全てのブレークポイントを閉じる Remove All Breakpoints（ジャンルを示す接頭語は無い）
    更新情報を確認する Code: Check for Updates
  • その他操作系
    ショートカットキー名 意味 その他
    Ctrl+T ★ターミナルへ移動（自分のカスタマイズ環境のみ）
    Ctrl+1(イチ) ★エディタへ移動
    Ctrl+@ パネルの表示・非表示（トグル）
    Ctrl+PgUp ターミナルの切替（複数ターミナル起動時）。トグル動作、Ctrl+PgDnも同様
  • 検索、置換
    ショートカットキー名 意味 その他
    Ctrl+F エディタ内の検索
    Ctrl+H エディタ内の置換
    Ctrl+Shift+F フォルダ、ワークスペース全体の検索
    Ctrl+Shift+H フォルダ、ワークスペース全体の置換
