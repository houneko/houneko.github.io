複数の言語のデバッグ設定を書いたLaunch.json

launch.jsonは、VSCodeでデバッグする時の動作を定義する設定ファイルです。この時、複数言語のデバッグ設定を1つのlaunch.jsonに書くごとができます（Configurationsキーの値を配列にして複数のバリューを設定したらいい）

以下が開発環境として、この時の注意事項です


          # 自分の開発環境
          My
          ├ .vscode
          │   └ launch.json
          ├ 01_SW_Code
          │   ├ 10_Code
          │   │   ├ C
          │   │   ├ PowerShell
          │   │   ├ other lang.・・・

また、launch.jsonは「C」と「Powershell」のデバッグ設定が書かれているとします


          {
            "version": "0.2.0",
            "configurations": [
              {
                "name": "PowerShell: Launch Current File",    // こっちがPowerShell
                "type": "PowerShell",
                "request": "launch",
                "script": "${file}",
                "args": []
              },
              {
                "name": "C Debug (gcc)",                      // こっちがCのデバッグ設定
                "type": "cppdbg",
                "request": "launch",
                "program": "${fileDirname}\\${fileBasenameNoExtension}.exe",
                "cwd": "${fileDirname}",
                "MIMode": "gdb",
                "miDebuggerPath": "C:/Program Files/mingw64/bin/gdb.exe",
                "externalConsole": false,
                "preLaunchTask": "build c"
              }
            ]
          }

発生した問題というか疑問、および対応

今、Cの開発を行いF5キーでステップ実行しデバッグを行いました。無事デバッグが終わり次にPowerShellのモジュール開発を始めました

PowerShellのモジュールでF5キーで実行させたところ「Cのデバッガが始まってしまった」という問題です

これは何故か？launch.jsonに複数言語のデバッグ設定を書いていても各言語の設定が自動的に選択されないということが原因です。
当初、このlaunch.jsonに複数のデバッグ設定を書いておけばそこに書いている言語をデバッグ実行したら自動的に対応する言語のデバッグ設定が使われると思っていました

しかし、launch.jsonは今の開発言語に合わせてデバッグ設定を変えるという事はできません。そういう機能は無いということです。代わりにというわけではないですが、前のデバッグ設定は覚えているので「C言語のデバッグ設定」をPowerShellのモジュールのデバッグに使ってしまったというわけです。
じゃどうすんの？

答え：以下のように、手動でデバッグ設定を変更すればいいです

  1. Ctrl+Shift+Dでデバッグ画面を開く
  2. 今の言語用のデバッグ設定を選択する

    以下のようにデバッグ設定をプルダウンから、今デバッグしたい言語の設定に変更すればいいです
