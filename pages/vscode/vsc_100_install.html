VSCodeのインストールと日本語化

VSCodeのインストール

VSCodeのインストールといっても他のアプリケーションのインストールと大きな違いはなく、インストーラをダウンロードしてウィザードに従ってステップを進めるだけ。
VSCodeのインストーラ

ダウンロードページはいくつかあるようで、ここからダウンロードすると以下のように「User Install」と「System Install」を選ぶようになっています

どっちをDLしたらいいの？と思ったので、一応違いをメモしておくと、以下のようになっています。

なので、1人でPCを占有するならどちらでもいいと思うけど、複数人でPCを共有しているような場合はUser Installの方がいいのかな

  • User Install

    ユーザ毎のフォルダにインストールされる。
    C:\Users\xxx\AppData\Local\Programs\Microsoft VS Code

  • System Install

    システムドライブのProgram Filesにインストールされる。
    C:\Program Files\Microsoft VS Code

VSCodeの日本語化

インストール後は日本語化しておくと便利（そのまま使ってもいい。むしろ英語ができる人はこっちの方がいい）。日本語化は拡張機能としてMicrosoftが提供しているので、以下の手順で日本語化する

  1. 拡張機能を開く（Ctrl+Shift+X）
  2. Japaneseというキーワードで検索

    いくつか見つかった場合「Microsoft」のものを選び、インストールをクリックする
