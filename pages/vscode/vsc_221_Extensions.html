ToDo Tree

ToDo Treeとは

プログラムを作成する場合、後で見直す暫定コードとか、テストコードなどを書くことがあると思う。こういう時は、コメントで後で見直す、テストコードというような記載をするが、忘れてしまい回収されない事がままある（はず）。
この拡張機能は、TODOとなっている項目を管理し、このような回収漏れを防いでくれることができる。

ToDo Treeのインストール

Ctrl+Shift+Xで、拡張機能を開き「ToDo」と入力して検索する。

設定は、ToDoTreeの歯車アイコンで設定を開き、「General:Tags」の項目を探す。この項目が見つかればそこにキーワードとなるタグ名を追加する、または不要なキーワードを削除し、自分用の設定を行う。

この設定を、Settings.json で見ると以下のようになっている。


      "todo-tree.general.tags": [
      "[ ]",
      "[x]",
      "HOUTBD",           //← HOUxxが追加されている
      "HOUTEST",
      "HOUTODO"
      ],

ToDo Treeの使い方

  • 設定編

    ToDoの設定は簡単で、コード内のコメント文にキーワードを書くだけでいいです（コメントとして書かないと認識しない）。 自分の場合はHOUTBDなどを入れたコメントにしている。以下の例はhtmlコードのfooterのリンク先ページが未定の時にコメントにHOUTBDと書いてハイライトされるようにしています

  • ToDoの参照編

    次の例は、TODOの一覧を表示させている例。ToDo TreeをインストールするとVSCodeのアクティビティバーに「木」のアイコンが追加される。このアイコンをクリックするとカレントエディタ内のToDoキーワードの一覧が表示される。

    設定、参照は上述の通りですが、あんまりいっぱいTODOを付けていると埋もれてしまうので、実際の運用では適切な数分だけToDoを設定するのがいいと思います（要はToDoがありすぎて見えなくなり、結局管理できなくなるって事態にならないようにということです）

Highlight Line

Highlight Lineとは

VSCodeでカレント行に下線を表示してくれる機能。最初VSCodeを使うようになった時、カレント行をマークする機能がなくて（あるけど気に入らん）がっかりだったが、この拡張機能を入れて少しいい感じになった（なんか重い時もあるが）。イメージ的には秀丸エディタの下線表示のようにしたかった。

Highlight Lineのインストール

Ctrl+Shift+Xで、拡張機能を開き「Highlight Line」と入力して検索する。

設定は、Highlight Lineの歯車アイコンで設定を開き、色や線幅などを設定するが自分用にはとりあえずは線の幅を1pxにするだけでいい。以下の画像は Settings.json の画面コピー。幅だけ設定している。

Fix JSON

Fix JSONとは

Fix JSONは、JSONの入力を支援する拡張機能。JSONは人にも見やすいデータ形式だけど、いちいちダブルクォーテーションで括らないといけないので書くのがちょっとめんどくさい。なのでJSONっぽい構造のテキストを書き、この拡張機能で本当のJSONに置換するようなイメージ。

Fix JSONのインストール

Ctrl+Shift+Xで、拡張機能を開き「Fix JSON」と入力して検索する。

Fix JSONの使い方

{キー：バリュー, キー：バリュー, …}と入力して、コマンドパレットに「Fix JSON」を入力するとJSONに整形される


      // 1. {mykey1:hoge1, mykey2:hoga2, myekey3:hoge3} のような、なんちゃってJSONをタイプする
      // 2. Ctrl+Shift+P でコマンドパレットを開き、「Fix JSON」と入力
      // 3. 以下のように変換される
      //
      {
        "mykey1": "hoge1",
        "mykey2": "hoga2",
        "mykey3": "hoge3"
      }

Insert Numbers

Insert Numbersとは

Insert Numbersは、連番を付けてくれる拡張機能。例えば複数行にある変数やラベルなどに01、02、03・・と番号をつけたい場合、その位置にカーソルを持って行き手で1つずつ01、02、03・・と入力するしかなかった。マルチカーソルで複数のカーソル位置を指定できるが入力する値は同じものになるため無理（全部01にする場合はできる）。この作業は以外とあり、また地味に疲れる。

この拡張機能は、これらのなんともならん作業を解決してくれるナイスなもの

この拡張機能のリンク先

Insert Numbersのインストール

Ctrl+Shift+Xで、拡張機能を開き「Insert Numbers」と入力して検索する。

Insert Numbersの使い方

  1. 連番を付ける位置をマルチカーソルで指定する


    左の図は、Write-Debugで「test」を表示するものだが、これに連番を付けたい。この時にInsert Numbersが威力を発揮してくれる。
    まずは、マルチカーソルで各行のtestの後ろにカーソルを置く

  2. 「Ctrl+Alt+N」でInsert Numbersを起動する

    Insert Numbersはショートカットキーが用意されており「Ctrl+Alt+N」でInsert Numbersを起動できます

  3. 書式を指定する

    書式は、桁数基数[:初期値:ステップ数] となっており初期値やステップ数は省略できる。
    例えば、連番は10進数2桁(0パディング有り)で、1から+3ずつした値を付けたい場合「%02d:1:3」と指定すればいい

  4. 連番結果


    各行の「test」の後に連番が振られている

    連番は、0パディングの2桁の10進数で、01、04、07・・・と+3刻みになっている

Insert Numbersの使い方（パート2）

基本的には上の章で説明した通りですが、デフォルトで設定された連番を変えたい時にいつも間違ってしまうので、この章は「自分用」に記したメモです（当たり前やんと思うと思いますが・・よく間違うので）

例：やりたい事「01、04、07…」のように、2桁で01から始まり+3ずつ増える連番

マルチカーソルで、Ctrl+Alt+NでInsert Numbersを起動するとデフォルトパタンで連番がつく

このままフォーマット「%02d:1:3」とすると、続きに連番が付いてしまう（こうじゃない!）

フォーマット指定のウィンドはESCで閉じる

デフォルトで付いた連番0,1,2…を「選択」する

選択後に、Ctrl+Alt+NでInsert Numbersを起動し、「%02d:1:3」

これで、無事01,04,07…になった

Path Intellisense

Path Intellisenseとは

コード内のパスを補完するためのツールです。自分の場合、もともとWebページの画像は相対パスで指定していましたが、ページ数が多くなってくるとパスを移動したりした場合、全部の相対パスを変えてないといけないなどの弊害が出てきたため、ルート相対パスに変更しました

しかし、ルート相対パスに変更したら、コード入力時にパス補完がされなくなり何か無いかなと探して見つけたものです

Path Intellisense（MarketPlace） 

          #今まで ： 
              <img src="../../pic/ho   ← ここまで入力するとパスが補完されて hoge.png が候補に表示されていた
          #ルート相対パスに変更後：
              <img src="/assets/pic/ho  ← パスが補完されない（VSCodeは、/assetsというフォルダがどこからか知らないから）

Path Intellisenseのインストール

Ctrl+Shift+Xで、拡張機能を開き「Path」と入力して検索する。

    参考にさせてもらったページ
  • VS Codeを快適に使うための初期設定とおすすめ拡張機能

Path Intellisenseの設定

Settings.jsonに以下のパス設定を追加しておく。そうすると「/assets/」入力でパスが補完されるようになう


          "path-intellisense.mappings": {
            "/": "${workspaceFolder}/src"
          }
