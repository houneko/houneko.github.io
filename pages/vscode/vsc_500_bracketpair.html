かっこのペアを表示する

かっこのペアを表示するとは？ htmlやプログラミング言語の多くは、()や{}で処理やスコープの範囲を示す構造になっている。このかっこのペアをわかるように表示する機能があるので、それを使う方法をまとめる

以前、拡張機能で同様なものを使っていたが更新が止まり別のものを探そうとしたところ、標準機能に同等機能が実装されたのでそちらを使うことにした

設定方法

設定は、Settings.jsonで行う

  1. コマンドパレット（Ctrl+Shift+P）を起動する
  2. 「open user settings」と入力して、Settings.jsonを検索して、開く
  3. Settings.json内で「Bracket」というキーワードを探す

      {
        "editor.bracketPairColorization.enabled": true,   // ()や{}の色をペアでつける設定をtrueにする
        "editor.guides.bracketPairs": true                // かっこにカーソルをあてると色が表示される設定をtrueにする
      }

表示イメージ

以下の例では、if文の{}に紫の線が表示されかっこ範囲が見える化されている。

また、この機能は、htmlのタグでもペア表示してくれる。例えばsummaryタグでは、開始タグの終わりにカーソルをもってくると <summary>～</summary> 範囲を囲んで表示してくれる
