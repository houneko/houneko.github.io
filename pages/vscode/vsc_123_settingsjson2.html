Settings.jsonの各設定

あるフォルダをエクスプローラから非表示にする

  • 使用キー「"files.exclude"」

VSCodeで言語A、言語B、…といろいろな開発を行っていくとあるフォルダは非表示にしたいというケースが出てくると思います。自分の場合で言うと、Webページを開発している時にこのケースがおきました

例えば、MyWebというフォルダの下のsrcというフォルダで各htmlファイルを作成していたのですが、ある時から開発環境とリリース環境を分けて管理するようになり、リリースフォルダ「Release」へ開発結果をコピーする運用に変えました。そうするとエクスプローラ上にこのReleaseフォルダも表示されるのですが、誤って書き換える可能性があるので、これを非表示にしたいという状況になりました

  • 設定例 
    
              {
                "files.exclude": {
                  "Release": true     //Releaseフォルダを表示から除外する（非表示）
                },
                "search.exclude": {
                  "Release": true     //検索も対象外にする
                },
              }

VSCodeの色設定を変える

  • 使用キー「"workbench.colorCustomizations"」

VSCodeを使っていくと自分の好みや、ここはその色じゃないやろっていうのが出てくると思います。その時は色を変えることができます。

"workbench.colorCustomizations"キーで、値はObjectで変えたい色のキーと値を指定します

  • 設定例 
    
              "workbench.colorCustomizations": {                      //workbench全体の色設定キー。値は{}で指定
                "terminal.foreground": "#00FD61",                     //terminal関係の色設定
                "terminal.background": "#383838",
                "terminalCursor.foreground": "#fc11c1",
                "terminal.ansiBrightBlack": "#50C1FF",
                "editorLineNumber.foreground": "#DDDDDD",             //editor関係の色設定
                "editorLineNumber.activeForeground": "#fc11c1",
                "editor.stackFrameHighlightBackground": "#383838",
                "editorRuler.foreground": "#37445c80",
                "editorCursor.foreground": "#f839ef",
                "editorMultiCursor.secondary.foreground": "#ff0000",
                "editor.findMatchBackground": "#dA1B9Af0",
                "editor.findMatchHighlightBackground": "#1565C0f0",
                "editorWhitespace.foreground": "#590be9",
                "tab.activeBackground": "#36454F",                    //tabの色設定
                "tab.activeForeground": "#FFFFFF",
                "widget.shadow": "#00E000",                           //widgetの影色設定
                "focusBorder": "#fc11c1",                             //borderをフォーカスした時の色設定
                "scrollbarSlider.activeBackground": "#c2f4f5",        //scrollbar関係
                "scrollbarSlider.background": "#404040",
                "scrollbarSlider.hoverBackground": "#c2f4f5",
                "window.activeBorder": "#fc11c1",                     //ウィンド関係
                "window.inactiveBorder": "#9dee9d",
                "diffEditor.insertedTextBackground": "#e94ddc30",     //diff時の色設定
                "diffEditor.insertedTextForeground": "#000000",
                "diffEditor.removedTextBackground": "#40ee5b30",
                "diffEditor.removedTextForeground": "#000000",
                "diffEditor.insertedLineBackground": "#00000000",
                "diffEditor.removedLineBackground": "#00000000"
              },
  • 検索時の色指定
    • "editor.findMatchBackground": "#dA1B9Af0", ← 今フォーカスしているfind結果（ピンク系）
    • "editor.findMatchHighlightBackground": "#1565C0f0", ← 複数見つかっているfind候補（ブルー系）


    • editorを検索した画面

      今のカレントfind結果はピンク色で表示されている

      他のfind結果の候補はブルー色で表示され、複数ヒットがあることが分かる
