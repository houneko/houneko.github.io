正規表現のキャプチャグループ

キャプチャグループとは

正規表現は、グループ毎にマッチさせることができます。パタンを丸かっこ（）で囲って示すとキャプチャグループ指定になります。

これで、グループ化した単位でマッチでき、0オリジンの配列でキャプチャ結果が取得されます。()が複数指定した場合、

例えば、2000-12-24 を年月日でキャプチャグループで表現する場合


        > "2000-12-24" -match '(\d{4})-(\d{2})-(\d{2})'
        true
        > $Matches
        Name    Value
        ----    -----
        3       24            # 3番目の()
        2       12            # 2番目の()
        1       2000          # 最初の()
        0       2000-12-24    # グループ0 が 全体

キャプチャグループを使うと、グループ単位で操作ができる。例えば上記の例で、年（グループ１。PowerShellの場合「$1」で示す）を2209年に置換したい場合


        > "2000-12-24" -replace '(\d{4})-(\d{2})-(\d{2})', '2209-$2-$3'  # $1だけリプレース、$2、$3はそのまま使う
        #結果
        2209-12-24    # 年（$1）だけリプレースされている

次の例は、月（$2）だけ取り出してみた場合です


        > "2000-12-24" -match '(\d{4})-(\d{2})-(\d{2})'
        true
        > $Matches[2]
        12

        # 月（$2）の値を変えてみる
        > $Matches[2] = "03"
        > $Matches
        Name    Value
        ----    -----
        3       24            # 3番目の()
        2       03            # 2番目の() 。月だけ 03 に変わっている
        1       2000          # 最初の()
        0       2000-12-24    # グループ0 が 全体
