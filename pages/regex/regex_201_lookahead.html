正規表現の位置へのマッチ

まずは位置へのマッチについて

正規表現は「文字へのマッチ」が一般的ですが「位置へのマッチ」というパタンを定義することもできます。先読み（後読みも）は位置にマッチするパタンです。位置へのマッチは、文字にはマッチしないので見かけ上何も無いように見えます が、内部的には位置にマッチしています

また、^ や $ も「位置へのマッチ」になっており「^」は行頭位置 にマッチします。「$」は行末位置にマッチします


        # 文字列 houneko に ^ をパタンマッチさせてみる
        > "houneko" -match '^'
        True    # ← Trueが返ってきているのでマッチしている
        > $Matches
        Name      Value
        -------------------
        0                     # ← 位置へのマッチなので何も見えない（文字にはマッチしていない）

正規表現チェッカーで見てみる（このチェッカーは位置へのマッチも可視化してくれる）


文字列：houneko

パタン：^（行頭位置へのパタン）

「^」は行頭への位置マッチなので、通常は見えないがこのチェッカーで見ると行頭にマッチしている事が確認できる（$でやると行末位置にマッチしていることがわかる）

正規表現の先読み

正規表現の先読みには、肯定先読みと否定先読みがあります

肯定先読み（Positive lookahead）

肯定先読みは、(?=右側にある文字列) で指定するパタン。(?で始まる拡張グループ構文の1つ。
肯定先読みは、今の位置からパタンで示した文字が「右側に」あるかをチェックする

先読みパタンは確認にだけ使われてマッチした文字には含まれない

実際に使う時は、位置だけだと使いにくいのでその位置にからめて何かの文字と組み合わせて使う


        #肯定先読み
        > "houneko" -match '(?=neko)'  # 右側に「neko」がある位置へのパタンマッチ
        True
        > $Matches
        Name      Value
        -------------------
        0                     # ← マッチしているが位置マッチなので何も見えない


(?=neko)は、肯定先読みで「右側に」nekoという文字がある位置へのマッチ。位置マッチなので通常は見えないがチェッカで見ると文字列nekoの前でマッチしていることが確認できる

実際に使う場合は、位置だけマッチしていても見えないので何かの文字と組み合わせて使うことが多いです。

次の例は、パタンを「hou(?=neko)」に変えて試してみた場合です。

この例では、houで始まりその右側に「neko」があるもの


        > "houneko" -match 'hou(?=neko)'  # houで始まり右側に「neko」があるパタンマッチ
        True
        > $Matches
        Name      Value
        -------------------
        0         hou          # ← houがマッチしているのがわかる

これは、houがまず見つかるので、その右側に（先の方に）「neko」があるかをチェックしている。先読みパタンはチェックに使われるが文字にはマッチしないので、houだけがパタンマッチしている


チェッカーで見ると左記のようにわかりやすい

否定先読み（Negative lookahead）

否定先読みは、(?!右側にある文字列) で指定するパタン（肯定先読みは?=で、?の後が「=」なので肯定っぽいイメージ、否定は「!」なのでNotっぽいイメージと覚えたらいいかな）。(?で始まる拡張グループ構文の1つ。
否定先読みは、今の位置からパタンで示した文字が「右側に」ない かをチェックする

文字列：houneko、否定先読みパタン(?!neko) だとどの位置がマッチするのか？

否定先読みも位置マッチなので、マッチ結果がTrueでも何も見えないけど、チェッカーで見ると以下のようになっていることが分かります。


否定先読みパタン(?!neko)は、右側に「neko」が無い位置にマッチするので、それぞれの位置がマッチしている

hの前の位置は右側に「neko」が無いのでマッチ

oの前の位置は右側に「neko」が無いのでマッチ

・・・

否定先読みも位置にマッチするので、実際に使う場合は文字列と組み合わせて使う

例）文字列：houneko、否定先読みパタンhou(?!inu)

houが見つかり、その右側（先の方）にinuが無い。∴このhouはマッチする。

否定先読みもチェックにだけ使われ、マッチした文字には含まれない 


        > "houneko" -match 'hou(?!inu)'  # houで始まり右側に「inu」が 無い パタンマッチ
        True
        > $Matches
        Name      Value
        -------------------
        0         hou          # ← houがマッチしているのがわかる
