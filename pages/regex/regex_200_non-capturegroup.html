正規表現の非キャプチャグループ

非キャプチャグループとは

非キャプチャグループは、(?:パタン） で示す正規表現です。これはパタンマッチには使うけど、グループとしては保存しないというパタンです。これはメモリには保存しないという事なので若干速度的なパフォーマンスがあります

キャプチャグループとの違いは保存しないというところですね

サンプル例：非キャプチャグループを使って「yyyy-mm-dd」「yyyy/mm/dd」にマッチさせる

非キャプチャグループは、マッチしてもメモリに保存されないだけなので、$Matches[0]では全体マッチとして「2000/12/24」がマッチしている

非キャプチャグループは、保存されないので$Matches[]配列には存在していない


        > "2000/12/24" -match '(\d{4})(?:-|/)(\d{2})(?:-|/)(\d{2})'
        True
        > $Matches

        Name                           Value
        ----                           -----
        3                              24
        2                              12
        1                              2000         # 非キャプチャグループは、$Matches[]配列には含まれない
        0                              2000/12/24   # $Matches[0]の全体には使われている
